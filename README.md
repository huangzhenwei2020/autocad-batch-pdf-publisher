# 批量 PDF 发布插件

AutoCAD / T20 天正建筑批量扫描图框、整理图纸并发布 PDF。当前运行目标为 AutoCAD 2022（.NET Framework 4.8），兼容通过 T20 启动的天正图纸。

## 一、安装与启动

1. 关闭正在运行的插件窗口（AutoCAD 可以保持打开）。
2. 双击根目录的 `启动批量打印插件.exe`。
3. 选择实际使用的 CAD 平台：T20 天正建筑、AutoCAD 2022 或 AutoCAD 2024。
4. 如果 CAD 已经启动，启动器会连接并加载到已有 CAD；不会重复打开同一份 DWG。
5. 选择 T20 时必须使用 T20 启动项，不要用普通 AutoCAD 打开天正对象，否则天正代理对象可能无法正确发布。

首次加载若被 AutoCAD 安全策略拦截，把插件目录加入 `TRUSTEDPATHS`。重新编译后再次双击启动器即可更新 DLL。

## 二、项目管理

“当前项目”保存一套完整发布参数，包括 DWG 文件清单、图框库、属性映射、分组、打印样式、纸张、白边、输出目录和目录插入参数。

- “打开”进入项目管理，可新建、切换、重命名项目。
- 项目文件夹可以在项目管理中自行指定；项目参数保存后，下次启动会自动恢复。
- DWG 文件列表支持勾选、添加、移除和双击打开。已经打开的文件会被激活，不会重复打开。
- 扫描当前文件只处理当前 CAD 文件；扫描所选处理文件列表中勾选的 DWG。
- 扫描设置中勾选需要扫描的空间。`模型空间` 与 `Model` 是同一个空间，不能重复勾选；布局空间可单独勾选，也可以自动扫描全部布局。

## 三、登记图框

图框必须先登记，扫描才知道哪些块是图框。

1. 展开“图框登记”，点击“拾取并登记”。
2. 在 AutoCAD 中选择图框块。
3. 对话框会智能判断 A0–A4、加长比例、方向和打印比例。
4. 检查结果；判断不正确时可手动修改。
5. 图号、图名、楼栋、比例等字段可分别选择图框块中的属性标签，也可填写手工默认值。
6. 保存当前图框库，供以后项目重复使用。

支持标准纸张和常用加长纸张：A0、A1、A2、A3、A4，以及各规格 `+1/4`、`+1/2`。加长尺寸是真实纸张尺寸，不会用基础 A 系列替代。内置 `BatchPdfPublisher.pc3` / `.pmp` 用于加长介质。

### 创建图框块

“创建图框”可以在当前 DWG 中生成标准图框：

- 选择纸张、加长、方向、字体样式、字高、宽度因子和 CAD 颜色。
- 插入纸张边框矩形时按实际纸张尺寸生成。
- 插入属性文字后直接在 CAD 中指定文字框，文字会居中；文字内容使用“标记 / 提示 / 默认值”定义，不是块属性定义。
- 创建图框块时输入用户备注作为名称的一部分，名称格式为 `A1_BPP_备注`；重名会自动增加后缀。
- 只有尺寸符合图框数据库的对象才允许创建；创建成功后会删除原始临时对象，用新图框块替换，并可自动登记。
- 窗口参数会保存上次修改内容。

## 四、扫描与整理图纸

点击扫描后，图纸列表从块属性读取图号、图名、楼栋、纸张、方向和打印比例。列表是项目的累加记录，只有再次扫描对应文件时才更新。

- 图纸可拖动排序，也可用“上移 / 下移”。
- “封面”“目录”备注或图名强制排在最前；“总平图”排在目录之后。
- 图纸列表中的“子项目”是下拉框，可以直接修改分组；未分组图纸也可重新分配。
- 可以按文件、楼栋、子项目管理。发布时只勾选需要发布的子项目。
- 预览只针对当前 CAD 文件；“显示当前子项目预览”默认关闭。
- 模型空间和布局空间会分别记录，避免同一空间被重复扫描。

## 五、发布 PDF

右下角“发布 PDF”按当前设置生成 PDF。发布过程中会显示进度，失败时会指出具体图纸、DWG 和 AutoCAD 错误。

输出设置包括：

- CAD 打印样式（CTB）和白边 / 出血位。
- 输出到指定目录，或输出到各 CAD 文件同级目录；界面会显示实际输出路径，并提供“打开”按钮。
- 每个子项目生成一个 PDF，或每页单独生成 PDF。
- 合并 PDF 时保留每张图纸的真实尺寸：A1 输出 A1，A1+1/4 输出真实加长尺寸。
- 不合并时每页带序号，便于排序；单页文件使用图名命名。
- 文件名可选择包含工程名、子项目名；同名文件可选择覆盖或自动生成带后缀的新目录 / 文件。
- 如果工程目录中已经存在同名输出文件夹，程序会创建带后缀的新文件夹，避免覆盖原工程输出。

### 框选发布当前文件

点击 CAD 文件列表下的“框选发布当前文件”，在当前 DWG 中框选需要发布的图框。随后在弹窗中设置 PDF 文件名、保存位置、预览和合并方式，确认后只发布框选内容。

## 六、插入图纸目录

顶部“插入目录”会把图纸列表绘制到当前 CAD 中，结果是 AutoCAD 的线和文字，不依赖外部表格控件。

1. 选择要插入目录的子项目；一个子项目生成一个目录。
2. 勾选目录列：序号、图号、图名、图框、比例。
3. 设置每页行数、行高、各列宽、文字高度、插入比例、字体样式和 CAD 颜色。
4. 点击“插入目录”，回到 CAD 指定左上角插入点。

所有输入参数会记录，下次打开目录窗口自动恢复。目录插入命令由 AutoCAD 原生命令上下文执行，避免模型窗口锁定导致的 `eNotApplicable`。

## 七、常见问题

### 出现 `eNotApplicable`

先确认当前 CAD 是实际打开图纸的 AutoCAD / T20 实例，并重新双击启动器加载最新版。目录插入时不要同时关闭 AutoCAD 文档或切换到其他图纸。插件日志位于：

```text
%TEMP%\BatchPdfPublisher.trace.log
```

### 出现 `eLayoutNotCurrent`

图纸所在布局不是当前布局。请在扫描设置中取消不需要的布局，或先切换到对应布局再发布；最新版会按图纸记录的空间重新激活布局。

### 天正图纸发布内容异常

不要用普通 AutoCAD 直接打开天正 DWG。先启动 T20 天正建筑，再用启动器连接 T20。程序会在 CAD 文件列表中提示当前文件是否为天正文件。

### 图框识别不正确

展开图框登记，修改纸张、加长、方向和比例；然后重新扫描对应文件。图号 / 图名等属性标签也可以手动重新选择。

## 八、编译

需要安装 Visual Studio 或 Build Tools 的 .NET 桌面生成工具，并安装 AutoCAD 2022（用于引用托管程序集）：

```powershell
msbuild .\BatchPdfPublisherLauncher\BatchPdfPublisherLauncher.csproj /t:Rebuild /p:Configuration=Release /p:Platform=AnyCPU
```

生成的主要文件为：

```text
启动批量打印插件.exe
BatchPdfPublisher.dll
```
