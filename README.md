# 万落建筑工具

面向 AutoCAD / 天正的一体化建筑设计工具。当前包含批量扫描图框、整理与发布 PDF、创建图框、插入图纸目录、批量修改图块属性、建筑设计说明助手、一键楼梯大样，以及建筑图像转 CAD。

统一入口为“万落建筑工具启动器.exe”，加载后在 AutoCAD Ribbon 中显示“万落建筑工具”标签。

## 唯一正确的编译与安装入口

从 GitHub 拉取后，不要运行仓库根目录或旧安装包中的 DLL/EXE。执行：

```powershell
git pull --ff-only
powershell -ExecutionPolicy Bypass -File .\build\Build-Release.ps1
```

然后只运行 `dist\WanLuoArchitectureTools\万落建筑工具启动器.exe`。脚本每次都会清空旧发布目录并从当前提交重新编译，同时用 `build-info.json` 记录提交号和文件哈希。环境要求、版本分组、验证及清理方法见 [从 GitHub 构建与安装最新版本](docs/BUILD_AND_INSTALL.md)。

## 2026-08-14 更新

- 比例管理严格限定在本次框选对象内处理，取消复杂图纸中的全图重生成，并补充各阶段耗时日志。
- 优化天正对象比例更新：墙、门窗、柱、尺寸、轴号和图名标注继续参与处理；图名标注会同步更新显示的 `1:N` 比例文字。
- 登记图框加入独立比例更新规则：只修改 TAG 含“比例”的登记属性，不调整图框块比例、其他属性、字体、字高或图层；同名不同结构图框继续按登记特征区分。
- 制图标注默认文字样式调整为：`WL-文字-正文`（宋体、2.5）、`WL-文字-标题`（黑体、7.0）、`WL-文字-标注`（宋体、3.5）；旧版原始默认配置可安全迁移，用户自定义值不覆盖。
- 启动器增强 AutoCAD/T20/T30 多版本识别并内置建筑设计说明与楼梯组件；支持版本缺少任一功能组件时会停止安装并明确提示。
- 修复一键楼梯大样未加载：启动器现内置完整 R24 楼梯运行包（宿主、计算核心及 WebView2 依赖），无需另带 `StairDetail` 文件夹。

## 一、安装与启动

1. 关闭正在运行的插件窗口（AutoCAD 可以保持打开）。
2. 双击干净发布目录 `dist\WanLuoArchitectureTools` 中的 `万落建筑工具启动器.exe`。
3. 选择实际使用的 CAD 平台：启动器可识别 AutoCAD 2021–2026 以及本机检测到的 T20/T30 天正产品，并显示完整产品名和年份。AutoCAD 2020 及更早版本不再支持。
4. 如果 CAD 已经启动，启动器会连接并加载到已有 CAD；不会重复打开同一份 DWG。
5. 选择 T20 时必须使用 T20 启动项，不要用普通 AutoCAD 打开天正对象，否则天正代理对象可能无法正确发布。

首次加载若被 AutoCAD 安全策略拦截，把插件目录加入 `TRUSTEDPATHS`。重新编译后再次双击启动器即可更新 DLL。启动器中的“卸载”只删除插件、自动加载包和插件纸张配置，不删除 DWG、项目参数或 PDF。

AutoCAD 2025/2026 已改用 .NET 8，和本插件的 .NET Framework 4.8 程序集不是同一运行时；启动器会检测到这类版本并提示使用对应编译版本，避免误加载导致 CAD 崩溃。版本关系以 Autodesk 的 Managed .NET Compatibility 表为准。

## 二、快速入口

Ribbon 和经典菜单会显示全部已登记功能。输入 `KJJPZ` 可打开“快捷键设置”，修改后立即生效；以后新增功能也会自动进入该窗口。默认快捷键包括：

- `BPP`：打开面板
- `TKK`：创建图框
- `ML1`：插入目录
- `LTDY`：打开楼梯构件编辑器并生成一键楼梯大样（AutoCAD 2021–2026）
- `TXZCAD`：打开“图像转 CAD”，识别图片中的建筑线稿并生成可编辑直线
- `BZS`：打开“制图标准设置”，统一配置并应用图层、文字样式和标注样式
- `KJJPZ`：修改所有功能快捷键

## 统一制图标准

图框、图纸目录、建筑说明和楼梯大样共用一套命名资源。输入 `BZS` 后可在“图层标准 / 文字样式 / 标注样式”三页中修改名称、ACI 颜色、线宽、线型、字体文件、宽度因子、常用标注比例、标注文字高度和箭头大小。窗口会标记当前 DWG 中资源是“已存在”还是“待创建”，支持“仅保存设置”和“保存并应用到当前图纸”。默认只补齐缺少的资源；勾选“同步更新图中已有的同名资源”后，才会修改已有资源。设置保存在 `%APPDATA%\WanluoArchitectureTools\drafting-standard.ini`，后续图框、目录和楼梯会自动读取。

## 一键楼梯大样

Ribbon“万落建筑工具”或经典菜单中点击“楼梯大样（LTDY）”，也可以直接输入 `LTDY`。编辑器支持按楼层设置不同层高和跑数，每跑独立设置踏步级数、踏步宽、梯段宽、方向、楼板、平台及梁参数。确认参数并指定插入点后，插件会按楼板标高生成首层、中间层和顶层楼梯平面，并在右侧生成构件化连续楼梯剖面；中间层的到达梯段使用隐藏线，平面包含上下行箭头、剖切线、图名、比例及楼梯间总尺寸。插件还会对重复构件、尺寸冲突和不合理构造给出校验提示。

楼梯大样随 R24、R25 组件安装，覆盖 AutoCAD 2021–2026。

## 图像转 CAD

Ribbon“建筑工具”中点击“图像转 CAD”，或输入 `TXZCAD` / `LINEVISION`。第一版支持 PNG、JPG、BMP、TIFF 图片，可整图识别或直接框选图片范围；处理后以绿色、蓝色和黄色分别预览水平线、垂直线与斜线。用户可以逐根取消误识别对象，通过两点输入实际距离标定比例，再指定左下角插入点生成原生 CAD `Line`。

生成结果按方向写入 `LV-LINE-H`、`LV-LINE-V`、`LV-LINE-DIAG` 图层，整次插入使用一个事务，失败不会留下半成品。当前发布版先完成本地线稿矢量化；界面会明确显示 OCR Worker 尚未安装，不会把未识别文字冒充线稿 OCR。中文 OCR、文字遮罩和原生文字恢复将在独立本地 Worker 接入后启用，避免 OCR 原生依赖污染 AutoCAD 进程。

## 三、项目管理

“当前项目”保存一套完整发布参数，包括 DWG 文件清单、图框库、属性映射、分组、打印样式、纸张、白边、输出目录和目录插入参数。

- “打开”进入项目管理，可新建、切换、重命名项目。
- 项目文件夹可以在项目管理中自行指定；项目参数保存后，下次启动会自动恢复。
- DWG 文件列表支持勾选、添加、移除和双击打开。已经打开的文件会被激活，不会重复打开。
- 扫描当前文件只处理当前 CAD 文件；扫描所选处理文件列表中勾选的 DWG。
- 扫描设置中勾选需要扫描的空间。`模型空间` 与 `Model` 是同一个空间，不能重复勾选；布局空间可单独勾选，也可以自动扫描全部布局。

## 四、登记图框

图框必须先登记，扫描才知道哪些块是图框。

1. 展开“图框登记”，点击“拾取并登记”。
2. 在 AutoCAD 中选择图框块。
3. 对话框会智能判断 A0–A4、加长比例、方向和打印比例。
4. 检查结果；判断不正确时可手动修改。
5. 图号、图名、楼栋、比例等字段可分别选择图框块中的属性标签，也可填写手工默认值。
6. 保存当前图框库，供以后项目重复使用。

支持标准纸张和常用加长纸张：A0、A1、A2、A3、A4，以及各规格 `+1/4`、`+1/2`。加长尺寸是真实纸张尺寸，不会用基础 A 系列替代。`Resources/Plotters` 中的 `BatchPdfPublisher.pc3` / `.pmp` 用于加长介质。

## 发布目录结构

插件发布文件按类型存放，不要把 DWG、PC3、PMP 与程序 DLL 混放：

```text
万落建筑工具启动器.exe
CadApi/
  R24/、R25/             AutoCAD 2021–2026 分代程序组件
Resources/
  Blocks/                插件图块资源
    WanLuoArrowSymbols.dwg
  Plotters/              PDF 绘图仪与纸张资源
    BatchPdfPublisher.pc3
    BatchPdfPublisher.pmp
（建筑设计说明与楼梯运行组件已嵌入启动器，安装时统一校验）
```

启动器会把图块库安装到对应版本组件下的 `Resources/Blocks`。旧版本将资源直接放在 DLL 旁边的方式仍可读取，但新的发布包统一使用上述结构。

默认启动方式为便携运行：插件 DLL、建筑说明组件、楼梯组件和图块库直接从启动器所在目录读取，不复制到用户插件目录。因此整个文件夹可以移动到其他磁盘或电脑，移动后重新运行启动器即可。只有勾选“永久安装”时，才会部署到 AutoCAD 的 `ApplicationPlugins` 自动加载目录。用户设置、工程参数和日志仍保存在当前 Windows 用户的应用数据目录；PDF 绘图仪文件仍需按 AutoCAD 规则复制到该用户的 Plotters 目录。

### 创建图框块

“创建图框”可以在当前 DWG 中生成标准图框：

- 选择纸张、加长、方向、字体样式、字高、宽度因子和 CAD 颜色。
- 插入纸张边框矩形时按实际纸张尺寸生成。
- 插入属性文字后直接在 CAD 中指定文字框，文字会居中；文字内容使用“标记 / 提示 / 默认值”定义，不是块属性定义。
- 创建图框块时输入用户备注作为名称的一部分，名称格式为 `A1_BPP_备注`；重名会自动增加后缀。
- 只有尺寸符合图框数据库的对象才允许创建；创建成功后会删除原始临时对象，用新图框块替换，并可自动登记。
- 窗口参数会保存上次修改内容。

## 五、扫描与整理图纸

点击扫描后，图纸列表从块属性读取图号、图名、楼栋、纸张、方向和打印比例。列表是项目的累加记录，只有再次扫描对应文件时才更新。

- 图纸可拖动排序，也可用“上移 / 下移”。
- “封面”“目录”备注或图名强制排在最前；“总平图”排在目录之后。
- 图纸列表中的“子项目”是下拉框，可以直接修改分组；未分组图纸也可重新分配。
- 可以按文件、楼栋、子项目管理。发布时只勾选需要发布的子项目。
- 预览只针对当前 CAD 文件；“显示当前子项目预览”默认关闭。
- 模型空间和布局空间会分别记录，避免同一空间被重复扫描。

## 六、发布 PDF

右下角“发布 PDF”按当前设置生成 PDF。发布过程中会显示进度，失败时会指出具体图纸、DWG 和 AutoCAD 错误。

输出设置包括：

- CAD 打印样式（CTB）和白边 / 出血位。
- 输出到指定目录，或输出到各 CAD 文件同级目录；界面会显示实际输出路径，并提供“打开”按钮。
- 每个子项目生成一个 PDF，或每页单独生成 PDF。
- 合并 PDF 时保留每张图纸的真实尺寸：A1 输出 A1，A1+1/4 输出真实加长尺寸。
- 不合并时每页带序号，便于排序；单页文件使用图名命名。
- 文件名可选择包含工程名、子项目名；同名文件可选择覆盖或自动生成带后缀的新目录 / 文件。
- 如果工程目录中已经存在同名输出文件夹，程序会创建带后缀的新文件夹，避免覆盖原工程输出。

### 框选发布当前文件

点击 CAD 文件列表下的“框选发布当前文件”，在当前 DWG 中框选需要发布的图框。随后在弹窗中设置 PDF 文件名、保存位置、预览和合并方式，确认后只发布框选内容。

## 七、插入图纸目录

顶部“插入目录”会把图纸列表绘制到当前 CAD 中，结果是 AutoCAD 的线和文字，不依赖外部表格控件。

1. 选择要插入目录的子项目；一个子项目生成一个目录。
2. 勾选目录列：序号、图号、图名、图框、比例。
3. 设置每页行数、行高、各列宽、文字高度、插入比例、字体样式和 CAD 颜色。
4. 点击“插入目录”，回到 CAD 指定左上角插入点。

所有输入参数会记录，下次打开目录窗口自动恢复。目录插入命令由 AutoCAD 原生命令上下文执行，避免模型窗口锁定导致的 `eNotApplicable`。

## 七、常见问题

### 出现 `eNotApplicable`

先确认当前 CAD 是实际打开图纸的 AutoCAD / T20 实例，并重新双击启动器加载最新版。目录插入时不要同时关闭 AutoCAD 文档或切换到其他图纸。插件日志位于：

```text
%TEMP%\BatchPdfPublisher.trace.log
```

### 出现 `eLayoutNotCurrent`

图纸所在布局不是当前布局。请在扫描设置中取消不需要的布局，或先切换到对应布局再发布；最新版会按图纸记录的空间重新激活布局。

### 天正图纸发布内容异常

不要用普通 AutoCAD 直接打开天正 DWG。先启动 T20 天正建筑，再用启动器连接 T20。程序会在 CAD 文件列表中提示当前文件是否为天正文件。

### 图框识别不正确

展开图框登记，修改纸张、加长、方向和比例；然后重新扫描对应文件。图号 / 图名等属性标签也可以手动重新选择。

## 八、编译

需要安装 Visual Studio 或 Build Tools 的 .NET 桌面生成工具，并安装 AutoCAD 2022（用于引用托管程序集）：

```powershell
msbuild .\BatchPdfPublisherLauncher\BatchPdfPublisherLauncher.csproj /t:Rebuild /p:Configuration=Release /p:Platform=AnyCPU
```

生成的主要文件为：

```text
万落建筑工具启动器.exe
BatchPdfPublisher.dll
```
