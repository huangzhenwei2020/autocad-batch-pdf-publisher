# 领域模型

## 项目

`ArchitectureProject` 是唯一项目数据中心，包含所在地、项目阶段、建筑分类、规划指标、建筑参数、防火、无障碍、防水、节能、绿色建筑、单体、批复文件和规范引用。

关键数据使用 `ProjectValue<T>`，同时保存：

- 值；
- 状态；
- 数据来源和来源文件；
- 录入人和确认时间；
- 是否人工覆盖及覆盖原因。

空字符串不等同于“不适用”或“其他专业提供”。

## 文档

`ArchitectureDesignSpecDocument` 由章节、专业表格、版面、CAD 绑定和修订信息组成。章节和文档节点均有稳定 GUID。项目字段节点与普通文本分离，以便全文同步和避免误删。

## 专业表格

`ArchitectureTable` 保存表格类型、列、行、单元格和公式审计。公式审计记录输入、结果、计算时间、公式版本和人工覆盖原因。阶段0包含：

- 主要技术经济指标表；
- 防水设计表；
- 建筑安全措施表；
- 防火分区汇总表。

## 规范和审查问题

`StandardReference` 保存标准编号、名称、生效/废止日期、状态、适用类型和官方来源。状态为 `Unknown` 时不得据此判定符合。

`ReviewIssue` 可定位到章节、节点、字段、表格单元格或后续 CAD 对象。

## CAD 绑定

阶段0只定义 DTO，不连接 AutoCAD。持久绑定使用 DWG 指纹、Handle、稳定节点 ID、内容 Hash 和几何快照，不使用 ObjectId 作为跨会话标识。
