# 建筑专业表格编辑器

对应版本：0.14.0

## 当前能力

- 创建主要技术经济指标表、防水设计表、室内装修做法表、建筑安全措施表和无障碍设施表；
- 多张表随项目文件保存；
- 新增、删除行列；
- 设置标题、表号、单位、列宽、小数位、必填状态；
- 从 Excel 粘贴二维区域；
- Shift+单击选择矩形区域；
- 合并和拆分单元格；
- 项目字段绑定；
- 安全白名单公式；
- 公式输入、结果、输入值、计算时间和版本审计；
- CSV、XLSX 导出；
- 撤销和重做。

## 从 CAD 读取与直接导出

有两种互不覆盖的入口：

- 在建筑设计说明助手中点击“从 CAD 读取表格”，识别结果会作为一张新的自定义专业表格打开，供用户复核和编辑；
- 在“万落建筑工具”Ribbon/经典菜单点击“CAD表格转Excel”，或输入默认快捷键 `CE`。识别后进入类 Office 编辑预览，可修改文字与列名、粘贴 Excel 区域、增删行列、合并或拆分单元格并设置对齐方式。之后可导出 `.xlsx`，或选择比例、CAD 文字样式与纸面字高后重新插入 CAD；旧命令 `CAD2XLSX` 继续兼容。

直接导出支持一张 AutoCAD 原生 `Table`，也支持由直线、多段线、普通文字、MText、块属性和可读取的天正文字组成的线框表格。默认忽略关闭、冻结和不可见图层。识别和导出过程只读，不炸开、不修改、也不覆盖源 DWG；用户取消框选或取消保存时不会生成文件。

导出完成后，CAD 命令行会显示文件位置、识别行列数和待复核提示数量。存在断线、跨格冲突或代理对象读取提示时，仍保留识别结果并明确提示用户复核，不静默当作完全正确。

## 多单元格选择

先单击起点，再按住 Shift 单击终点。起点和终点围成的矩形区域会被选中。

整行或整列可以通过行号、列标题选择。合并区域必须是完整矩形，且不能包含其他已经合并的单元格。拆分后，被覆盖单元格原有内容会恢复，不会因为合并而删除。

## 项目字段绑定

选中单元格后，可从“绑定字段”选择项目数据中心中的字段。插件会复制：

- 字段值；
- 单位；
- 数据来源；
- 确认状态；
- 字段路径。

表格保存字段路径和当前显示值，并支持在需要时集中同步项目数据中心的最新值。

点击“同步项目字段”会扫描所有表格：

- 普通绑定值自动更新；
- 字段不存在时给出提示；
- 人工修改或含公式的绑定单元格进入冲突确认；
- 用户可选择保留人工修改，或使用项目字段覆盖；
- 不会在没有提示的情况下覆盖人工内容。

## 公式

公式只能引用当前行的列，列名写在方括号中：

```text
ROUND([design] - [planning], 2)
IF([design] >= [planning], 1, 0)
SUM([planning], [design])
```

允许的函数：

```text
SUM
MIN
MAX
ROUND
IF
ABS
COUNT
```

允许的运算符：

```text
+  -  *  /
>  <  >=  <=  ==  !=
```

公式由内置解析器解释，不调用 `eval`、`Function` 或其他动态脚本执行能力。除零、未知列、非法字符、未知函数和参数数量错误都会被阻止。

每次成功计算都会保存公式审计信息。用户直接修改公式结果时，审计记录会标记为人工覆盖。

## 当前边界

- 公式当前只引用同一行；
- 尚未支持跨行、跨表和项目字段直接参与公式；
- 字段绑定支持集中手动同步，尚未自动监听每一次字段变化；
- 合并单元格在编辑预览中按真实跨行跨列区域显示，也可导出 Excel 并输出为原生 CAD Table；
- 跨页重复表头目前只保存排版参数，待 CAD 输出阶段生效。
