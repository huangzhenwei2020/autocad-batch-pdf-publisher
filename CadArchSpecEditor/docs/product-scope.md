# 产品边界

本模块只服务于建筑专业施工图设计说明、专项说明、建筑专业技术经济指标及相关专业表格。

系统可以帮助设计人员进行说明编制、数据同步和审图前自检，但不得宣称自动保证审图通过，也不得替代注册建筑师、设计校审人员或施工图审查机构。

阶段0只建立可追溯数据基础：

- 明确区分未知、待确认、已确认、不适用、其他专业提供、专项提供和人工覆盖；
- 确定性检查只能使用已确认或有覆盖原因的值；
- 规范与规则必须保存来源、版本、生效日期和核实状态；
- AI 不参与阶段0，也不得自动确认专业参数。

批量 PDF 功能仍由现有 BPP 模块承担。两个模块以后只通过稳定 DTO 和项目标识共享必要信息，不互相引用界面或 AutoCAD 实现。
