# 建筑设计说明助手

`CadArchSpecEditor` 是 BPP 产品套件中的独立建筑专业模块。它负责结构化建筑设计说明、项目数据、专业表格、可追溯规则预审以及后续 CAD 写回；现有 `BatchPdfPublisher` 继续独立负责批量 PDF。

当前已完成领域基础、AutoCAD 2022/2026 双技术代际宿主验证、结构化章节编辑器、
项目文件持久化、字段来源与锁定、建筑类型模板、分步新建项目向导、版本历史，
以及国家建筑专业基础完整性预审的第一批试运行规则。
专业表格编辑与规范预设库已进入可测试阶段；规范预设只提供选用入口，正式项目仍须按报审日期和所在地复核现行版本。

## CAD 图框与文字双向交换

在 AutoCAD 中运行 `JZSM` 后，面板顶部提供三个 CAD 功能：

- `CAD 版面`：在当前 DWG 拾取图框块，再框定说明文字编辑区。系统按图框真实外包尺寸识别 A0–A4、`+1/4`、`+1/2`、方向和出图比例；图框区与文字编辑区分别保存到项目文件。
- `从 CAD 获取文字`：框选 DBText/MText，按从上到下、从左到右排序，并追加到当前章节。
- `插入当前章节`：把当前章节作为 MText 插入已记录图框的文字编辑区，纸面字高按出图比例转换；若内容超过文字区会明确提示。

网页预览不再使用固定页面：外框显示实际图框区，内部虚线框显示文字编辑区。图框 Handle 和 DWG 路径一起保存，切换图纸、图框被删除或 Handle 失效时会要求重新拾取，避免写到错误图纸。

## 当前可测试内容

- 六个 `netstandard2.0` 共享核心项目；
- 建筑项目、字段状态、设计说明、专业表格、规范、审查问题和 CAD 绑定领域模型；
- React + TypeScript + ProseMirror 建筑说明编辑器；
- AutoCAD 2022（.NET Framework 4.8）和 AutoCAD 2026（.NET 8）宿主；
- `.jzsmproj` 新建、打开、保存、另存为、最近项目和版本快照；
- 项目字段来源、确认状态、锁定和人工覆盖；
- 建筑类型、设计阶段和专项条件驱动的章节模板；
- 四步新建项目向导，录入项目地区、报审日期、分类、规模及专项条件；
- 字段值、状态、锁定和来源的持久化变更记录；
- 地下室、项目元数据、绿色建筑目标及字段锁定状态的确定性冲突检查；
- 项目快照列表、当前版本差异比较、安全恢复和恢复前自动备份；
- 国家基础规则“一键预审”、问题统计、问题定位和 JSON 审查报告导出；
- 设计依据、项目概况、技术指标、无障碍、防火章节及关键项目字段的完整性检查；
- 预审记录随项目归档，保留规则版本、执行时间、完整问题清单和项目数据指纹；
- 预审历史可区分“匹配当前项目”与“基于旧版本数据”，并支持 A4 打印或保存 PDF；
- 预审问题支持待处理、处理中、已解决、接受风险和不适用五种处理状态；
- 保存责任人、处理意见、复核人，形成问题闭环和签字汇总；
- 报告采用多页 A4 版式，包含封面、范围汇总、问题明细、处理记录和规则声明；
- 预审历史支持任意两次记录对比，区分新增、持续和本次不再检出的问题；
- 持续问题显示处理状态变化，差异结果可导出 JSON；
- 项目可设置设计单位、项目负责人、编制人、校对人、审核人和默认报告编号；
- 每次预审固化当时的签发信息，旧报告不会被后续人员设置改写；
- 专业表格正式纳入项目文件，可新建和编辑主要技术经济指标表、防水设计表；
- 增加室内装修做法表、建筑安全措施表和无障碍设施表；
- 表格支持增删行列、列宽/单位/小数位/必填设置、撤销重做、Excel 区域粘贴和 CSV 导出；
- 技术经济指标差值自动计算，防水道数与必填内容提供即时校验；
- 表格支持 Shift 矩形多选、合并和拆分单元格，拆分后保留原单元格数据；
- 单元格可绑定项目数据中心字段，并保存字段路径、数值、单位、来源和状态；
- 支持集中同步所有绑定字段；人工修改或公式内容会进入冲突确认，不会被静默覆盖；
- 正文中的专业表格可单击选择、放大、缩小和删除；双击进入同一表格编辑，保存后同步正文引用；
- 规范库支持多选批量插入，并按住宅、办公、商业、教育、医疗、宿舍、旅馆、养老、停车、文体、工业和既有建筑改造等类型筛选；
- 老项目打开时自动合并新版本预设，同时保留用户修改和自定义规范；
- 支持 SUM、MIN、MAX、ROUND、IF、ABS、COUNT 白名单公式和可追溯公式审计；
- 白名单公式、版本化规则包、JSON Schema 和自动化测试。

## 构建

需要 .NET 8 SDK 和 Node.js。共享程序集的目标框架仍是 `netstandard2.0`，因此后续可被 .NET Framework 4.8 与 .NET 8 宿主引用。

```powershell
dotnet build .\CadArchSpecEditor.sln -c Release
dotnet test .\CadArchSpecEditor.sln -c Release

cd .\src\CadArchSpec.Editor.Web
npm ci
npm run build
npm run test
```

## 安全和专业边界

- 不把 AI 当作规范数据库；
- 不把 `Unknown` 或 `Pending` 字段用于确定性“符合”判断；
- 规则只能使用受控检查类型和白名单公式；
- 当前国家基础规则包状态为 `Draft`，只做资料完整性提示，不能代替建筑专业审查；
- 防火、无障碍等规范引用仅用于提示适用标准，不自动判定条文符合性；
- 地方规则完成正式调研和专业复核前只保留空包提示；
- 共享核心不引用 AutoCAD、WPF 或 WebView2；版本宿主保持薄适配层。
