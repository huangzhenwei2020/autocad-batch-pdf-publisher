# 万落建筑工具云同步开发计划

## 1. 目标

为万落建筑工具建立可选的跨设备同步能力：用户在本机选择同步文件夹，配置、方案库和项目文件保存成功后自动进入同步队列；另一台电脑连接同一云端后，安全取得最新版本。同步失败不得影响 AutoCAD、本地保存或现有功能。

同步能力采用“统一同步引擎 + 存储适配器”结构，先交付本地同步文件夹，之后接入 115 官方开放平台。不得使用抓取 Cookie、模拟网页或其他未公开接口。

## 2. 设计原则

1. 本地文件永远优先保证可用，网络故障不能阻止保存。
2. 两端同时修改时不静默覆盖，必须保留冲突副本。
3. 下载到临时文件，完成哈希校验后才原子替换正式文件。
4. 每次远端覆盖和删除前建立本地历史版本。
5. 判断内容使用 SHA-256 和上次同步基线，不只依赖修改时间。
6. DWG 正在 AutoCAD 中打开时禁止远端覆盖，下载到待应用区等待关闭。
7. 同步数据使用相对路径；机器相关绝对路径、令牌、日志和缓存不得同步。
8. 关闭同步后，程序行为必须与同步功能开发前完全一致。

## 3. 数据范围

### 3.1 默认同步

- 通用设置、快捷键、图层、比例、标注和制图标准配置。
- 楼梯、门窗、大样排版等跨项目方案库。
- 项目配置和图框模板。
- 建筑设计说明项目文件及其显式历史版本。
- 用户为项目明确启用同步的 DWG 和其他项目文件。

### 3.2 默认排除

- `Logs`、`Temp`、输出 PDF、预览缓存和可重新生成的裁切缓存。
- DLL、EXE、PDB、模块 ZIP 等程序文件。
- `.dwl`、`.dwl2`、自动保存和临时下载文件。
- 最近打开列表、当前电脑的绝对目录映射。
- OAuth 令牌、设备密钥和其他凭据。

## 4. 同步目录

```text
万落建筑云同步/
├─ 通用配置/
├─ 方案库/
│  ├─ 楼梯/
│  ├─ 门窗/
│  └─ 大样排版/
├─ 图框模板/
├─ 项目/
├─ 冲突文件/
├─ 历史版本/
└─ .wanluo-sync/
```

本地同步状态、上传队列和登录凭据不放在上述共享目录内，而是保存在当前设备的应用数据目录。

## 5. 冲突规则

| 本地 | 云端 | 处理 |
|---|---|---|
| 已修改 | 未修改 | 上传 |
| 未修改 | 已修改 | 备份本地后下载 |
| 内容相同 | 任意 | 不处理 |
| 两边均修改且内容不同 | 冲突 | 两份都保留并提示用户 |
| 一边删除、另一边未修改 | 删除 | 移入回收/历史区 |
| 一边删除、另一边修改 | 冲突 | 保留修改版本和删除记录 |

初版不自动合并 JSON。后续只有在具备领域级合并规则和测试时，才允许对特定配置做结构化合并。

## 6. 保存与上传流程

1. 原业务文件完成原子保存。
2. 写入本地变更日志并立即进入队列。
3. 合并连续 2～3 秒内的重复文件事件。
4. 确认文件长度和修改时间稳定，并且可安全读取。
5. 计算 SHA-256，内容未变化则结束。
6. 建立本地历史快照。
7. 上传临时对象，校验后替换云端正式对象。
8. 更新本机同步基线和状态。

DWG 只在 `SAVE`、`QSAVE` 或 `SAVEAS` 成功结束后加入队列。远端 DWG 更新若对应图纸仍打开，则仅下载到待应用区。

## 7. 备份策略

- 本地覆盖前备份。
- 每个文件默认保留最近 20 个版本、最长 30 天。
- 云端删除进入历史区，默认 30 天后才可清理。
- 恢复历史版本前再次保存当前版本，确保恢复操作可撤销。

## 8. 115 接入

1. 完成 115 开发者认证并创建应用。
2. 仅使用官方 OAuth 和文件接口。
3. 用户通过官方授权页登录，插件不接触账号密码。
4. Token 使用 Windows 凭据管理器或 DPAPI 保存，不进入同步目录。
5. 实现上传、下载、列表、移动、删除、限流重试和令牌刷新。
6. 115 暂不可用时，本地同步文件夹模式仍可独立工作。

## 9. 实施阶段

### 阶段 0：恢复基线

- 保存本计划并记录稳定 Git 提交。
- 保留现有便携版安装包和用户数据迁移路径。
- 所有新功能均由 `Enabled` 开关控制，默认关闭。

### 阶段 1：统一同步清单

- 建立同步配置模型、数据源清单和排除规则。
- 为分散在 AppData 与便携版目录的数据建立稳定逻辑路径。
- 将机器绝对路径转换为每台设备单独维护的目录映射。

### 阶段 2：本地同步引擎

- 文件监控、SHA-256、持久队列和重试。
- 临时下载、原子替换、本地历史和冲突副本。
- 支持手动“立即同步”和后台增量同步。

### 阶段 3：本地同步文件夹模式

- 设置界面、目录选择、设备名称和同步范围。
- 配置、方案库、图框模板与项目参数跨设备验证。

### 阶段 4：项目文件与 DWG

- 接入项目保存事件和 AutoCAD 保存完成事件。
- 实现占用检测、待应用区、大文件进度与失败重试。

### 阶段 5：115 官方适配器

- OAuth、凭据安全、文件接口和断点/分片上传。
- 适配官方限流、接口变更和授权失效。

### 阶段 6：同步中心

- 队列、状态、冲突解决、历史版本和设备管理界面。
- 提供诊断日志，但日志本身不参与同步。

### 阶段 7：验收

- 两机轮流编辑、离线同时编辑、删除/修改冲突。
- 保存或下载时断电、断网、磁盘不足和云端损坏。
- 打开的 DWG 收到远端更新、超大 DWG、中文与长路径。
- 登录过期、恢复历史后继续同步、完全关闭同步。

## 10. 交付顺序

- V1：配置、方案库、图框和项目参数的本地文件夹同步。
- V2：DWG、冲突中心和历史恢复。
- V3：115 账号直连和云端适配器。

每个版本单独提交、测试和部署；任何阶段出现问题都可以回到上一稳定提交。
