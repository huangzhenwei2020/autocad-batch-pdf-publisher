**最新用户约定：CAD 入库平面，就已经同时进入三维图库；同一资源一一对应。CAD 能直接插入，三维只补充模型文件。正常流程不能让用户导出、再导入平面、重复建库。**

当前为 **1.5.6**。同机共享图库、原生 CAD 块插入、GLB 静态模型配对已实现并覆盖原安装，自测通过。外部模型正式放入建筑项目、可变尺寸、部件开闭、家具实例和完整材质尚未完成。旧参数门窗继续兼容。

**最新规划约定：原有门继续作为“建筑门”；本轮图库门按“装修门”发展，覆盖常见开启机构、扇组合、门套和五金。装修门关联同一建筑洞口／实例，不重复切墙或统计。资源入库先用名称和参考规格，项目编号在选定类型及尺寸后确定。**

**R0 首批已实现、通过验证并覆盖原安装（2026-10-07 20:34）：** 装修门资源编号可留空；CAD 平面按门套、主／副扇、把手、五金、固定板及开启示意标注，当前部件名称和实际几何高亮始终可见。三维预载同一条 CAD 记录，多个 GLB 节点可以合并为一个部件，整组关联已标注的 CAD 部件，草稿与发布保留稳定部件身份。现阶段仍为固定规格／静态资源；门型选项只记录组合分类，不表示各机构的尺寸及运动已实现。R1 建筑实例关联／放置、尺寸解算及开闭仍待开发。详见 [R0 验收](reviews/装修门部件入库-R0-2026-10-07.md)。
