# CAD WinForms UI 实现标准

本文档同时约束设计稿和 AutoCAD 内嵌 WinForms 界面。新增或改造窗口时，先按本文档核对设计稿，再实现并逐项检查运行界面；图片生成结果不能代替尺寸和交互规范。

## 0. 设计顺序

- 先列出现有功能和状态，设计稿必须给每项功能明确的位置；不能为了画面整齐删掉操作。
- 先确定窗口在设计尺寸与最小尺寸下的卡片、控件和滚动范围，再绘制视觉稿。
- 设计稿通过下文的等高、对齐、间距、滚动条检查后，才作为实现依据。生成图片中的错误文字、尺寸和控件形状不自动成为需求。
- 设计稿确定后，记录窗口宽高比、左右栏宽度占比、标题栏与卡片高度、主要对齐线和选中态；实现时用相同或等比例的窗口截图逐项对照。局部无法对齐时先调整整体比例和网格，不靠给单个控件叠加偏移修补。
- 每次只改一个窗口，完成后核对实际运行画面与通过的设计稿；发现偏差先修正，再开始下一个窗口。
- 批准的设计稿是布局验收基准，不是配色参考。用相同 DPI、相同窗口尺寸并排比对实际 CAD 截图；逐项记录标题、页签、卡片、分栏线、控件和底部操作的边界坐标，不能仅凭“看起来接近”宣布完成。设计稿中与本标准冲突的尺寸，先向用户明确确认，不能自行选择有利于实现的一边。

## 1. 基础尺寸

- 所有常规交互控件的外框设计高度统一为 `36 px`（96 DPI 逻辑尺寸）：文字按钮、图标按钮、搜索框、文字和数字输入框、只读与可输入下拉框、目录选择框、数字步进框、颜色块。图标按钮和颜色块通常为 `36 × 36 px`。
- 同一行控件必须使用相同的上边距、外框高度和垂直中心线；标签与控件按垂直中心线对齐。不能依靠字体的 `PreferredHeight` 或按钮的 `AutoSize` 决定外框高度。
- 开关的可点击区域与同排控件对齐并至少高 `36 px`，开关轨道可以比点击区域矮；表格行、列表项和标题不受 `36 px` 控件高度约束。
- 同排控件之间使用统一水平间距，外框和文字不得被相邻控件、卡片边缘或滚动条截断；窗口变窄时整组换行或在所属区域内滚动，不单独缩矮某个控件。
- 固定分组和需要对齐右边界的操作使用 `TableLayoutPanel` 等明确列宽的网格；`FlowLayoutPanel` 仅用于允许自然换行的工具组。不能让某个 `DockStyle.Fill` 按钮吃掉剩余行高，导致它比同排控件高。
- DPI 缩放交给 `DpiAwareForm` 和 WinForms 布局系统；自绘控件内部根据 `ClientSize` 和当前 `Font.Height` 重新计算文字位置。
- 确实需要紧凑工具条时，先为该工具条定义一个共用高度；不得在同一行混用紧凑和常规高度。

## 2. 按钮

- 功能按钮使用自绘圆角按钮，不启用系统视觉样式。
- 图标、文字、悬停、按下、禁用和焦点状态均由同一控件绘制。
- 不在 `Paint` 中创建长期对象；需要复用的画笔或图标应缓存或及时释放。
- 同一行按钮通过统一工厂创建，禁止在页面代码中分别设置高度和内边距。
- 页签式双按钮属于一个连续控件组：两半等高、无中间空隙，共享一条中心分隔线；仅最左和最右的外侧角为圆角，连接处是直角。页签外边界须与下方主卡片左右边界精确对齐，不能用各自的 `Margin` 凑视觉效果。
- 图标与文字按一个整体居中，图标不得挤压文字或让按钮高度变化；同组操作按钮应等宽、同顶线、同底线，标题图标和功能图标使用同一套颜色与线宽。

## 3. 文字输入框

- 原生 `TextBox` 只负责文字编辑、光标、选择和输入法，不负责外框。
- 外层使用统一的自绘宿主绘制背景、圆角和焦点边框。
- 内部编辑区使用 `(容器高度 - 文字编辑区高度) / 2` 垂直居中，禁止使用 `+3`、`+4` 等按截图试出的固定偏移。
- 占位文字由宿主中的标签绘制，不能依赖不同 Windows 版本表现不一致的原生 Cue Banner。
- 焦点进入和离开时要验证占位文字状态。`TextBox.Leave` 触发时 `Focused` 可能尚未变为 `false`；依赖焦点状态的显示更新应在焦点切换完成后执行，并在实际屏幕截图中确认。
- 内部编辑区必须与圆角边框至少保持 `8 px` 水平间距，不能覆盖抗锯齿边线。

## 4. 下拉框

- 深色自绘界面禁止使用原生 `ComboBox` 再覆盖绘制。原生控件会自行重算高度并在悬停时先绘制一次，容易造成闪烁、错位和文字不居中。
- 统一使用自绘下拉控件：外框、输入区、箭头和弹出列表全部由应用控制。
- 可输入模式仍使用无边框 `TextBox` 提供输入法和文本编辑能力；只读模式点击整个控件打开列表。
- 弹出列表使用双缓冲自绘列表，支持鼠标、滚轮、上下键和回车选择。
- 弹层关闭事件先清空当前引用，等鼠标/键盘事件栈退出后再释放弹层及其宿主控件；不要在 `Closed`、`MouseDown` 或选中回调的同步调用链中立即 `Dispose()`。连续点击开合、点外部关闭后再打开、选择后立即再次打开都要测试，避免访问已释放的 `ToolStripDropDown`。
- 数据源显示字段、选中项、选中索引和文本变化必须保持与原 `ComboBox` 等价的事件语义。

## 5. 列表和卡片

- `ListBox`、`CheckedListBox` 等原生列表只负责行交互，外层由统一圆角宿主绘制边框。
- 自绘选中行按批准设计稿保留完整的颜色、圆角、内边距和左侧标记，不把“蓝色高亮”简化为默认系统选中态。`DrawItem` 只能清理并绘制当前 `e.Bounds`；不要调用会擦除整个列表表面的 `Graphics.Clear`，否则滚动或选择后其他行会消失。
- 列表与宿主边框至少间隔 `3 px`，防止子窗口覆盖圆角边线。
- 不要同时给宿主设置圆角 `Region` 并沿 Region 边缘画抗锯齿线；裁剪会切断半个像素的边框。
- 页面区域使用独立卡片。需要拖动调整大小时保留 `SplitContainer`，但不绘制多余的旧式分隔横杠。
- 同一级大卡片之间的间距与大卡片到窗口内容边缘的间距一致；卡片内使用统一内边距，不在卡片中再套装饰性卡片。
- 大卡片不得贴着窗口的 `1 px` 视觉边框。先定义统一的内容外边距，再用同一网格放置页签和卡片；检查左右与底部留白，以及页签到卡片的垂直距离。
- 内容外边距以设计稿的紧凑密度为准，不因修复对齐而任意加宽卡片、按钮和窗口边缘之间的空白；标题、页签、卡片和底栏的高度应作为一套整体尺寸核算。
- 标题是文本，不画成按钮或单独铺强调色底纹；操作按钮通过位置、颜色和图标区分主次。

## 6. 开关

- 二元设置统一使用启动器同款自绘开关，不混用系统复选框。
- 标签位于开关左侧，开关轨道和圆点保持固定尺寸；禁用状态必须可辨认。

## 7. 表格和滚动

- 大表格使用双缓冲，关闭原生滚动条后只能保留一套自绘滚动条，不能再给隐藏的原生滚动条安装重绘钩子。
- 表格选择列禁止使用 `DataGridViewComboBoxColumn`；使用文本单元格、自绘箭头和统一的自绘选择弹层，避免进入编辑状态时闪出系统下拉框。
- 鼠标滚轮必须显式改变首个可见行；每个滚轮刻度建议移动当前可见行数的约三分之一，形成接近浏览器的连续翻页体验。
- 拖动滑块时，值没有变化就不触发表格刷新；不要在每个鼠标移动消息中重复设置同一个滚动位置。
- 滚动条可见部分只有一条细路径线和一个圆头胶囊滑块。路径线建议 `1–2 px`，滑块保持固定视觉宽度；不要绘制整条深灰色背景、宽轨道、槽形底板、阴影或额外边框。
- 滚动条的鼠标命中区可以比路径线宽，但命中区必须与所在卡片背景完全一致；它应位于卡片内部，不能压住内容、圆角边框或相邻卡片。无须滚动时隐藏路径线和滑块。
- 纵向、横向滚动条以及列表、表格、设置区都遵守同一视觉规则。滚轮、拖动滑块、点击路径和键盘滚动必须同步到实际内容位置。
- 数据刷新、排序和预览生成不得放在滚轮或滑块的同步事件中。

## 8. 窗口和页面切换

- 所有 CAD 工具窗口的标题栏统一使用 `CadBrandIcon`：无边框自绘标题栏使用 `CreateTitleMark()`，系统标题栏由 `DpiAwareForm` 设置同源窗口图标；不再在各窗口硬编码字母方块或混用默认图标。
- 标识是共享品牌资产，不是每个窗口单独绘制的装饰；在标题栏小尺寸和系统图标尺寸分别验证辨识度，并确保图标可随 DPI 缩放。
- 无边框窗口视觉边框保持 `1 px`。缩放命中由 `WM_NCHITTEST` 在客户区边缘统一处理，不添加会产生额外非客户区条带的 `WS_THICKFRAME`，也不能靠增加可见 `Padding` 制造粗边框。
- 无边框窗口应给自身保留至少约 `6 px` 的四边命中带，不让铺满窗口的子控件截走边缘鼠标消息；命中带与画布同色，边框另绘 `1 px`，不能把整条命中带涂成边框色。
- 最小化、最大化和关闭按钮使用自绘窗口按钮，不让系统按钮主题混入自定义标题栏。
- 同一容器中的页签页面必须互斥设置 `Visible`，不能让两页同时可见后只调用 `BringToFront`。
- 批量显示或切换控件前后使用 `SuspendLayout` / `ResumeLayout`，防止启动时显示半成品布局。
- 窗口只能由一个集中入口创建并缓存；关闭后清空缓存，避免旧窗口与新窗口叠加。
- 固定行高相加后必须留出正文控件的实际最小高度。窗口被 `DpiAwareForm` 按显示器工作区缩小时，输入、下拉、颜色和操作按钮仍须完整可见；空间确实不足时，在所属区域使用统一的细线加胶囊滚动条，不能裁掉最后一行。
- 核算固定行高时必须计入每层 WinForms 子控件的默认 `Margin`。例如 26px 标签加 36px 色块的 62px 行，宿主容器若保留默认上下边距，色块就会被裁切；紧排容器须显式清零边距并在设计尺寸、最小尺寸核对完整外框。
- 同一行的多个输入控件必须按可用宽度和当前 DPI 核算文字区、箭头区、内边距与边框；短数字下拉框不得只给文字宽度。横向空间不足时改为两行排布，不缩窄到箭头或圆角边线被邻项覆盖。

## 9. 性能规则

- 高频消息（鼠标移动、滚轮、滚动、调整大小）中禁止读取文件、扫描 CAD、生成 PDF 或创建大量 GDI 对象。
- 自绘控件启用 `UserPaint`、`AllPaintingInWmPaint`、`OptimizedDoubleBuffer` 和按需 `ResizeRedraw`。
- 不在 `WM_PAINT` 后再次取得窗口 DC 覆盖绘制原生控件；这会造成双重绘制和闪烁。
- 只使发生变化的控件失效，避免 `Invalidate(true)` 重画整棵控件树。
- 窗口连续缩放由布局系统自然重排；不要在每次 `SizeChanged` 后排队调用整页 `Refresh()`，也不要给已双缓冲的顶层窗口再开启无必要的全窗 `ResizeRedraw`。
- 预览按用户操作生成并缓存；切换图纸只读取缓存，不自动重新打印。

## 10. 发布前检查

1. 在 100%、125%、150% DPI 下检查按钮、图标按钮、颜色块、搜索框、输入框和下拉框是否等高、同顶线、同中心线。
2. 输入中文、英文和数字，检查文字、光标和选择背景是否垂直居中。
3. 快速经过所有下拉框，确认没有白色闪屏或边框闪烁。
4. 在列表、表格和设置区检查滚动条：只看见细路径线和胶囊滑块，没有深色长方形轨道；滚轮、拖动滑块、点击路径和键盘滚动的位置同步且无明显停顿。
5. 在设计尺寸、窗口最小尺寸和较矮工作区检查大卡片间距与外边距一致，页面密度不过分松散；所有参数、颜色块和操作按钮可见或可通过所属区域滚动到达，卡片圆角和边框不被子控件盖住。
6. 拖动窗口四边和四角，确认缩放命中稳定且视觉边框仍为 `1 px`。
7. 连续切换预览与输出设置，确认不存在页面重叠或首次打开闪出旧布局。
8. 对照批准设计稿检查实际屏幕截图，而不只检查控件树或 `DrawToBitmap`；后者可能漏画原生子控件、焦点提示或窗口阴影。至少检查设计尺寸和最小尺寸，确认所有行仍可读取、选中态完整、内部滚动可到达最后一个操作。
   对所有下拉框特别检查右端箭头和圆角边线完整可见；短数字框至少同时容纳最长预设值、箭头、文字内边距和边框，不能让百分比列宽或相邻控件裁掉右端。
   检查页签是否连成一组、连接处是否方角、页签与主卡片左右边界是否同线，以及页签、普通按钮、输入框、下拉框的实际外框高度是否符合当前窗口的统一尺寸。
9. 用独立窗体冒烟测试验证搜索过滤与清空、所有常规控件 `36 px` 高度、最小尺寸下滚动到底以及标题图标；编译失败后不得继续运行磁盘上的旧测试程序并误报通过。
10. 分别编译 R24（.NET Framework）和 R25（.NET 8），要求 `0` 警告、`0` 错误。环境缺少某版本 SDK 时明确记录未验证，不用另一版本 DLL 代替。
11. 覆盖 CAD 加载的 DLL 前先请用户确认关闭 CAD，再检查 `acad.exe` 已退出；只复制已编译且与目标版本匹配的文件，并用哈希核对源文件与每个部署位置。未得到确认时保留构建产物、不覆盖安装目录。

## 11. 共享实现

- 通用卡片、圆角按钮、文字输入宿主、列表宿主和开关控件集中在 `BatchPdfPublisher/Infrastructure/CadDialogTheme.cs`。
- 标题栏和系统窗口图标集中在 `BatchPdfPublisher/Infrastructure/CadBrandIcon.cs`；新窗口直接复用，不复制位图、字母标记或另一套画法。
- 自绘可输入下拉框当前由 `PublisherForm.ThemedComboBox` 提供，批量发布、项目管理相关入口和目录插入窗口必须使用这一实现，禁止重新引入原生 `ComboBox`。
- 新窗口优先组合共享控件；确有新交互状态时先扩展共享控件，再在页面中使用，不能在页面代码中复制一套颜色、圆角和高度常量。
- 应用界面不直接显示原生按钮、复选框、下拉框、列表边框或滚动条。无边框 `TextBox` 可以保留为输入法和光标内核，但必须放入自绘宿主；系统文件夹选择器和消息框属于操作系统对话框，不计入应用界面控件。
