# 图像转 CAD 实现说明

## 当前版本

产品版本：1.4.0。

固定命令为 `LINEVISION`，默认快捷键为 `TXZCAD`。窗口为模型窗口，打开后仍可切换视图和操作 CAD。

已实现：

- PNG、JPG、JPEG、BMP、TIFF 本地读取；
- 整图或图片内矩形裁剪；
- Otsu 自动阈值及手工阈值；
- 孤立噪点过滤和小断口连接；
- 水平线、垂直线和 45 度斜线检测；
- 任意角度直线检测；用户可设置横竖吸附角度，范围外保持原始角度；
- 可将无分支、端点可靠相接的线链重构为原生 CAD `Polyline`，可关闭；
- 新增独立矢量化 Worker，AutoCAD 进程不加载第三方图像原生库；
- 建筑中心线模式采用 Zhang-Suen 骨架化与拓扑折线追踪；
- 保留轮廓模式采用 VTracer 1.0.0-alpha.4；
- 混合模式同时返回中心线和 VTracer 轮廓，轮廓默认作为未勾选候选；
- 保守识别闭合圆形，并生成原生 CAD `Circle`；
- 保守识别连续圆弧，并生成原生 CAD `Arc`；
- 坐标聚类、共线合并及最短线过滤；
- 原图、黑白预处理和彩色结果切换；
- 逐项启用/禁用、全选和全不选；
- 两点已知距离标定；
- 指定插入点并按方向分层生成原生 CAD 直线；
- 通过独立本地进程调用 Windows 中文/英文 OCR，不向 AutoCAD 进程加载 OCR 组件；
- OCR 结果缓存、文字区域遮罩、逐项启用与文字校正；
- 在 `LV-TEXT` 图层生成可编辑 CAD 原生文字；
- 圆与圆弧统一放在 `LV-CURVE` 图层；
- OCR 不可用或失败时自动降级为纯线稿识别；
- 单事务写入和失败回滚；
- R24 与 R25 双版本构建；
- 不依赖 AutoCAD 的算法测试。

## 当前限制

- 当前识别器面向清晰建筑线稿、扫描图和截图，不负责照片透视矫正。
- 斜线首版识别 45 度方向，任意角度 LSD/Hough 融合将在图像引擎升级时加入。
- Windows OCR 不提供逐字置信度，当前按文字行显示统一的可用置信度，重要文字仍应在右侧文字页校正。
- 圆弧、尺寸及墙门窗语义对象属于后续阶段。
- 新中心线内核解决笔画中心追踪，但墙、门、窗等建筑语义仍需后续分类。

## 第三方矢量内核

- VTracer：<https://github.com/visioncortex/vtracer>，MIT 许可，作为独立命令行程序运行。
- Skeleton Tracing 算法参考：<https://github.com/LingDong-/skeleton-tracing>，MIT 许可。
- 两份许可证随发布文件放置，VTracer 和矢量 Worker 均不会加载进 AutoCAD 进程。

## 后续 OCR 接入原则

OCR 使用独立本地进程，通过 JSON 文件返回文字、矩形、方向和置信度。OCR 失败时只降级为线稿识别，不允许 OCR 组件直接加载到 AutoCAD。
