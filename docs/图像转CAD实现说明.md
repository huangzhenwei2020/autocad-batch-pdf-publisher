# 图像转 CAD 实现说明

## 当前版本

产品版本：1.3.0。

固定命令为 `LINEVISION`，默认快捷键为 `TXZCAD`。窗口为模型窗口，打开后仍可切换视图和操作 CAD。

已实现：

- PNG、JPG、JPEG、BMP、TIFF 本地读取；
- 整图或图片内矩形裁剪；
- Otsu 自动阈值及手工阈值；
- 孤立噪点过滤和小断口连接；
- 水平线、垂直线和 45 度斜线检测；
- 坐标聚类、共线合并及最短线过滤；
- 原图、黑白预处理和彩色结果切换；
- 逐项启用/禁用、全选和全不选；
- 两点已知距离标定；
- 指定插入点并按方向分层生成原生 CAD 直线；
- 单事务写入和失败回滚；
- R24 与 R25 双版本构建；
- 不依赖 AutoCAD 的算法测试。

## 当前限制

- 当前识别器面向清晰建筑线稿、扫描图和截图，不负责照片透视矫正。
- 斜线首版识别 45 度方向，任意角度 LSD/Hough 融合将在图像引擎升级时加入。
- OCR 接口已与 CAD 写入分开，但 PaddleOCR 本地 Worker 和模型尚未随本版发布，因此当前只转换线稿。界面会明确提示这一状态。
- 圆弧、原生文字、尺寸及墙门窗语义对象属于后续阶段。

## 后续 OCR 接入原则

OCR 必须使用独立本地进程，通过结构化消息返回文字、多边形、方向和置信度。OCR 失败时只降级为线稿识别，不允许原生 OCR DLL 直接加载到 AutoCAD，也不允许低置信度文字静默生成。
