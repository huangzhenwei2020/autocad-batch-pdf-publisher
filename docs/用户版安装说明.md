# 万落建筑工具用户版安装说明

## 适用版本

本安装包适用于 Windows 10/11，以及 AutoCAD 2021–2024（含基于这些版本 AutoCAD 运行的兼容天正产品）。

## 首次使用

1. 关闭所有 AutoCAD 和天正窗口。
2. 将压缩包完整解压到一个固定文件夹。不要直接在压缩包内运行，也不要只复制单个 EXE 或 DLL。
3. 双击 `万落建筑工具启动器.exe`。
4. 在启动器中选择需要使用的 AutoCAD 或“天正 + AutoCAD”组合，然后启动或加载插件。
5. AutoCAD 打开后，使用插件工具栏，或输入对应命令开始使用。

默认是便携运行，不会把整套程序复制到系统目录。以后移动了安装文件夹，需要重新运行一次启动器。若选择“永久安装”，启动器会为所选 AutoCAD 注册自动加载组件。

## 更新版本

1. 关闭所有 AutoCAD 和天正窗口。
2. 备份自己需要保留的工程文件；用户设置和工程参数通常保存在当前 Windows 用户的应用数据目录，不在本安装包内。
3. 删除旧程序文件夹，完整解压新版本。
4. 重新运行新文件夹中的 `万落建筑工具启动器.exe`。

不要把新旧版本文件混在同一个目录，也不要用旧 DLL 覆盖新 DLL。

## 云同步

百度网盘直连不要求安装百度网盘客户端。首次使用时，在插件“云同步”窗口点击连接百度网盘，在浏览器中完成授权后返回 AutoCAD。授权信息只保存在当前 Windows 用户的本机加密存储中，不包含在安装包内。

插件设置、项目登记、图框和方案库作为一个“系统文件包”同步，可在云同步设置中指定发生变动后等待多少分钟再打包上传；点击“立即同步”会立即重新打包。项目 DWG 和配套资料仍按单个工作文件同步。在“同步中心 → 工作文件”中双击文件，可查看该文件保留的历史版本并选择恢复，恢复前当前版本仍会自动备份。

## 常见问题

- 启动器没有检测到 AutoCAD：确认已安装 AutoCAD 2021–2024，并至少正常启动过一次。
- Windows 阻止运行：右键压缩包或启动器查看“属性”；若文件来自可信发布来源，可解除锁定后再运行。
- 插件没有加载：先关闭全部 AutoCAD/天正进程，再以当前 Windows 用户重新运行启动器。
- 天正图纸显示异常：请从对应天正产品启动 AutoCAD，不要用普通 AutoCAD 直接处理依赖天正对象的图纸。
- 需要排查问题时，可把启动器或插件界面显示的错误文字、复现步骤和截图发给维护人员。

## 文件完整性

发布包根目录的 `build-info.json` 记录了构建提交和程序 SHA-256。交付时另附整个 ZIP 文件的 SHA-256，可用来确认下载或复制过程中没有损坏。
