# 启动器界面与缩放

依据 `BatchPdfPublisherLauncher/Assets/approved-design.png` 实现左右布局、工作环境卡片、最近项目入口、蓝色 W 程序图标。右上角使用独立太阳 / 月亮按钮选择日间或夜间，保存到用户通用设置的 `launcher-theme.txt`。最近项目显示真实登记项目，按现有项目文件夹修改时间排序；不会显示设计图中的虚构项目和日期。

项目管理沿用共享业务服务，保留新建、文件改名、项目改名、移除、备份和 CAD 运行锁；使用相同侧栏与配色。

## 适配

- 自适应表格、文字换行、可滚动内容；高缩放时不缩小字体硬塞内容。
- 主导航始终保留在左侧，项目列表和详情始终左右排列，不再使用字体高度触发上下布局。小窗口适当压缩列宽，字段允许换行。项目管理去掉整页滚动，仅列表和编辑表单内部滚动。
- 窗口根据所在显示器工作区限制大小；支持最大化和跨屏 DPI 改变后重新布局。
- `.NET Framework 4.8` 通过 `app.config` 启用 `PerMonitorV2`。发布时必须保留启动器旁的 `万落建筑工具启动器.exe.config`。
- 依据：[Microsoft WinForms 高 DPI 文档](https://learn.microsoft.com/en-us/dotnet/desktop/winforms/high-dpi-support-in-windows-forms)。

## Ribbon

18 个功能保留原有命令映射。图标用 128 像素资源在 32 DIP 区域完整显示，名称和蓝色圆角快捷键标签由 WPF 控件绘制，可随 DPI 缩放。快捷键读取用户设置，配色跟随 CAD 的 `COLORTHEME`，改变设置或主题时刷新。仍保留 16 / 32 像素图标资产，避免再次出现原生图像容器只显示图标角落的问题。

使用本机 R24 和官方 NuGet R25 API 编译验证的 Ribbon 内容宿主；Autodesk 对自定义 Ribbon 内容控件的说明见 [RibbonItemControl](https://help.autodesk.com/cloudhelp/2019/ENU/OARX-ManagedRefGuide/files/OREFNET-Autodesk_Windows_RibbonItemControl.html)。

## 验证范围与限制

- 启动器、R24、R25 编译通过；18 个 Ribbon 按钮的命令和自定义快捷键构造检查通过。
- 项目管理测试使用隔离配置，验证项目和文件装载、CAD 运行锁、双色切换及主题保存。
- 1120 / 760 / 480 像素窗口宽度，以及 100%、125%、150%、175%、200%、250%、300% 控件与字体放大压力检查。
- 使用隐藏窗体的 DrawToBitmap 和 WPF 渲染检查真实控件。测试用窗口边框和标题图标属于测试进程，正式 EXE 使用新的 W 图标。
- 放大压力检查不等于更改实际 Windows 显示设置；尚未验证混合 DPI 多屏拖动，也未在本轮启动 CAD 验收 Ribbon 宿主最终显示。不同 Windows 原生边框及滚动条会有差异，不声称所有显示器或像素级一致。

测试入口：`BatchPdfPublisher.Tests/BatchPdfPublisher.Launcher.Tests.csproj`。图标生成记录见 `BatchPdfPublisherLauncher/Assets/README.md`。

## 2026-09-19 布局与拖动修正

- 日月按钮在两个主窗口中统一置于右上角；项目大小、状态、修改时间列按当前字体和数据测量，窗口尺寸改变时复用测量结果。
- 拖动窗口边框期间暂停密集的嵌套布局；连续拖动结束、或停顿 120 ms 后统一排版，释放鼠标立即完成最后一次布局。不是只优化滚动条。
- 新增左栏可见性、左右排列、禁止整页嵌套滚动和连续 80 次改变窗口尺寸的回归检查。1001 条文件记录的列表滚动不触发外层页面重排。
- 使用与正式启动器相同的 .NET Framework 4.8、manifest 和配置运行额外验证：本机测试进程 DPI 为 96；80 次连续尺寸变化，两种窗口都合并为 1 次布局。仍不代表用户所有 DPI/显示器环境的人工拖动体验已验收。

## 圆角、对齐与主题细节

- 品牌区和右侧页面标题采用相同的 52 DIP 高度与 24 DIP 上边距；导航紧接品牌区，移除导航跟随右侧卡片产生的大间隔。我的项目移入侧栏，右侧三个等宽标签与详情卡片使用完整余下宽度。小高度或大字号时侧栏可独立滚动，项目列表不会压成零高度。
- 下拉框使用完整客户区和圆角窗口区域，不再叠加原生非客户区的矩形边框，保留原生键盘选择和下拉行为。
- 项目列表、文件表格和输入框使用圆角外框。表头填满可用宽度，避免未覆盖的白色尾部。
- 自定义绘制原生滚动条外观，保留 Windows 的拖动、鼠标滚轮、键盘滚动和可访问性。横竖滚动条均有深色像素检查；位置和滑块尺寸读取 [SCROLLBARINFO](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-scrollbarinfo)。
- 两个主窗口使用自绘双色标题栏：左段与侧栏同色，右段与内容同色，分界贯穿整个窗口。保留最小化、最大化、还原、关闭、标题拖动和边缘调整尺寸，最大化按所在屏幕工作区计算。其他小对话框继续使用系统标题栏。
- 滚动条关闭原生主题动画，在鼠标悬停、移出及原生拖动循环期间补绘，避免系统白色悬停外观覆盖。增加两方向悬停/移出后的像素检查；原生输入行为不改写。
- 本次额外验证：品牌与标题同高对齐、项目列表侧栏归属、详情区宽度、窗口左右角缩放命中、标题栏最大化/还原和任务栏工作区边界。混合 DPI 多屏移动仍需真实设备验收。

## 实际拖动回归（2026-09-19）

- 移除自绘标题栏上误加的系统厚边框样式，避免窗口激活、移动或从模态项目管理返回时重新画出系统边框。
- 窗体保留 6 DIP 的同色拉伸区域，内部控件不覆盖该区域；八个方向的边缘命中由窗体统一处理。窗口尺寸变化后同步重绘两栏接缝。
- 原生滚动条在尺寸/位置更新完成后排队补绘，防止拉伸后新出现的滚动条恢复白色。
- 在 CAD COM 探测前尝试初始化 PerMonitorV2，保留 .NET 4.8 配置兼容路径。
- 使用 computer-use 实际操作完整启动器：上下左右边缘拉伸、向外增加高度、标题栏移动、最大化/还原、进入项目管理、项目管理拉伸与关闭返回。确认标题位置保持稳定，未再出现原先的白色外框。
- 自动回归同时检查原生样式没有系统标题/厚边框、重复激活/移动后窗口与客户区等大、标题位置稳定，以及内部控件不挡住边缘。
- 本轮并未更改用户 Windows 缩放设置；字体放大压力检查仍为模拟，不替代所有显示器组合的实机测试。
