## 一、以前 vs 现在

| | 以前 | 现在 |
|---|---|---|
| 打开建模程序 | 自己去文件夹里找 `万落建筑模型.exe` 双击，程序默认打开**样例**，还要手选项目文件夹与模型名称 | CAD 里执行 **`JZMX`（建筑模型）**：自动带着**当前项目的文件夹与模型名称**启动，程序直接打开那个模型（还没有就按名字新建） |
| 落图 | `LTTZ` 弹文件对话框，自己在 `views\` 里翻 json（还要认得哪个是哪个） | `LTTZ` **先列出本项目已生成的图纸/视图**（带类型、图名、修改时间），**输入序号就行**；`0` 才走文件浏览 |

## 二、这一轮做了什么

1. **建模程序新增启动参数**：`--project "<项目文件夹>" --model "<模型名称>"`（可与其它参数同时给）。
   CAD 侧就是这么把当前项目交给它的；不给就是原来的样例行为。
2. **CAD 新增命令 `JZMX`（功能简称「建筑模型」）**：
   - 取当前激活项目 → 模型目录 `StudioLaunch.FindModelFolder(...)`；
   - 找程序（按顺序）：**上次记住的路径**（存在 `%APPDATA%\万落建筑工具\建筑模型程序路径.txt`）
     → **发布目录候选** `<发布根>\建筑模型\万落建筑模型.exe`（插件 DLL 在 `<发布根>\CadApi\R24\`，所以从 DLL 位置往上找两级）
     → 都没有就弹一次文件对话框让你选，**选完记住**；
   - 启动后命令行提示："画完点「生成全部视图」，回到 CAD 执行 `LTTZ` —— 会先列出本项目的图纸/视图，挑序号就行。"
3. **`LTTZ` 改成"先列清单再选序号"**：清单按**图纸 → 平面 → 立面 → 剖面 → 门窗表**排序，
   每行显示 `[图纸] 建施-01 一层 平面图　09-26 15:40`；没有项目/没有视图时自动退回文件浏览。
4. **发布流程带上建模程序**：`Build-Release.ps1` 现在会把建模程序编到
   **`dist\WanLuoArchitectureTools\建筑模型\`**（含 exe/dll/deps/runtimeconfig 与一份 `运行说明.txt`），
   并写进发布清单 `StudioSha256`。这样 CAD 侧"发布目录候选"才真的找得到它。
5. **功能清单**：新增第 22 个功能「建筑模型」（`JZMX`），构建脚本的四字简称校验、图层命令校验全部通过。

## 三、核实过的事实

**单元测试**（新增第 11 组"启动与取件"，纯逻辑、不依赖 CAD）：

```
启动与取件：参数、发布目录候选、模型目录定位、视图清单（跳过坏文件）都符合预期
PASS 立面门窗：… / 排版出图 / 启动与取件
```

断言包括：`--project "H:\项目\万落示例" --model "样例-两层小房子"` 的参数拼装（含去尾斜杠、去首尾空格）、
空参数得到空串、只有项目文件夹时不带 `--model`；候选里**跳过不存在的路径**取第一个存在的；
**发布目录候选确实包含 `<发布根>\建筑模型\万落建筑模型.exe`** 且能命中；
模型目录按名称定位、只给项目文件夹且只有一个模型时自动取它、名字不存在返回 null；
视图清单**跳过坏 json**、图纸排最前、每行显示类型与图名。

**启动参数实测**：先 `--generate %TEMP%\WanluoLaunchCheck 住宅楼`，再模拟 CAD 的启动方式：

```
> 万落建筑模型.exe --snapshot-ui out.png --project %TEMP%\WanluoLaunchCheck --model 住宅楼
界面快照：…（预览 63 条线；…；模型 住宅楼）
```

打开的确实是**住宅楼**而不是样例 —— 说明 CAD 传参这条路是通的。

**发布**：`Build-Release.ps1 -Bands R24,R25` exit 0，
发布目录里出现 `建筑模型\万落建筑模型.exe`，功能校验由 21 个变为 **22 个**，
R24 `3FE873EF…` / R25 `01763A25…`。

## 四、需要你在 CAD 里试的两步

1. **`JZMX`**：应弹出建模程序并直接打开当前项目的模型（第一次可能让你指一下 exe 的位置，之后会记住）；
2. 在程序里画/生成 → 回 CAD **`LTTZ`**：命令行先列出本项目的图纸与视图，输入序号 → 点插入点 → 落图完成。

若 `JZMX` 提示"还没有打开/激活项目"，先在启动器里选中一个项目再执行。

## 五、已知边界（下一步）

1. 建模程序还是**独立 exe**（不是启动器里的模块），启动器里暂时看不到它；
2. 落图选清单是**命令行序号**（没做带缩略图的对话框）；
3. 论文"画完直接落图"目前是"回 CAD 敲 `LTTZ`"——**还不能在程序里点一下就推到 CAD**
   （那需要 CAD 侧常驻监听或程序侧调用 CAD；P5 再评估）；
4. 需要目标机装 **.NET 8 桌面运行时**（`运行说明.txt` 里写了下载地址；找不到运行时会双击没反应）。
