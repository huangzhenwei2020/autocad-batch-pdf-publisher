## 一、模型里新增两样数据

```csharp
AxisModel  { Id, Name(轴号), Vertical, Position, ExtentStart, ExtentEnd }   // 整栋通用（不挂楼层）
RoomModel  { Id, StoreyId, Name, Outline[] , AreaSquareMetres（现算） }      // 挂楼层
```

- **轴网**：竖轴标 X（轴号 1、2、3…），横轴标 Y（轴号 A、B、C…，超过 26 个 AA、AB…）；
  **轴号永远跟位置一致**：`PlanEditing.RenumberAxes` 在新增/移动/删除轴线后按位置重排。
- **房间**：闭合轮廓 + 名称，**面积用鞋带公式按轮廓现算**（mm² → m²），不存冗余数据；
  `PlanEditing.ValidateRoom` 拦住少于 3 个点或面积≈0 的坏房间。

## 二、平面图里画出来（`ProjectPlan` 扩展）

| 元素 | 画法 |
|---|---|
| **轴线** | 点划线（`LineType = "CENTER"`，落图后随层的线型就是点划线），两端**轴号圆圈**（新 `ViewCircle` → 落图建成 CAD 的 `Circle`） |
| **房间** | 轮廓细线 + **房间名 + 面积**（居中在形心） |
| **尺寸** | 平面改成**标准三道**：内层洞口定位 → 中层**轴线尺寸**（有轴网时）→ 外层总尺寸；左侧同理 |
| **可点选** | 轴线与房间也进锚点表（`Kind = "axis"/"room"`），所以**平面里点轴线/房间名也能选中** |

干净样例一层平面：线 72（门窗图例 15、轴线 5、房间 8）、文字 19、尺寸 22；
外皮总长 7440 / 总宽 5640（与立面图一致），轴线链正好是开间 3600 + 3600。

## 三、画布新增两个工具

- **「拉轴线」**：两次点击拉出一条轴线，方向取主轴方向（竖着拉就是竖轴）、位置取垂直坐标；
  自动编号（按位置重排）；选中后**只能沿垂直方向拖动**（竖轴改 X、横轴改 Y），属性面板可改轴号/位置/延伸范围。
- **「画房间」**：连续点轮廓，**点回起点或按 Esc 闭合**；自动起名"房间N"，属性面板改名字，
  面积实时现算；选中房间名可**整体拖动**（面积不变）。

## 四、核实过的事实

**单元测试**（第 9 组"平面图"扩写，数值手算核对）：

```
平面图：墙面线在洞口断开、窗 2 条玻璃线、门扇线 + 弧、柱断面、5 条轴线 + 10 个轴号圈、
        2 个房间（起居室 17.34 m²），总长 7440 / 总宽 5640，锚点 11 个
```

断言包括：5 条轴线全为 `CENTER` 线型、x=3600 竖轴与 y=5400 横轴都在、10 个轴号圆圈半径 400、
轴号 1/2/3/A/B 都有文字、房间轮廓 8 条线、面积文字 `17.34 m²`（3360×5160 手算）、
轴线尺寸链含 0→3600 与 3600→7200 且画在中层、洞口定位链各段之和 = 总长 7440。

**交互自检**（把这些工具的真实路径钉住）：

```
PASS 拉轴线：拉 3 条 → 轴号按位置重排 1,2,3；拖轴线只沿垂直方向移动
PASS 画房间：4 点闭合 → 面积 6.00 m²；拖整体移动；拖动中删除不抛异常
PASS 平面交互自检：拖柱 / 拖墙夹点 / 拖洞口 / 拉轴线 / 画房间 —— 目标被删、被撤销、换楼层、宿主墙消失都只取消拖动，不抛异常
```

**预览自检**：9 张视图逐张离屏真画，线/文字/尺寸/圆条数与视图数据完全一致。

## 五、这一轮顺带查出的三个真问题

1. **点划线在极端缩放下卡死**（自检实测卡住）：轴线长到 2e8 像素时 GDI+ 要生成上亿段虚线。
   现在**所有线条先裁到视口**（`DrawGuard.ClipLine`，Liang–Barsky），平面画布与预览统一走它 ——
   这跟上一轮"网格死循环"是同一类问题：**绘制的计算量必须有界**。
2. **锚点没跟着视图归零平移**（`Normalize` 只平移了线/填充/文字/尺寸）：预览点选会按"没平移的位置"命中，
   点到的地方和你看到的窗对不上（立面偏差小、平面偏差上千毫米，正好被这次平面测试抓住）。
3. **X/Y 范围把标注类线算进去了**（标高符号线、图名）导致总长偏大 —— 现在只按"建筑几何"图层取范围。

**发布**：`Build-Release.ps1 -Bands R24,R25` 两个版本都通过；`ViewCircle` 在两个版本都建成 `Circle`。
