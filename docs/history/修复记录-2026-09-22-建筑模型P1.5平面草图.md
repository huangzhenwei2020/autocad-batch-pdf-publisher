**日期**: 2026-09-22
**仓库/分支**: `huangzhenwei2020/autocad-batch-pdf-publisher` → `main`（**仅本地提交，未推送**）
**依据**: [建筑模型与立面剖面生成-开发计划](../建筑模型与立面剖面生成-开发计划.md)（v3.2）§5.0（档 B：程序里也能画）、§6 阶段 P1.5

## 一、这一轮做了什么

在建模程序（`BuildingModelStudio`）里加了**平面草图编辑器**：不用开 CAD 就能把平面画出来，
而且**画出来的就是模型**——不需要"提取图纸再反推"。

| 能力 | 说明 |
|---|---|
| **画墙** | 点两下画一道（可连续画下一道）；厚度取面板默认值、高度 0 = 用层高；自动正交/端点/中点/轴网捕捉；过短或无效的墙会在状态栏提示且不写入模型 |
| **放门窗** | 直接点在墙上 → 按"沿墙定位"落在鼠标投影处；窗默认 1500×1800@窗台 900，门默认 900×2100 落地；**越出墙长或与同墙其它洞口重叠会被拒绝**并提示 |
| **布柱** | 点位置放 400×400 柱 |
| **选择与编辑** | 点选墙/门窗/柱；拖夹点改墙端点、拖中点整体平移墙、拖门窗沿墙滑动、拖柱移动；Delete 删除（删墙会连带删掉墙上门窗） |
| **撤销/重做** | Ctrl+Z / Ctrl+Y，按整份模型快照记录（栈深 64；改动后自动丢弃重做分支） |
| **楼层** | 增加/编辑（名称、标高、层高）/删除楼层；列表里显示每层墙数；当前楼层决定新画的构件属于哪层 |
| **属性面板** | 选中构件后可直接改坐标/厚度/洞口宽高与窗台/柱尺寸等，点"应用属性"写回 |
| **视图与保存** | 每次改动自动保存 `model.json`；"生成全部视图"按默认视图集合写出 `views/*.json`（供 CAD 的 `LTTZ` 落图） |
| **视图操作** | 中键/右键拖动平移、滚轮缩放、Ctrl+A 缩放适应、状态栏实时显示坐标与捕捉类型 |

**分层**：画布（`PlanCanvas`，WinForms GDI+）只负责交互与显示；编辑规则放在
`Shared/BuildingModel/PlanEditing.cs`（**纯逻辑、无 UI 依赖**），因此规则可单元测试，
将来 CAD 侧的"构件化绘制"也能复用同一套，两边行为一致。

## 二、已经核实过的事实

1. **纯逻辑测试全过**（`BatchPdfPublisher.BuildingModel.Tests`，共 6 组）：
   - 命中：洞口优先于墙身、端点/中点夹点、柱、空白处不命中；
   - 捕捉：端点 (6000,0)、中点 (3000,0)、正交贴齐、100mm 轴网；
   - 洞口校验：越界、与同墙其它洞口重叠、过短墙 都被拒绝；
   - 撤销栈：撤销/重做/改后丢弃重做分支/重复状态不增长（栈深 2）；
   - **端到端**：手画 4 道墙 + 1 窗 1 门 → 南立面 6240 宽（= 6000 + 两侧各 120 外皮）、
     8 条门窗线、2 个标高 —— 即"画出来就能出图"。
2. **界面自检通过**：`--selftest` 真正构造并显示主窗口，确认画布装载（楼层 2、墙 8、洞口 5）。
3. **R24/R25 与完整发布通过**：`Build-Release.ps1 -Bands R24,R25` exit 0；
   插件侧只链接它真正用到的三个共享文件（样例工厂与平面编辑逻辑只有程序用，不进发布 DLL）。

## 三、已知边界（P1.5 只做了第一增量）

1. **楼板与房间还不能在程序里画**（需要多边形绘制 + 房间边界），目前仍来自样例/后续阶段；
2. **门窗类型库还没接上**：现在放门窗用面板默认尺寸 + 自动编号（`C1500`/`M900`），
   还没读插件的门窗表/门窗立面参数库（那是下一步：把参数库导出成程序可读的 JSON）；
3. **捕捉**只有端点/中点/正交/轴网，还没有交点捕捉、延长线捕捉、极轴追踪；
4. **没有"墙接头自动清理"**：画十字/T 形接头时两道墙在几何上重叠（投影与体量阶段允许重叠，不影响出图）；
5. **没有三维视口**（P4）；
6. 大图纸性能未测（当前样例 8 道墙；目标见计划 §11：200 道墙常用操作 ≤100ms）。

## 四、下一步（按计划）

1. **把参数库接进来**：从插件导出"门窗类型库"（编号/宽/高/窗台/分格/开启/材料）到 JSON，
   程序里放门窗时直接选类型 → 立面门窗分格就能复用现有能力；
2. **程序里画楼板与房间**（多边形 + 房间名/面积）；
3. **墙接头清理**（T/L/十字按中心线裁剪）与交点捕捉；
4. 之后进 P2（领域模型与参数治理）→ P4（三维体量与视口）→ P5（出图与落图联动）。
