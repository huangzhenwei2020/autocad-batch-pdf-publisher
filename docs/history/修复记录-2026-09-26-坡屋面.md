## 一、这一轮加了什么

| | 之前 | 现在 |
|---|---|---|
| 模型 | 墙 / 洞口 / 楼板 / 柱 / 轴网 / 房间 / 楼梯 | 新增 **`RoofModel`（双坡屋面）**：檐口矩形 + 屋脊方向 + 坡度角（+ 板厚） |
| 标高 | —— | **檐口标高默认现算**：本层楼面 + 层高；**屋脊标高 = 檐口 + 半跨 × tan(坡度)** |
| 立面 | 到墙顶（或屋面板）为止 | 正对坡面看：檐口线 + 屋脊线（矩形轮廓）；**山墙这头看：两条坡线交于屋脊的三角** + 檐口板厚 |
| 剖面 | 只有墙/板/窗/楼梯 | 顺着屋脊剖：屋面**三角轮廓**；横着剖到：该处屋面的**高度线** |
| 尺寸 | 层高链 + 总高 | 总高**算到屋脊**（样例：6900 → **8610**），并单标一道 **"屋面（檐口→屋脊）1710"** |
| 三维体量 | 到屋面板（平顶） | 屋面实体 **5 个面**（底面 + 两坡 + 两端山墙三角），暖色（陶瓦感）；挑檐就是檐口矩形多拉出去那圈 |
| 平面草图 | 画墙/门窗/柱/楼梯/轴线/房间 | 新增 **「放屋面」**（点两个角拉檐口矩形，长边即屋脊方向）+ 屋面属性面板；草图上用**虚线**画檐口、**点划线**画屋脊并标出脊高与坡度 |

## 二、几何（一个几何，三处共用）

`Shared\BuildingModel\RoofGeometry.cs`（纯计算、可单元测试）：

```
屋脊沿 X（AlongX = true）：坡度方向跨度 = Depth/2，屋脊在 Y + Depth/2
屋脊标高 = 檐口标高 + 半跨 × tan(坡度角)；坡面斜长 = √(半跨² + 举高²)
法线：坡面法线 = (沿脊方向 × 坡向) 归一，再翻成朝上 —— 例：1:2 坡 → (0, ∓0.4472, 0.8944)
```

立面/剖面、三维体量、平面草图都调它，所以"草图上看到的"就是"出图后画出来的"，也是"三维里立起来的"。

## 三、核实过的事实

**单元测试**（第 14 组 `RoofChecks`，全部手算核对）：

```
坡屋面：檐口 6900、屋脊 8310（半跨 2820、坡度 26.565°）；山墙坡线 2 条、体量屋面 5 面
```

- 檐口 7440×5640、坡度 26.565°（1:2）、檐口标高现算 = 二层楼面 3600 + 层高 3300 = **6900**
  → 屋脊 = 6900 + 5640/2 × 0.5 = **8310**；改成 45° → 屋脊 6900 + 2820 = **9720**
- 南立面（正对坡面）：有檐口线 6900、屋脊线 8310，且都是横平竖直的线
- 东立面（山墙这头）：**两条坡线**，都交在屋脊 8310 上
- 剖面：顺着屋脊剖（CutX）→ 两条坡线；横着剖到屋脊处（CutY 在 Y=2820）→ 剖到的屋面线在 8310
- 体量：屋面 **5 个面**（底 + 两坡 + 两端山墙），最高点 = 屋脊 8310、最低点 = 檐口 − 板厚 120 = 6780；
  两片坡面都是四边形、法线朝上且一南一北、Z 分量 0.8944（1:2 坡）

**平面画布自检**（`--selftest-canvas`）：

```
PASS 放屋面：两点拉出 7440×5640 → 屋脊沿长边、檐口 3600 屋脊 5000；拖动整体移动；拖动中删除不抛异常
```

**真实产物**（样例两层小房子 + 注入一圈挑檐 600 的双坡屋面，`--snapshot`）：

- `样例-两层小房子 东立面图.png`：山墙三角 + 檐口板厚 + 右侧尺寸链 **3300 / 3600 / 1710（屋面）/ 8610（总高到屋脊）**
- `1-1 剖面图.png`：屋面三角轮廓 + 同样两道屋面尺寸
- `三维轴测.png`：坡屋顶立起来（两坡 + 山墙三角 + 挑檐），体量 281 面、范围 8640×6840×8610

**发布**：`Build-Release.ps1 -Bands R24,R25` 两个版本都通过。

## 四、需要你在程序里试的

1. `JZMX` → 「平面草图」→ 工具行点 **「放屋面」**；
2. 沿外墙外沿（把挑檐算进去）拉一个矩形 —— 长边自动成为屋脊方向；
3. 选中它 → 右侧属性面板改 **坡度角 / 屋脊方向 / 檐口标高 / 板厚**，点「应用属性」；
   面板里直接写着现算出来的"檐口 / 屋脊 / 半跨 / 坡面斜长 / 坡度 1:2"；
4. 切「立面 / 剖面预览」点「重算当前视图」：山墙立面能看到三角、剖面能看到屋面轮廓；
5. 「三维预览」里就是坡屋顶的体量（暖色）。

## 五、已知边界（下一步）

1. 只支持**双坡**：四坡（庑殿/歇山）、单坡、折线坡、天沟/斜天沟、老虎窗、烟囱都还没做；
2. **山墙只到檐口**：没有把山墙（檐口以上那半个三角墙）补出来，所以三维里山墙位置看到的是屋面的三角面；
   立面上"山墙三角"是屋面的轮廓，不是墙的轮廓；
3. 屋面的**坡度箭头 / 分水线**（屋顶平面图）还没做：平面图（剖在 1.2m）里本来也不画屋面；
4. 檐口没有做**檐沟/封檐板**，也没有保温/挂瓦条的构造层次；
5. 剖到的屋面**没有混凝土填充**（和楼梯一样，按"看线"画）。
