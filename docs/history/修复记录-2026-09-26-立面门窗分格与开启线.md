## 一、这一轮做了什么

立面上的门窗**不再只是一个矩形洞口**：分格（中挺/上下亮/自定义分格）与开启线
（平开/推拉/上悬/下悬/百叶…）都按**类型库里的做法**画出来。

关键决定：**不重写一套画法**。程序侧只做"翻译"，几何仍由插件已有的
`DoorWindowElevationGeometryBuilder`（CAD 里画门窗立面用的同一份源码）算：

```
模型洞口(编号+尺寸)  ┐
                     ├─→ OpeningElevationAdapter（适配器）─→ DoorWindowElevationGeometryBuilder
类型库(做法/框料/材料)┘                                        └─→ 分格/开启线/框线（mm，洞口局部坐标）
                                                                    └─→ 换算到视图 + 遮挡裁剪 + 镜像 → 视图 JSON
```

| 环节 | 做法 |
|---|---|
| **参数从哪来** | 尺寸用模型里的洞口；做法（分格预设/开启方式/外框/中挺/安装缝/门扇内框/自定义分格/凸窗/材料）用类型库里按**编号**查到的那条。模型里不复制做法，改库重算即全楼同步 |
| **分格** | 单扇 / 双扇等分 / 三扇等分 / 四扇等分 / 五扇等分 / 上亮 / 侧亮 / 上亮+侧亮 / 拱形亮子 / 门联窗 / 自定义（`CustomCellLayout` 或 `CustomColumnWidths`+`CustomRowHeights`）——全部走生成器，取值与插件一致 |
| **开启线** | 左/右平开（合页角 → 对侧中点 → 另一角）、双扇平开、上悬/下悬/中悬、推拉箭头、百叶横线、固定扇不画 |
| **重线处理** | 正好落在洞口四边上的分格线不重复输出（洞口轮廓已经画了），CAD 里不会出现两条完全重合的线 |
| **遮挡** | 分格/开启线与洞口轮廓**同一套隐藏线规则**：被更近的墙/柱挡住的部分，用线段减矩形（Liang–Barsky）裁掉，斜的开启线也逐段裁。北立面的窗绝不会透到南墙上 |
| **镜像** | 背立面（北/东/西）U 轴与墙轴反向时左右镜像，门联窗的门扇位置、平开扇的合页侧不会画反 |
| **比例分级** | **1:100 及更小**：只画洞口轮廓 + 分格 + 开启线（不画 20mm 安装缝、50mm 门扇内框、玻璃/百叶材料符号——那些在 1:100 上只有零点几毫米，纯属糊线）；**1:50 及更大**：按类型库全画（与插件 1:50 门窗立面详图一致） |
| **缺参数与坏参数** | 编号不在库里 → 只画洞口轮廓 + 一条提示（"在 CAD 里用 TQLX 导出类型库后可补上分格与开启线"）；分格参数不合法（超出洞口/重叠）→ 不让整张视图失败，退回单格 + 一条提示 |

同时把类型库的导出补齐（`TQLX`）：新增 `CustomColumnRatios`、`CustomRowRatios`、`DoorPlacement`、
`DoorEdgeDistance`、凸窗左右侧做法与进深、凸窗左右分格等字段，与插件里的门窗参数一一对应。

## 二、为了"同一份源码"做的两处小重构

1. **把 `DoorWindowScheduleItem` / `DoorWindowFloorQuantity` 拆成单独文件**
   （`Features/DoorWindows/Models/DoorWindowScheduleItem.cs`，纯搬移，插件行为不变）。
   原因是原文件 `DoorWindowElevation.cs` 带 AutoCAD 引用（`ObjectId`/`Point3d`），
   程序侧链接不进来；拆开后这两个类型与生成器都**不依赖 AutoCAD**，可以被程序与测试工程以
   **源码链接**的方式共用（沿用本仓库"不新增 DLL"的做法）。
2. **新增 `OpeningElevationAdapter`**（`Shared/BuildingModel/`）：模型洞口 + 类型 →
   生成器输入。程序与插件、测试工程共用这一份，避免出现"程序画的"和"CAD 画的"两套结果。

## 三、已经核实过的事实（都可以重跑）

单元测试（`BatchPdfPublisher.BuildingModel.Tests`，6 组全过；新增第 6 组"立面门窗"5 项）：

```
分格与开启线：洞口 4 条边 + 做法 11 条 = 15 条（中挺 x=1500、外框内边 6 条、开启线 4 段）
背立面镜像：开启线合页侧随视线反向（U=-800 一侧）
遮挡裁剪：全挡 0 条 / 半挡保留 13 条且都在 x≥1200
自定义分格：固定玻璃扇 + 平开门扇 → 中挺双线 1625/1675、玻璃符号 3 条、开启线只在右扇
详简之分：1:100 10 条（无安装缝/门扇内框/材料符号）/ 1:50 21 条（全画）
参数兜底：非法分格 → 洞口 4 条边 + 提示「分格参数无效」
```

测试里的坐标都是**手算出来的**（1500 宽双扇等分窗：两格各 750、外框 50、两扇都可开启 →
中挺并成一条、每扇开启线两段），不是"有线条就算过"。
