## 一、这一轮把"回 CAD 敲命令"变成"点一下"

| | 上一轮 | 这一轮 |
|---|---|---|
| 从程序到 CAD | 画完 → 切回 CAD → 敲 `LTTZ` → 在清单里找刚生成的那张 | 程序里点 **「推到 CAD」**：生成全部视图与图纸 → 写下**待落图清单** → **自动把 AutoCAD 切到前台并输入 `LTTZ`** |
| CAD 里选哪张 | 清单按类型排，得自己认 | 清单里**待落图的带 ★ 并排最前**，`LTTZ` 默认序号就落在刚推过来的那张上 |
| 落完之后 | 无从判断还剩几张 | 落一张少一张：`LTTZ` 落完会把该条的 ★ 去掉，并提示"还有 N 张待落图 / 已全部落图" |

## 二、具体做法

1. **待落图清单**（`Shared\BuildingModel\StudioLaunch.cs`，程序与插件共用、可单元测试）：
   - 文件位置 `<模型目录>\views\待落图.txt`（用 `.txt` 免得被当成视图读）；
   - 格式是纯文本，第一行带时间戳，之后每行 `id|文件路径` —— 出问题用记事本就能看；
   - 提供 `WritePending / ReadPending / RemovePending`，读的时候**跳过坏行与空路径**；
   - `ListViews` 会把清单里的条目**标上 ★ 并排到最前**（图纸优先）。
2. **程序侧「推到 CAD」按钮**（还有等价的命令行 `--push`，便于脚本/自检）：
   生成全部视图与图纸 → 标记待落图（**优先推图纸**：整张 A3 才是要落图的东西；没有图纸就推所有视图）。
3. **切窗口 + 自动输入**（`BuildingModelStudio\CadWindow.cs`）：找 `acad*` 进程主窗口 → 最小化就还原 →
   `SetForegroundWindow` → 等 250ms → **确认前台窗口确实属于 AutoCAD 之后**才 `SendKeys("LTTZ{ENTER}")`；
   切不过去就只留清单并提示"回 CAD 手动敲 LTTZ"。任何异常都吞掉——这只是便利功能，不能把程序弄崩。
4. **CAD 侧 `LTTZ`**：清单里显示 ★、提示"★ = 建模程序刚推过来、还没落图的 N 张，默认落第一张"，
   落图成功后 `RemovePending` 掉这一条并报剩余张数。

## 四、需要你在 CAD 里试的完整闭环

1. CAD 里 **`JZMX`** → 建模程序打开当前项目的模型；
2. 画/改 → 程序里点 **「推到 CAD」** → 程序自动把 CAD 切到前台并输入 `LTTZ`；
3. CAD 提示里选序号（默认就是刚推的那张，带 ★）、点插入点 → 落图；
4. 继续落剩下的：再执行 `LTTZ`，命令行会提示"还有 N 张待落图"。

如果第 2 步没自动输入（窗口切换被系统拦住、或 CAD 正在执行别的命令），清单已经写好了，手动敲 `LTTZ` 即可。

## 五、已知边界（下一步）

1. `SendKeys` 是"模拟键盘"，个别情况下（CAD 正忙于其它命令）可能没被接住 —— 已按"确认前台是 CAD 才发"处理，失败也不影响清单；
2. 还没有**图纸目录**（图号/图名/张数清单表）；
3. 视图在图纸上的位置还不能手工微调；
4. 出图要素还差：房间填充、剖切符号与索引号、立面轴网竖线与轴号。
