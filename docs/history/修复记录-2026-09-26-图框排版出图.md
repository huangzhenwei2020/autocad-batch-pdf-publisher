**依据**: [建筑模型与立面剖面生成-开发计划](../建筑模型与立面剖面生成-开发计划.md)（v3.3f）

## 一、核心决定：图纸本身就是一份视图产物

新增 `ViewKind.Sheet` 与 `SheetComposer`：把若干张视图按纸张排到一张图纸上，画出**图框 + 标题栏**，
产出的仍然是一份 `ViewDocument`（线 + 文字 + 圆 + 尺寸 + 填充）。

这条决定的直接好处：**插件落图命令一个字都没改** —— `LTTZ` 照常把整张图纸落到 DWG 里，
打图时按 **1:1** 出图即可（视图内容已经按各自比例缩到纸面尺寸）。没有新命令、没有新 DLL、没有 CAD 侧改动。

| 排版内容 | 规则 |
|---|---|
| **纸张** | GB/T 50001-2017 基本幅面 A4/A3/A2/A1/A0，横放/竖放可选（默认横放 A3） |
| **图框留边** | 装订边 25、其余 5（外框 = 纸边，内框 = 图框） |
| **标题栏** | 右下角 180×40，两行：图名 / 图号、比例、单位与日期 |
| **视图排布** | 内容区（让开标题栏那一条）按数量分成格子（≤1 → 1 列、≤4 → 2 列、更多 → 3 列），每个视图按自己的比例缩到纸面、格子内居中 |
| **尺寸** | 缩到纸面后几何距离不再等于真实尺寸，所以排版时把视图尺寸**转成带显式文字的尺寸**（`ViewDimension.Text` = 模型真实值）—— 图上读到的数字仍然对，箭头与界线位置也正确 |
| **文字下限** | 纸面字高不小于 1.8 mm，不然印出来看不清 |
| **塞不下时** | 给出提示（"建议换大纸或改比例"），**不擅自改用户定的出图比例** |

默认套图（`SampleModelFactory.CreateDefaultSheets`）：A3 横 4 张 ——
`建施-01 一层平面图`、`建施-02 二层平面图`、`建施-03 立面图（南/北/东/西）`、`建施-04 剖面图 + 门窗表`。

「生成全部视图」会把这些图纸一并写成 `views/sheet-*.json`；预览下拉里每张图纸都能直接看，
`--snapshot` 出 `图纸-建施-0X ….png`。

## 二、核实过的事实

**单元测试**（新增第 10 组"排版出图"）：

```
排版出图：A3 横图框 25/5、标题栏 180×40、平面 74.4×56.4mm 落在图框内、尺寸带显式文字，超格/缺视图都有提示
PASS 立面门窗：… / 平面图 / 排版出图
```

断言包括：图纸是 `Kind=Sheet`、`Scale=1`；标题含图号与纸张；标题栏有图名（字高 7）、图号、单位与日期；
纸边外框 0..420/0..297 与图框 25..415/5..292 都在；墙断面缩到纸面后**正好 74.4×56.4mm**（7440/5640 的 1:100）；
轴线也一起排上图纸且比建筑范围更长；**所有内容都在图框内**（逐条线检查）；
**尺寸必须有显式文字**且能读到 "3600"；四个立面挤 A4 竖排会报超格；视图 id 找不到只提示不崩。

**程序与产物**：`--generate` 一次写出 4 张图纸（线 86/51/154/54），`--snapshot` 出 4 张 PNG，
逐张看过：图框、标题栏、视图排布、剖面填充、门窗表都正常，**与标题栏不再重叠**（内容区整体让开标题栏那一条）。

**发布**：`Build-Release.ps1 -Bands R24,R25` 两个版本都通过（共享源码链接，未新增 DLL）。

## 三、顺手修的一处预览取景

图纸的单位是**纸面毫米**（A3 = 420×297），而原来预览取景固定留 500mm 边距 —— 一张 A3 图纸会被缩成很小的方块。
现在留边按视图大小的 4% 取（模型视图几千毫米时约 300、图纸几百毫米时约 17），图纸在预览里铺满画面。

## 四、已知边界（下一步）

1. **还没有用你项目里的图框模板**：现在画的是标准图框 + 自建标题栏；
   要套用你自己的图框（`FrameTemplateStore` 里那些），需要在图纸定义里带上"图框模板名"，
   落图时插入图框块、视图内容对齐到图框内框 —— 这是下一步（也是唯一需要动 CAD 侧的一步）；
2. 图纸目录（图纸清单表）还没生成；
3. 视图在图纸上的**位置还不能手工微调**（现在是自动分格居中）；
4. 平面/立面还缺一些出图要素：房间填充、剖切符号与索引号、立面轴网竖线与轴号。
