## 一、这一轮加了什么

| | 之前 | 现在 |
|---|---|---|
| 视图类型 | 立面 / 剖面 / 平面 / 门窗表 / 图纸 | 新增 **`ViewKind.Axonometric`（轴测图）**：三维体量投出来的**可见轮廓线** |
| 出图 | 4 张 A3（两层平面 / 四立面 / 剖面+门窗表） | **5 张**：多一张 **`建施-05 轴测图`**（排 `axon-1`） |
| 相机 | 三维预览页签里自己转 | 视图定义里存 **方位角 / 仰角 / 是否透视**（`AzimuthDegrees`、`ElevationDegrees`、`Perspective`），改完重算就是另一个方向 |
| 图层 | —— | 新图层 `WL-模型-轴测`（线宽 0.18，预览配色同步） |

**关键点：走的是三维预览那一整条链路**（`BuildingVolumeBuilder` → `VolumeRenderer`），
所以背面剔除、藏在墙里的面丢掉、逐段消隐全都在里面 —— 落图出来的线与程序里看到的**是同一份几何**。
落图后它就是普通视图（线 + 图名），CAD 侧一行都不用改（`LTTZ` 直接落，`ViewKind.Sheet` 那条套图框的分支照旧）。

## 二、核实过的事实

**单元测试**（第 15 组 `AxonometricChecks`）：

```
轴测出图：默认 35°/28° 104 条轮廓（可见 79 面）、215° 时 60 条、透视 187 条；A3 图纸内 104 条
```

- 默认 35°/28°：**104 条**轮廓线（可见面 79，每条边一段到几段），坐标全部有限，有图名
- 换方位角 215°：轮廓变成 **60 条**（说明相机真的起作用了）
- 开透视：**187 条**，坐标仍然有限
- 排进 A3 图纸：内容全部落在图框（25/5 留边）以内
- 默认套图 **5 张**，第 5 张是 `sheet-axon` / `建施-05` / 排 `axon-1`

**离屏自检**（`--selftest-canvas`）：

```
PASS 预览 样例-两层小房子 轴测图：线 104（门窗 0）、文字 1、尺寸 0、填充 0，非背景像素 213883
PASS 立面预览自检全部通过（6 张视图 / 极端变换 / 坏数据 / 坏 Graphics）。
```

**真实产物**（`--generate` + `--snapshot`，样例两层小房子）：

```
图纸：建施-05 轴测图  A3 横  420×297  1:1 出图 — 线 118、文字 5、尺寸 0 — sheet-axon.json
完成：856 条线（原来 634）
```

`图纸-建施-05 轴测图.png`：A3 图框 + 标题栏（图名"轴测图"、图号"建施-05"）+ 中间的轴测轮廓（外墙转角、
门窗洞口、屋面轮廓都能看出来）。

**发布**：`Build-Release.ps1 -Bands R24,R25` 两个版本都通过。

## 三、需要你在程序里试的

1. `JZMX` → 「立面 / 剖面预览」页签，视图下拉里多了 **「样例-两层小房子 轴测图」**；
2. 点「重算当前视图」看轮廓；
3. 想换方向：目前改角度要改视图定义（下一步会做成面板上的两个数值框 + "透视图"勾选）；
4. 点「推到 CAD」或生成全部视图 → 回 CAD 敲 `LTTZ`，选 **建施-05** 落到图里就是轴测图。

## 四、已知边界（下一步）

1. **只画轮廓线、不画明暗**：CAD 里没有填充/明暗面（三维预览里是彩色明暗，落图是线框轴测）；
   要做"带明暗的轴测"就得往 CAD 里写 `Solid`/`Hatch` 或 `GradientHatch`，还没做；
2. 轴测图的**角度还不能在界面上调**（只能在视图定义里改 `AzimuthDegrees/ElevationDegrees/Perspective`）；
3. 没有**剖切轴测**（把水平剖切与轴测合起来出一张图）；
4. 轴测图**没有阴影/配景**（树、人、地面），也不是"鸟瞰"（仰角上限还是 88°）。
