## 一、先回答"有没有可以预览三维模型的"

有，三条路都可行，这一轮走的是**第三条**：

| 方案 | 优点 | 代价 | 结论 |
|---|---|---|---|
| WebView2 + three.js（计划里的默认） | 效果最好（阴影、材质、剖切动画） | 需要 WebView2 运行时 + 带一份 js；**没法离屏截图自检**（渲染在子窗口里） | 以后要"好看"再上 |
| CAD 里建三维实体（`LTTZ3D`） | 能在 CAD 里随便转、能出轴测/剖切 | 重（要拉伸实体、布尔开洞），而且又回到"必须在 CAD 里看" | 后面按需做 |
| **程序里自研 GDI+ 轴测图**（本轮） | **零依赖**（不用 WebView2/js）、离线可用、**能离屏出图自己核对**、体量逻辑还能被 P5 出图复用 | 只有平面着色，没有材质/阴影 | ✅ 先做这个 |

## 二、这一轮做了什么

### 1. 三维体量（`Shared\BuildingModel\BuildingVolume.cs`，纯几何）
- **墙 → 洞口挖洞**：沿墙轴线按洞口分段——洞口之间拉整高体块；洞口那段只在**窗台以下 / 窗顶以上**拉体块。
  于是窗和门在三维里是**真的洞**（不然建筑永远是个实心方块，这条是体量生成最关键的一步）。
- **柱 → 长方体**；**楼板 → 按轮廓拉出的棱柱**（顶标高 − 板厚 ~ 顶标高）。
- 体量自带包围盒（宽/深/高）与中心，供相机与出图用。

### 2. 轴测渲染（`Shared\BuildingModel\VolumeRenderer.cs`，纯几何、可单元测试）
- **相机**：方位角 / 仰角 / 缩放三个参数，**平行投影（轴测）** —— 与建筑制图的轴测图观感一致，也没有透视除零；
- **消隐**：① 背面剔除（法线背对相机不画，凸体块靠这一步就去掉了全部被挡的面）；
  ② 按面深度**从远到近**排序，画布按序填充（画家算法）；
- **明暗**：固定"太阳方向"，按面法线夹角给 0.25~1 的系数，顶面另加一点亮 —— 不用光照引擎也能看清体块关系。

### 3. 程序里的「三维预览」页签（`BuildingModelStudio\VolumeCanvas.cs`）
- 左键拖动 = 绕建筑转，滚轮 = 缩放，Ctrl+A = 复位适应；按钮：重算体量 / 轴测视角 / 俯视 / **只看当前楼层**；
- 切页签或在平面里改动（`StructureChanged`）会自动重算；
- `--snapshot` 现在也会出一张 **`三维轴测.png`**（与页面同一条绘制路径）。

## 三、核实过的事实

**单元测试**（新增第 12 组"三维体量"）：

```
三维体量：整栋 150 面（7440×5640×6900）、一层 96 面、一樘窗把墙分成 4 块（24 面）、落地门 3 块（18 面）；
        35°/28° 可见 75 面并按深度排序；取景比例 0.0541
```

断言包括：整栋/单层包围盒（7440×5640×6900、单层 3600）、面数是 6 的倍数、
**一樘窗把墙分成 4 块 = 24 面且窗台面正好在 900、窗顶面正好在 2700**、
**落地门 3 块 = 18 面（门下不封）**、投影后可见面数少于总面数、面按深度从远到近、
投影坐标有限、明暗在 0.25~1、**顶面比底面亮**、取景后所有点都落在视口内。

**三维自检**（离屏真画，4 个视角 + 单层过滤）：

```
PASS 三维体量：方位 35° / 仰角 28°　画出面 75（剔背面 75）非背景像素 249282
PASS 三维体量：方位 0° / 仰角 0°　画出面 25（剔背面 125）非背景像素 374398
PASS 三维体量：方位 135° / 仰角 60° / 方位 250° / 仰角 5° … 
PASS 三维体量：只看一层时高 3600、面 96 个（整栋 150 个）
PASS 三维预览自检全部通过（4 个视角 + 单层过滤）
```

**人眼核对**：干净样例的 `三维轴测.png` 上，两层体块、3.600 分层线、
**南面能看到一层的窗与门、二层窗的洞口（能透过洞看到室内）**，东面也能看到窗洞；
顶面最亮、南面中间调、东面最暗 —— 明暗关系正确。

**发布**：`Build-Release.ps1 -Bands R24,R25` 两个版本都通过。

## 四、已知边界（P4 后续）

1. 体量里**没有楼梯、坡屋面、阳台/雨篷**，楼板也还没做出挑；
2. 洞口只挖"矩形洞"，**窗框/玻璃/门扇**在三维里还没画（立面投影里是有的）；
3. 只有平行投影，没有透视、没有阴影/材质、不能"剖开看里面"（剖切动画）；
4. 相邻体块之间还留着描边线（看上去像分格线），合并同材质共面片可以更干净；
5. 程序里的三维**不能量尺寸、不能保存视角**（P4 再说）。
