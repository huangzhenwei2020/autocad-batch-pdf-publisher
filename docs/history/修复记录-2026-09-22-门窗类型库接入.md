# 建筑模型：把门窗参数库接进程序（TQLX 导出 → 程序里选类型放门窗）

**日期**: 2026-09-22
**仓库/分支**: `huangzhenwei2020/autocad-batch-pdf-publisher` → `main`（**仅本地提交，未推送**）
**依据**: [建筑模型与立面剖面生成-开发计划](../建筑模型与立面剖面生成-开发计划.md)（v3.2）§3 复用资产、§6 P1.5 下一步第 1 条

---

## 一、为什么先做这条

程序里画平面时，门窗如果只能手输宽高，就等于把你**已经在 CAD 里录好的门窗参数**又录一遍。
这条把它接上：CAD 侧一条命令导出类型库，程序里选类型直接放——**尺寸、窗台、编号、立面做法全部复用**。

## 二、这一轮做了什么

| 位置 | 内容 |
|---|---|
| **中间格式** | 新增 `OpeningTypeModel` / `OpeningTemplateModel` / `OpeningTypeLibraryDocument`（编号、类型、洞口宽高窗台 + 立面做法：类型/分格预设/开启方式/框料/中挺/安装缝/门框/自定义分格/材料/图集/备注），以及 `openings.json` 的读写与路径约定（放在模型目录下，随项目走） |
| **CAD 侧新命令 `TQLX`（导出类型库）** | 读**当前项目**的门窗参数（`DoorWindowElevationPreference`，即门窗立面的"按工程记忆"）与立面做法模板（`DoorWindowElevationTemplate`），去重后导出成 `openings.json`；同一编号有多条历史尺寸时保留最后一条；已在 `FeatureRegistry` 登记（四字简称「导出类型」） |
| **程序侧面板** | 右侧新增「门窗类型库」：列表显示"编号 类型 宽×高 @窗台/落地"；按钮「导入类型库…」（导入并**复制到模型目录**）／「刷新（模型目录）」／「套用到选中洞口」／「取消选择类型」；说明行显示来源项目、类型数、模板数与载入时间 |
| **放门窗用类型** | 选中一个类型后，`放窗/放门` 直接套用它的编号与尺寸（门一律落地）；未选类型时仍用默认尺寸 |
| **套用到已有洞口** | 选中一樘门窗 → 点「套用到选中洞口」，会先校验（越界/与同墙其它洞口重叠），**校验不过就原样退回**，不会把模型改坏 |
| **演示类型库** | `SampleModelFactory.CreateDemoOpeningLibrary()`（C1215 / C1518 / C1824 / M0921 / M1524 + 3 个做法模板）；`--generate` 时**只在没有时**写入，不覆盖 CAD 导出的真库 |

## 三、已经核实过的事实（我跑过的验证）

1. **门窗类型库测试 4 组全过**：
   - 往返：`openings.json`（2950 字节）保存/读取后类型 5 个、模板 3 个，C1518 的 1500×1800@900、
     「双扇等分 / 双向推拉」、图集名都对得上；
   - 套用：C1518 → 1500×1800@900；M0921 与「门联窗」都按**落地**处理（窗台 0）；
   - 查找：按编号忽略大小写与空格；不存在的编号与空库返回空；
   - 演示库：编号唯一、尺寸有效、既有落地门又有带窗台的窗。
2. **原有测试不回归**：投影 5 组 + 平面编辑 6 组（含端到端"手画 4 道墙 + 1 窗 1 门 → 南立面 6240 宽"）全过。
3. **界面自检通过**：主窗口构造、画布装载（2 楼层 / 8 墙 / 5 洞口）。
4. **完整发布通过**：`Build-Release.ps1 -Bands R24,R25` exit 0，功能简称校验通过（新增第 21 个功能）。

## 四、已知边界

1. **门窗表（图纸里的表格）还没接**：现在导的是"项目参数 + 立面模板"；如果某项目只在图纸里有门窗表、
   没有在 MCLM 里录过参数，导出的库会是空的（程序会提示"当前项目还没有门窗参数"）。
   下一步可以加"从当前图纸的门窗表读一次"（复用 `TianzhengDoorWindowService`，需要用户框选表格）。
2. **类型里存了立面做法，但程序还没用它画分格/开启线**：立面目前只画洞口轮廓；
   把 `DivisionPreset / OpeningMode / 框料 / 中挺 / 自定义分格` 画成门窗立面（复用现有门窗立面生成器）
   是接下来的增量。
3. 类型库没有"项目类型 vs 单樘覆盖"的区分（计划 §5.6 里那套优先级还没落地）。

## 五、下一步（按计划）

1. **门窗立面分格与开启线**：用类型库里的做法参数把立面门窗画出来（这是"复用现有能力"最有价值的一步）；
2. **可选**：`TQLX` 支持"从当前图纸门窗表读一次"；
3. 程序里画楼板与房间；墙接头清理与交点捕捉。
