## 一、这一轮做了什么

上一轮的图纸是**自带图框 + 自建标题栏**。这一轮让它**套用你项目里已登记的图框模板**：

| 位置 | 做法 |
|---|---|
| **视图格式** | `ViewDocument` 新增 `PaperName`/`PaperWidth`/`PaperHeight`（图纸才有）与 `FrameTemplate`（指定块名；空 = 按纸张自动匹配） |
| **自带图框分层** | 图纸自带的图框与标题栏改画在**独立图层 `WL-模型-图纸框`** —— 套用项目图框时整层跳过，不会出现双层图框 |
| **落图（LTTZ）** | 读图纸 JSON 时：按 `PaperName`（与横竖方向）在 `PublishPlanStore().LoadFrames()` 里找同规格的已登记图框 → 插到插入点，按纸张缩放到 1:1 纸面 → **回填图名/图号/比例/子项目名属性** → 跳过 `WL-模型-图纸框` 层 |
| **找不到时** | 提示一句（"项目里没有 A3 的登记图框：本次用图纸自带的图框"）并照常落图自带的图框；图框块不在当前图纸里、块没有可计算范围等情况也都只提示、不中断 |
| **图框图层** | 插进来的图框块放到制图标准的 `WL-图框` 图层（`EnsureFrameLayer`），与门窗立面/大样插入保持一致 |

关键复用：图框定位数学与门窗立面分页插入**完全相同**——
`factor = min(纸宽/块宽, 纸高/块高)`、`插入点 = 纸角 - 块包围盒最小角 × factor`、
排版范围用登记时的 `LayoutLeftMargin/...`。所以图纸内容（纸面毫米、原点=纸左下角）自然落在图框内框里。

## 二、核实过的事实

**编译**：R24 与 R25 两个版本都通过（`RotatedDimension`/`BlockReference`/`AttributeReference`/
`DraftingStandardService.EnsureFrameLayer` 两边一致）；**没有新增 DLL**（`SheetComposer` 走源码链接）。

**单元测试**（排版出图组扩写）：

```
排版出图：A3 横图框 25/5、标题栏 180×40、平面 74.4×56.4mm 落在图框内、尺寸带显式文字，超格/缺视图都有提示
```

新增断言：图纸必须记录纸张规格（`A3` / 420×297，落图时按它匹配项目图框）、
**自带图框与标题栏文字都在 `WL-模型-图纸框` 图层上**（套用时好整层跳过）、
视图内容（不含图框/标题栏两层）仍全部落在图框内。

**发布**：`Build-Release.ps1 -Bands R24,R25` 两个版本都通过。

## 三、需要你在 CAD 里验的三步（这段只能在 CAD 里看）

1. 在项目里登记一个 **A3 横** 图框（插件已有的「图框登记」流程，与门窗立面用的是同一套）；
2. `LTTZ` 落 `views/sheet-plan-1F.json`，命令行应出现
   **"已套用项目图框：A3（图框块名）（按纸张缩放到 420×297，图纸自带图框已跳过）"**；
3. 打图时按 **1:1**、纸张 A3、横向 —— 图纸内容正好落在你图框的内框里，标题栏里应是图名/图号/比例 1:1。

如果命令行提示"项目里没有 A3 的登记图框"，说明该图框还没登记（或登记的纸张规格不是 A3）。

## 四、已知边界（下一步）

1. 还没有**图纸目录**（图纸清单表：图号、图名、张数）；
2. 视图在图纸上的位置还不能**手工微调**（现在自动分格居中）；
3. 图纸只按纸张自动挑图框，同一规格有多张图框时取第一条（要精确指定可在图纸定义里填 `FrameTemplate`）；
4. 平面/立面出图要素还差：房间填充、剖切符号与索引号、立面轴网竖线与轴号。
