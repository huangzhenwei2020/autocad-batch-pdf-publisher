# 三维预览：门窗看得出来、能透视、能剖开看内部

**日期**: 2026-09-26
**仓库/分支**: `huangzhenwei2020/autocad-batch-pdf-publisher` → `main`（**仅本地提交，未推送**）
**依据**: [建筑模型与立面剖面生成-开发计划](../建筑模型与立面剖面生成-开发计划.md)（v3.3k）
§6 阶段 P4（三维体量与投影）

---

## 一、这一轮补的四件事

| | 上一轮（v3.3j） | 这一轮 |
|---|---|---|
| 门窗 | 只在墙上**开洞**，洞里什么都没有 → 看不出是窗是门 | 洞口里补上**窗框（四边各一块，60mm）+ 玻璃（20mm，居中）+ 打开 35° 的门扇**；玻璃半透明偏蓝、门扇暖木色、框料最深 → **一眼分得出窗和门** |
| 投影 | 只有轴测 | 新增**透视**（视场角 32°，可调）：近大远小，更像"看模型" |
| 看内部 | 只能在外面看 | 新增**水平剖切**（默认 1500mm）：剖切标高以上的部分**真的切掉**（Sutherland–Hodgman 裁剪），像剖切轴测一样看室内 |
| 描边 | 墙被洞口切成几块，块与块之间的接缝线全画出来 | **共面合并**（贴在一起的那段边不画）+ **丢掉藏在墙里的内部贴合面**（背面剔除之后再丢一次） |

## 二、具体做法

1. **门窗构件**（`Shared\BuildingModel\BuildingVolume.cs`）
   - 窗：四条边框（各 60mm 厚，随墙厚）+ 一块玻璃（20mm 厚、居中在墙厚里）；
   - 门：一扇**打开 35°** 的门扇（合页在洞口起点、朝墙法线方向开，厚 40mm）——
     平开门的门扇在三维里是斜的，比"画个方块堵住洞口"好认得多；
   - 都是长方体，所以"每块 6 个面"的规律不变（一樘窗 = 4 块墙 + 4 块框 + 1 块玻璃 = 54 面）。
2. **剖切**（`VolumeRenderer.ClipFaces`）：拿水平面做单平面裁剪，交点的 Z 取剖切标高本身，
   裁剪后仍是凸多边形；`ClipKeepAbove` 反向保留（上面那半），UI 只暴露"以下"这一半。
3. **透视**（`VolumeCamera.Perspective / FieldOfViewDegrees`）：`f = 1/tan(fov/2)`，
   深度 ≤ 1mm 的点直接弃面（免得出现"翻过来"的怪图）。
4. **共面合并**（`VolumeRenderer.SuppressCoplanarEdges`）：同一个平面上的面互相"吃掉"贴在一起的那段边，
   **按区间求差**逐段算，所以"被盖住一半"的边也能只画剩下的一半。
5. **丢掉藏在墙里的面**（`DropHiddenInterfaces` + `DropFacesBehindParallelPlanes`）：
   体量是一堆小方块拼出来的，块与块贴在一起的那片面谁也看不见 ——
   - 同一平面（不分正反）：整片被别的面**拼满** = 内部贴合面 → 全丢；
     洞口把墙切成几块是"不重叠地拼满"，每块都有别人盖不到的地方 → 全留；
   - 平行且在它前面 **≤600mm** 的另一层：投影像素被那层盖满 = 埋在实体里（楼板侧边落在墙厚正中、柱身贴在墙里）→ 丢。
     这一步必须用**全部面（含背面）**判定：先用背面剔除会把判据本身剔掉。
6. **画布**（`BuildingModelStudio\VolumeCanvas.cs`）：按种类给基色（玻璃半透明偏蓝、门扇暖木、框料最深），
   逐段画边（`face.Edges`）；状态行显示"隐藏面 N、轴测/透视、剖切标高"。

## 三、核实过的事实

**单元测试**（第 12 组扩写，`BatchPdfPublisher.Tests\OpeningElevationTests.cs`）：

```
三维体量：整栋 276 面（7440×5640×6900）、一层 192 面、一樘窗 = 4 块墙 + 4 块窗框 + 玻璃（54 面）、
          落地门 24 面；35°/28° 可见 79 面并按深度排序；取景比例 0.0541
三维剖切/透视/共面：剖切 1500 mm 后 131/276 面（最高点 254 vs 5100）；共面合并 11 个面上的线被吃掉，
          描边总长 61105 → 42135 mm；透视近/远面积 0.589 / 0.327
三维藏面：单墙开窗 54 面 → 可见 17 面（玻璃 1、窗框 8）
三维藏面：平行面前 120mm 的小面被丢掉、1000mm 的保留（阈值 600mm 生效）
```

新增断言：整栋体量里同时有 `frame/glass/door`；一樘窗 54 面、落地门 24 面；
剖切后**没有点高于剖切标高**、且最高点正好停在剖切标高上；反向保留时都在标高以上；
平行投影下远近两个一样大的面**面积相等**，透视下近的明显更大、视场角变小画面变大；
实心墙"画出来的线 = 各面周长"，开洞后描边总长明显变少；可见面里不该再有背面；
"藏面"规则幂等（过滤一遍后再跑不该还能丢）。

**离屏自检**（`pwsh -File .\build\Test-BuildingModelStudio.ps1` → `--selftest-canvas`）：

"漏底"是轮廓**内部**夹着的背景像素（左右都画过东西、中间却空着）——

## 四、需要你在程序里试的

1. `JZMX` 打开建模程序 → 「三维预览」页签；
2. 左键拖动旋转、滚轮缩放、`Ctrl+A` 复位；
3. 勾 **「剖切标高」**（默认 1500）：上面的部分被切掉，能看见墙里的门窗洞口与室内；
4. 勾 **「透视」**：近大远小；
5. 勾 **「只看当前楼层」**：只画这一层。

## 五、已知边界（下一步）

1. **画板算法（按平均深度排序填充）不是逐像素消隐**：个别"高处小面压住低处大面"的情形
   仍可能留下一条很淡的接缝线（已经用"丢掉藏在墙里的面"兜掉大部分）；彻底解决要上深度缓冲。
2. 剖切面**没有封口**（切开的墙顶是空的），俯视时能看到墙腔内部 —— 这也是剖切轴测的常见画法；
3. 楼梯、坡屋面、阳台栏板还没做；门窗只有"框 + 玻璃 + 门扇"三件，没有分格（立面里才有分格）；
4. 三维还不能出图（没有轴测出图/透视图纸），也没有量取尺寸。
