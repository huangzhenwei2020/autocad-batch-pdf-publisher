## 一、这一轮加了什么

| | 之前 | 现在 |
|---|---|---|
| 模型 | 只有墙/洞口/楼板/柱/轴网/房间 | 新增 **`StairModel`（双跑楼梯）**：楼梯间矩形 + 两跑梯段 + 一个休息平台 |
| 参数 | —— | 踏步宽、每跑踏步数、梯段宽、梯井宽；**踏步高默认按层高现算**（层高 ÷ 总踏步数），保证"上一层"正好落在上一层楼面标高上 |
| 平面草图 | 只有画墙/放窗/放门/布柱/拉轴线/画房间 | 新增 **「放楼梯」**：点两个角拉出楼梯间矩形，**长边自动当作梯段方向**；放完在属性面板逐项改参数（改完立刻看得到踏步/平台/箭头） |
| 平面图 | 没有楼梯 | 两跑梯段 + 踏步线 + 休息平台 + 梯井扶手线 + **剖断线** + **上/下箭头与文字**，可点选（锚点 `stair`） |
| 三维体量 | 没有楼梯 | 一级踏步一个小方块（底面按"踏面 − 踏步高 − 板厚"取，下面就是斜板的样子）+ 平台板 + **两侧栏板**（靠梯井那侧，每 3 级一段跟着踏步上升） |
| 校验 | —— | `PlanEditing.ValidateStair`：净宽放不下两跑、净长放不下踏步+平台、踏步高超出 100~200 都会给出人话提示 |

## 二、做法（一个几何，三处共用）

新增 `Shared\BuildingModel\StairGeometry.cs`（纯计算、可单元测试）：把楼梯参数展开成
**两跑梯段、每级踏步的平面矩形与顶标高、休息平台、梯井、扶手线、上下行路径**。
平面图、三维体量、平面草图三处都调它 —— 所以"草图上看到的"就是"落图后画出来的"，也是"三维里立起来的"。

平面约定（`AlongX = true`，楼梯间 `X..X+Length × Y..Y+Width`）：

```
第二跑（北侧条带，从平台往回跑，标高 1800 → 3600）  ┌──────────────┐
                                            梯井     │  休息平台     │
第一跑（南侧条带，从 X 起步朝 +X，标高 0 → 1800）      └──────────────┘
                                             踏步区 2340      平台 660
```

## 三、核实过的事实

**单元测试**（第 13 组 `StairChecks`，全部手算核对）：

```
楼梯几何：踏步高 200、踏步总长 2340、平台 660@1800、到达 3600；平面线 38、文字 上；体量楼梯面 150
```

- 参数：净长 3000、净宽 2700、踏步宽 260、每跑 9 级、梯段宽 1200、层高 3600 →
  踏步高 = 3600/(2×9) = **200**、踏步总长 = 9×260 = **2340**、平台 = 3000−2340 = **660**、
  平台标高 = **1800**、第二跑到达 = **3600**（= 一层楼面 + 层高）
- 每跑 **9 级踏步 / 8 条踏步线**；第一跑占 Y 0..1200、第二跑占 Y 1500..2700（中间是梯井）
- 沿 Y 跑时 `Length` 改成沿 Y、`Width` 沿 X（两跑占 X 0..1200 / 1500..2700）
- 平面：楼梯线 **38 条**、有"上"字，最低层只有"上"、非最低层同时有"上"和"下"、有 `stair` 锚点
- 体量：只看一层时高 = **3600 + 平台口栏板 1000 = 4600**；第九级踏板底在 **1480**（1800−200−120，
  说明下面不是实心块）；楼梯平面范围正好 3000×2700
- 校验：净宽 2000（放不下两跑）、净长 2000（放不下踏步+平台）、踏步高 260（超出常用范围）都报错

**平面画布自检**（`--selftest-canvas`）：

```
PASS 放楼梯：两点拉出 3000×2700 → 沿长边定向、踏步高 200 到达上一层 3600；拖动整体移动；拖动中删除不抛异常
```

**真实产物**（样例两层小房子 + 注入一部 3000×2700 的双跑楼梯，`--snapshot`）：
`一层 平面图.png` 里能看到两跑踏步、平台、剖断线（两条 45° 线）与箭头；
`三维剖切.png`（切到 1500）里两跑踏步、平台板、栏板都立得起来。

**发布**：`Build-Release.ps1 -Bands R24,R25` 两个版本都通过（含把建模程序发布到 `dist\...\建筑模型\`）。

## 四、需要你在程序里试的

1. `JZMX` 打开建模程序 → 「平面草图」页签 → 工具行点 **「放楼梯」**；
2. 在楼梯间位置点两个角（比如沿墙长方向拉一个 5400×2700 的矩形）——长边自动成为梯段方向；
3. 选中它 → 右侧「构件属性」里改 **每跑踏步数 / 踏步宽 / 梯段宽**，点「应用属性」，
   平面上的踏步、剖断线、"上/下"箭头会立刻重画（属性面板里也直接写着现算出来的踏步高与到达标高）；
4. 切到「三维预览」，勾 **「剖切标高」**（1500）就能看见室内的楼梯；
5. 生成全部视图 → 回 CAD 用 `LTTZ` 落图，平面图上就有楼梯了（图层 `WL-模型-楼梯`，线宽 0.18）。

## 五、后面又补上了：剖面里的楼梯

剖面（`ViewKind.Section`）现在也画楼梯了（`OrthographicProjector.AddStairProfile`）：

| 剖的方向 | 画法 | 数得出来的条数（每部楼梯） |
|---|---|---|
| 与**梯段方向一致**（顺着梯段剖） | 锯齿：每级**踏面** + **踢面**，下面一条**梯段斜板**线，加栏杆斜线；平台板顶/底 + 两端竖线 + 平台栏杆 | **45 条**（竖 20 = 18 踢面 + 平台两端，横 21 = 18 踏面 + 平台 3，斜 4 = 2 斜板 + 2 栏杆） |
| 与梯段方向**垂直**（横着剖到） | 一级一条水平线（"摞起来的踏步"）+ 栏杆线；平台同上 | **25 条** |
| 整部楼梯落在**剖切面之前** | 被切掉，一条不画 | **0 条** |

（还有"看线深度"限制：比 `ViewDepth` 更远的楼梯不画。）这几条线直接进视图、不走矩形遮挡那套：
楼梯在建筑内部，挡住的只是剖切面之后薄薄一层墙，画在最上层更像制图习惯里的"看线"。

实测（样例两层小房子 + 注入一部 3000×2700 双跑楼梯，`--snapshot`）：
`1-1 剖面图.png` 图例里"WL-模型-楼梯 (25 条)"，平面图里同名图层 38 条。

## 六、已知边界（下一步）

1. ~~**剖面里还没画楼梯**~~ —— 已补（见第五节）；剩下的：**剖到楼梯时没有画断面填充**（按制图习惯剖到的梯段板要打混凝土填充），
   以及顺着梯段剖时"上/下"梯段的起步位置还没有按剖切面各自裁断；
2. 只支持**双跑**（最常见的楼梯间）；单跑、三跑、弧形/旋转楼梯、剪刀梯还没做；
3. 栏杆在三维里是**栏板**（不是栏杆杆件），也没有做楼梯井的挡板与防火门；
4. 平面里的"下"箭头与"上"箭头之间用 200mm 偏移避让，还没有按制图习惯做成"同一条折线两端各一个箭头"；
5. 楼板上的楼梯洞口（楼梯井开洞）还没做：现在楼板是整块，不会自动挖掉梯井位置。
