## 用户已确定的方向

- 从同一启动器选择独立版，或打开 AutoCAD／天正。独立版逐步覆盖完整 CAD 和建筑专业功能。
- 二维工作台使用 WPF，沿用 CAD 式图标功能区，优先保证画布面积。项目和属性面板可以收起，图纸、模型／布局、命令栏和状态栏保持对齐。
- 操作向 AutoCAD 靠拢。空格／Enter 确认，两点点击框选，中间移动时可松开鼠标，中键平移应显示对应光标。
- 原有三维建模集成进独立工作台，共用项目、模型、楼层和构件图库。CAD 与 Studio 使用同一资源 ID 和同一本地构件目录。
- 已应用编辑由 Ctrl+Z 撤销，Esc 取消临时操作。夹点落点直接提交。
- 保留旧参数门窗、语义模型和标准层。外部资源项目放置、可变尺寸和运动仍待实现。

## 在另一台电脑构建

需要 Windows x64、Visual Studio 2022 Build Tools 的 MSBuild／C++ x64／CMake 组件、.NET Framework 4.8 或 4.8.1 Targeting Pack、.NET 8 SDK。系统安装 .NET 8 即可，便携 SDK 为本机可选项。完整 CAD 插件发布还需要相应已安装 AutoCAD 的 API 引用。

先拉取最新源码，然后按 [正式构建安装说明](../BUILD_AND_INSTALL.md) 执行。下面使用暂存目录，随后备份更新原安装目录。

```powershell
git pull --ff-only
git status --short
.\build\Build-Release.ps1 -Bands R24,R25 -R24AutoCadYear 2022 -OutputRoot dist\source-sync-stage
```

另一台只有 CAD 2022 API 时将 `-Bands` 改为 `R24`。R25 编译需要对应 API，R24／R25 编译通过与目标宿主实测分别记录。构建脚本会生成独立工作台、三维编辑器、读图引擎、原生 CAD 内核及许可证文件。

独立工作台回归需要可交互 Windows 桌面，默认创建临时 DXF 和独立配置。

```powershell
.\build\Test-StandaloneWorkbench.ps1 -WorkbenchDirectory .\dist\source-sync-stage\独立工作台 -PackageRoot .\dist\source-sync-stage
```

CAD 宿主回读必须先取得本轮用户批准，仅使用 AutoCAD 2022。下列开关表示批准已取得，不能用作自动批准。

```powershell
.\build\Test-StandaloneCadRoundtrip.ps1 -PackageRoot .\dist\source-sync-stage -UserApproved
```

该回读脚本目前使用 AutoCAD 2022 默认安装路径。其他安装位置需先调整脚本路径并核实实际宿主。此前启动器专项路由验证另有本机临时脚本，当前可移植回归入口以上述 `build/` 脚本为准。

安装前取得保存关闭确认并复查进程，完整备份原目录后覆盖原安装。若存在后台同步残留，先请用户退出或取得指定进程的结束授权。用户版本保持 1.5.6，原目录为 `dist/WanLuoArchitectureTools`。
