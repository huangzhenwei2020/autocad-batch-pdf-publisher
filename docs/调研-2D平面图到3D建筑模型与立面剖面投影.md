**生成墙体/楼板/洞口 + 剖面/立面**：FreeCAD BIM Workbench 明确具备——"fully parametric objects such as walls, beams, roofs, windows, stairs" 并支持 "production of 2D plans in combination with the TechDraw Workbench"（https://wiki.freecad.org/BIM_Workbench ）。TechDraw 里对应 `Arch SectionPlane`（剖切面）+ `TechDraw::DrawViewArch` / BIM View（https://wiki.freecad.org/TechDraw_ArchView ）。IfcOpenShell 提供 IFC 层面的墙/洞口构造（`bim/module/model/wall.py`），但出图能力弱于 FreeCAD。OCCT 本身只给内核，不给"墙"这种建筑语义。

> **对我们的取舍建议**：没有一个开源 BIM 内核能直接以 .NET 库形式嵌进 AutoCAD 插件——FreeCAD/IfcOpenShell 要你接受 Python 进程外调用。若坚持闭环在 .NET 内，务实路线是 **OCCT（几何内核，动态链接 DLL 满足 LGPL）+ 自研薄薄的建筑语义层**，不要指望直接复用 FreeCAD 的墙/洞口对象。

## 三、三维 → 二维投影（关键一节）

- **OCCT 的 HLR（Hidden Line Removal）**：`HLRBRep` 系列算法族（`HLRAlgo`、`HLRBRep_PolyAlgo` 等），是 OCCT 官方"Interactive visualization / Hidden-line removal"能力（https://occt3d.com/open-cascade-technology/ 模块表中明确列出 Hidden-line removal）。这是唯一能同时给出**可见边 / 隐藏边 / 轮廓线**分类的成熟内核，正是"剖面线稿分线型"所需要的。许可证 LGPL-2.1 + 例外，动态链接可闭源商用。
- **FreeCAD TechDraw / BIM View**：完全建立在 OCCT HLR 之上，且已验证了我们要的全部特性——"Cut lines, projected lines (Show Hidden) and 2D lines can be rendered with different line widths"、"Show Fill（剖切区域填色）"、`Data Render Mode` 的 Solid/Wireframe 双模式（https://wiki.freecad.org/TechDraw_ArchView ）。**这是最值得照抄的行为规格。**
- **Blender Line Art / Freestyle**：基于渲染管线，输出 SVG 风格化线条，效果漂亮但为 GPL-3.0 且必须宿主在 Blender（https://docs.blender.org/manual/en/latest/grease_pencil/modifiers/generate/line_art.html ）。GPL 传染 + 不能进 AutoCAD 进程 → 只能做独立"出图服务"。
- **ezdxf**：MIT，DXF 读写 + `drawing` add-on（SVG/PDF/PNG/DXF 后端，支持图层与线宽策略）（https://ezdxf.mozman.at/docs/addons/drawing.html ）。**但明确无 3D 渲染引擎，"3D entities are projected into the xy-plane"、"only top view rendering"** —— 它做不了立面投影，只能用于"把已经算好的 2D 线写到 DXF"。
- **libdxfrw**：GPL-2.0（https://github.com/LibreCAD/libdxfrw ），只做格式读写。

> **对我们的取舍建议**：**最佳组合 = OCCT `HLRBRep` 算投影与可见性 → 得到带分类的 2D 边 → 在 AutoCAD 进程内用 ObjectARX/.NET API（或 ezdxf）按图层写 Line/Polyline + HATCH 填充**。分图层分线型与图案填充这一步**必须在 CAD 侧完成**，TechDraw/ezdxf 都替代不了。OCCT 必须动态链接（DLL）以满足 LGPL，且要附许可证声明与可替换 DLL 的说明。

## 四、DXF/DWG 读写

| 方案 | 能力 | 许可证/代价 |
|---|---|---|

出处：
- https://github.com/mozman/ezdxf （MIT）

## 推荐落地路线

1. **建模层**：自研轻量建筑对象模型（墙/板/洞口/门窗），只存参数与轮廓，不引入完整 BIM schema。
2. **几何层**：OCCT DLL（LGPL 动态链接），用 HLRBRep 做正交投影与隐藏线消除，输出「可见边/隐藏边/轮廓边」三类带标签的 2D 线段。
3. **CAD 层**：AutoCAD .NET API 按三类标签写到不同图层（线型/线宽前置配置），剖切面用 HATCH 填充；基础设施复用 AutoCADCodePack（MIT）。
4. **不引入**：任何 GPL 组件（libdxfrw、DeepFloorplan、FloorplanToBlender3d）、任何 NC 数据集（CubiCasa5K）、ODA 商业 SDK。
5. **可选**：若客户要求 IFC 交付，用 GeometryGymIFC（MIT，纯 C#）作为导出器，而非 IfcOpenShell。
