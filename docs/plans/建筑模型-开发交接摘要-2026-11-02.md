## 当前代码

用户入口 `WLDIMEDIT`，在 CAD 当前视口内编辑非注释性原生直线尺寸，不另做导出／导入平面流程。支持共线串识别、增补、界点移动／重合去零、输入段长、合并／删段、整串尺寸线移动、串身份与复制隔离。保持测量几何、样式／文字保护和事务回滚。

| 位置 | 用途 |
|---|---|
| `BatchPdfPublisher/Features/Drafting/Services/DimensionChainGeometry.cs` | 与 CAD 无关的站位、去重、界点和越界检查 |
| 同目录 `CadDimensionChain.cs` | 原生尺寸读取、身份、样式校验及原子修改 |
| 同目录 `DimensionEditService.cs` | 非模态调度、双击／夹点命中、预览和文档生命周期 |
| `BatchPdfPublisher/Features/Drafting/Views/DimensionEditPanel.cs` | 深色工具面板，复用 DPI 窗口基类 |
| `Commands.cs`、`FeatureRegistry.cs`、`RibbonIconAssets.cs` | 用户入口、内部调度命令、27 功能图标 |
| `BatchPdfPublisher.Tests/DimensionChainGeometryTests.cs` | 不启动 CAD 的核心回归 |
| `BatchPdfPublisher.Tests/DimensionEditNativeTests.cs` | 临时侧数据库／桌面合成样例与只读结果报告 |
| `build/Test-DimensionEditNative.ps1`、`build/Test-DimensionEditDesktop.ps1` | 用户授权门控，固定 CAD 2022，测试文件留本机临时目录 |

提示／选择命令使用 `NoUndoMarker`，实际修改由普通 `WLDIMCOMMIT` 独立执行，防止下一次增补被 Esc 取消后出现空撤销步骤。点击命中使用当前绘图视口和本次消息坐标，处理像素／DIP 换算，不能退回旧的 PointMonitor 一秒有效期方案。

另携带编辑器依赖构建修复：package.json／lock 中 `prosemirror-history` 从无效的 1.4.2 修正为 1.4.1，并同步下载地址，完整性哈希保持；该修复已用于本批正式构建。
