# 外部三维导入与四向 CAD 立面

2026-10-29。用户要求导入 FBX 等外部模型后，支持生成四个方向的 CAD 立面。下文保留完整开发目标；首阶段已实现静态 FBX/GLB 导入、共用图库、四向预览和 CAD 矢量落图，完成正式发布、测试及原目录备份覆盖。外部实例放置与整栋出图仍待后续。产品版本继续保持 1.5.6。当前实现及验收见 [首阶段记录](../reviews/外部三维导入与四向CAD立面-2026-10-29.md)。

## 操作流程

1. 从共用“图库”选择已有资源补充三维模型，或新建家具/设备资源。CAD 已登记的资源沿用同一 AssetId，不创建第二套图库，不要求再次导入 CAD 平面。
2. 选择 FBX，预览实际几何，设置单位、尺寸、基点、向上方向及正面方向。用户可在预览中调整正面，四向视图据此统一计算，不假定家具具有建筑东南西北方向。
3. 在同一窗口切换“三维 / 正立面 / 背立面 / 左立面 / 右立面”，统一毫米尺寸和底部基准。调整方向或尺寸后刷新预览；生成过程显示阶段进度并可取消。
4. “生成 CAD 立面”可选择一个方向或四向同时生成。CAD 侧选择插入点，默认四向横排，可设置间距；名称、尺寸标注和出图比例可配置。模型空间按真实尺寸落图，打印比例另行处理。
5. 外部资源正式放入项目、出现在整栋建筑立面及更新后的关联刷新，是后续实例/出图集成的一部分，不能把资源单独立面生成当作整栋出图集成已完成。

## 线图质量

- 生成可编辑 CAD 矢量线或多段线，不用三维截图代替图纸。四个方向分别成块，便于独立移动、复制或替换。
- 默认只画可见轮廓及实际转折边，消除遮挡部分，合并共面网格的内部三角边，处理重复/重叠线；不能把 FBX 的所有三角网格边直接落进 CAD。
- 隐藏线作为可选虚线层；轮廓、细节、隐藏线、尺寸/图名分层管理。没有门窗部件与运动定义时，不从一般网格猜出门窗开启线。
- 材质贴图上的花纹、文字不自动等于几何线。第一阶段以真实几何出图；曲面、复杂细节的精度须有清楚的预览和设置。
- 尽量复用现有 BuildingVolume、VolumeRenderer 可见边/消隐计算、ViewDocument 和 CAD 落图接口；建筑专用矩形投影不能直接当作任意家具网格的立面算法。
- 投影与清理在副本中进行，不修改源 FBX、来源资源或其他项目实例。局部退化小面应按受控容差处理并记录，不随意丢失整个构件或阻断全部方向；复杂模型通过可取消的后台任务和明确的细节选项控制用时。

## 开发与验收顺序

1. 补外部格式导入及统一几何、单位/朝向、真实预览，仍接现有共用图库。
2. 补四向正交视图、轮廓边提取、共面三角边去除、消隐/去重和精度控制。
3. 接四向预览、CAD 矢量落图与块组织；确认后一次提交、一步撤销，取消不改当前图纸。
4. 接资源实例放置及整栋出图，校验位置、旋转、镜像和标准层归属，避免只在三维显示、CAD 出图缺构件。

验收至少包含：非对称家具（检查左右/背面不互换）、旋转与不同单位、凹面与遮挡、曲面和共面三角网格、重复线、尺寸一致、四向批量落图/取消/撤销、复杂模型进度，以及旧参数门窗和标准层回归。原生 CAD 使用临时图纸，不打开或修改用户工程测试。
