最新插入流程：图库选资源 → 输入洞口、编号、门垛、居中／靠边、墙厚和角度 → 点墙上位置 → 鼠标选择合页／开启侧 → 单击确认。墙厚 0 为自动，非零只限定墙线配对，不重写原墙厚。预览不提前写 CAD；取消不留门或墙洞。角度为原图、0°、30°、45°、60°、90°、120°、180°，也可输入。复杂门型缺少解算规则时继续固定规格，不能将分类宣称为全门型动作完成。

1. 用户实际 CAD 中确认连续鼠标采样与方向预览手感；自动测试已验证方向解算和原生结果，不能代替实际交互验收。
2. 按 [装修门完整计划](装修门-全门型组合与建筑门联动开发计划-2026-10-07.md) 的 R1 完成固定规格外部单开门与建筑洞口／实例关联、MM 放置、保存重开、离线副本及平面／图纸／CAD／三维／GLB 输出闭环。旧建筑参数门窗和标准层继续兼容。
3. 再实施外部模型联合尺寸／动作规则：固定截面、门缝、门套、各扇、五金锚点及运动轴共同求解。二维单开门变尺不等于外部三维模型已支持变尺。
4. 依序扩展 R2 双开／子母／亮子等组合、R3 推拉错轨及搭接、R4 折叠／转轴／暗藏、R5 特殊机构。每类需实际资源和完整闭环验收，未完成能力不开空按钮。
5. 普通 CAD MOVE／COPY 全程联动、普通门窗自动转换、弧墙和天正原生墙、家具正式实例、完整材质及跨电脑图库同步单独排期。

## 代码与复现入口

新 CAD 服务：`CadLibraryDoorPlacement.cs`（宿主／墙洞／恢复）、`CadPlanRegionService.cs`（区域捕获及原子提交）、`CadDoorDirectionJig.cs`（只读鼠标方向预览）。界面为 `CadComponentLibraryWindow.cs`、`CadPlanRegionWindow.cs`、`CadLibraryDoorEditWindow.cs` 和 `CadComponentPartPreview.cs`。共享契约位于 `ComponentCatalog.cs` 与 `ComponentPlanSymbol.cs`，模型图库负责同 ID 同步及配对。

按 [构建安装说明](../BUILD_AND_INSTALL.md) 准备 SDK 后重建。契约／UI 回归入口为 `BatchPdfPublisher.ComponentPackages.Tests.csproj` 与 `BatchPdfPublisher.ComponentPlan.Ui.Tests.csproj`；模型用 `--smoke --component-package-check --snapshot-size 960x680`。CAD 在一次性图纸执行 `WLCOMPONENTPLANQA`、`WLLIBRARYQA`、`WLLIBDOORQA`、`WLCADPLANQA`，要求各成功标记，无 FAILED。安装仍需当次关闭确认、进程检查、备份并更新原目录。
