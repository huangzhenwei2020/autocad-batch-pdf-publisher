## 换电脑继续

1. 先保存/备份本地改动，再 `git pull --ff-only`。
2. 阅读本页、当前上下文和选定 UI 规则，再开始改实际工作台。
3. 按 [构建与安装](../BUILD_AND_INSTALL.md) 准备 SDK，通过 `build/Build-Release.ps1` 重建。不要复用另一台电脑的历史 DLL 或把源码目录当安装目录。
4. 安装需当次保存/关闭确认、进程检查和备份原目录，不能沿用历史确认。

提交只包含源码、测试、文档、设计资产及原仓库已跟踪的内嵌模块资源。用户 DWG/模型项目、个人图库/配置/凭据、`.artifacts`、`.tools`、`dist` 和本机测试截图不上传。用户模型与安装包须另行授权传输，Git 源码不能恢复这些数据。
