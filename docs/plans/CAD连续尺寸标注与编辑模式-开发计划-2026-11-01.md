日期：2026-11-01。2026-11-02 状态更新：用户已批准实施、覆盖安装和本批 CAD 2022 临时图测试，首批已备份覆盖原目录，产品仍为 1.5.6。R24 正式构建／27 图标／核心／原生回归通过，最终桌面夹点移动、落点提交和一次撤销通过；最终双击增补、连续增补逐笔撤销及零段桌面复验未完成，用户停止电脑操作后已停止。详见 [本批进度](建筑模型-开发交接摘要-2026-11-02.md) 和 [验证及边界](../reviews/CAD连续尺寸编辑-首批开发与待验收-2026-11-02.md)。下文是完整开发目标，不能将后续项当成已实现能力。

用户最新要求：测试插件前先询问，只能用 CAD 2022；最终备份覆盖原安装，不另装多个版本。源代码编译与非 CAD 单元检查可继续，后续 CAD／Core Console 启动须先取得当次许可。模式外直接双击仍是后续增强，当前首批仅在明确的尺寸编辑模式内接管当前尺寸串。

## 1. 目标和默认解释

用户希望获得接近天正的连续尺寸操作：双击标注后补尺寸，零长度段自动删除，同一串尺寸同时移动；若模式外直接操作不能稳定实现，则使用明确的尺寸编辑模式。

“尺寸长度为为”暂按“长度为零”理解。这里的零是几何测量长度为零，或用户明确输入零使界点合并，不能按显示文字为“0”判断。只改变文字的显示值不能伪造实际尺寸。

建议采用 **原生 CAD 尺寸＋连续尺寸链关系＋尺寸编辑模式**。编辑模式必须完整可用，模式外双击和夹点增强另作实机验证。图形仍在当前 CAD 视口操作，不另开一个不能同步的平面编辑器；编辑模式不是必须弹出的全屏窗口。

首批范围：当前 DWG 内的水平、竖向和任意斜向直线尺寸串；模型空间及布局空间的原生线性尺寸。角度、半径、直径、弧长、三维异面尺寸列为后续，不能用直线规则硬套。

## 3. 用户操作

### 3.1 进入、选串及新建

功能区“制图与标注 → 尺寸编辑”，采用独立的真实功能图标；内部命令暂定 WLDIMEDIT，默认快捷键开发时检查冲突后确定。已有尺寸可右键“编辑尺寸串”。

1. 进入模式，点一段尺寸；整串高亮，显示总长度、段数和当前操作。
2. 已有链标识直接取链；旧普通尺寸先预览识别结果，点击确认后建立链关系。多串重叠时可切换候选、加选／减选，不能悄悄串在一起。
3. 没有标注时选“新建尺寸串”：确定方向，连续捕捉被测点，再放置尺寸线。水平／竖向／沿所选线方向均支持，沿用当前有效尺寸样式。
4. 模式内双击尺寸线或该段文字进入“增补尺寸”，以后点击几何点可连续补入。模式外双击作为增强入口，见第 8 节。

### 3.2 增补尺寸

- 捕捉真实几何点，投影到当前测量方向；预览新界线及将生成的数值。
- 在某段内部补点：例如 6000 中补 2400，变为 2400＋3600，整串总跨度不变。
- 在首尾之外补点：扩展尺寸串，原有各段不动；只影响当前串，不自动修改另一道总尺寸。
- 捕捉已有界点是无变化操作，不重复生成零尺寸；越界／方向歧义给就地提示。
- 支持沿串输入距指定界点的距离，界点和参考方向必须在视图明确标出；不可只改显示文字。
- 新段继承所在段的样式／覆盖参数。拆分含手工文字、前后缀或上下偏差的旧段，先预览分配方式，不能把“6000”等固定文字原样复制到两个新段。

### 3.3 零长度与删除／合并

| 情况 | 处理 |
|---|---|
| 新补点与已有点重合 | 不新增对象，不形成重复界点 |
| 编辑使相邻界点真正重合 | 合并界点，删除退化的原生尺寸段，重建相邻链关系 |
| 正长度因精度显示为 0 | 保留，不按格式化文字自动删除 |
| 手工文字覆写为“0” | 不判断为零长度；提示这是文字覆写 |
| 选择“删除内部界点” | 合并左右两段，保留首尾跨度；例如 2400＋3600→6000 |
| 选择“删除该尺寸段” | 仅删除这一段并留下空缺，拆开链关系；与“合并”明确区分 |
| 全串所有段退化或主动删除整串 | 清理空链；整次操作可 Ctrl+Z 恢复 |

第一版提供界点拖动／距离输入。明确输入某段为 0 时，以该段起界点为固定端，将终界点并到起界点；内部相邻段重算，末段收缩则缩短整串。输入时清楚标明固定端，可切换固定端。有关联的被测点不能自动脱离原物体：需明确选择“仅改标注点并解除相关关联”，否则取消此次数值编辑。绝不通过写一个“0”文字隐藏实际正长度。

零判定用几何容差，不用字高、显示精度、像素或图纸比例。起始建议为换算至模型毫米后的 0.000001 mm；R0 样例核定最终值与数值保护。先平移到局部原点再求投影，禁止按巨大世界坐标任意扩大容差而吞掉真实短段。单位不明时使用明确的 CAD 单位提示，不假定一定是毫米。

负长度、非数值及移动界点穿越相邻界点时，先限制或拒绝并显示原因；不能用绝对值掩盖错误，不能悄悄重排界点而把手工文字／关联转移给另一段。

### 3.4 同串一起移动

区分两种操作，默认使用第一种：

- **移动尺寸线**：拖动整串专用夹点，沿尺寸线法向移动所有段，原被测点、实际长度及墙／门窗几何不动。尺寸数字与箭头随线移动；已有手工文字相对偏移保留。
- **整体平移标注**：显式选择后才把尺寸定义点和尺寸线一同平移；有关联尺寸须先确定关联策略。该动作不是默认拖动。

同一直线上存在内外两道、分尺寸加总尺寸、两个建筑或不相连的串时，分别处理。不能只看“横向／竖向”就全图一起移动。

多串对齐、整组等距排布是第二阶段增强，默认不联动其他尺寸道。若做联动，必须显式多选和预览。模式外直接拖原生夹点带动整串须另行验证；未验证前通过编辑模式的整串夹点完成。

### 3.5 提交与撤销

- 悬停和拖动预览不写 DWG；夹点放下／点位确认直接提交，不多按一次 Enter。
- 每次补点、合并或整串移动是一次 CAD 可撤销操作，包含所有受影响对象和链元数据。
- Esc 只取消正在预览的动作／退出模式，保留此前已提交的编辑；Ctrl+Z 撤销上一笔，Redo 恢复。
- 切换图纸／布局或来源文档关闭时暂停编辑，保留可恢复选择；不把动作写进另一张图，不自动发送 Esc 中断用户命令。

## 4. 编辑模式 UI

使用现有深色主题的紧凑非模态面板，当前 CAD 视口作为唯一编辑画布；可收起，不遮住主要图形。

- 顶部：当前模式“尺寸编辑”、当前串方向／段数／总长，退出按钮。
- 操作区：新建、增补、移动界点、删除界点／合并、删除段、整串移动、解除成串关系；图标配中文提示。
- 属性：尺寸样式、当前比例／单位、字高／精度等当前有效值，文字位置与覆写状态。改样式作用范围明确区分“本段”和“本串”，不默认修改整个图纸的样式定义。
- 视口：整串使用柔和高亮，当前段强调；界点为方形夹点，整串移动为独立菱形夹点，文字移动单独处理，悬停提示用途。
- 就地输入：距离、固定端和方向；右键菜单用于切换操作／继续增补／完成。输入框聚焦时数字和退格不泄漏到 CAD 命令行，Esc 与撤销行为一致。
- 辅助说明只出现在需要时，错误在操作附近显示；模式状态始终可见，不让用户误以为在普通选择模式。

不提前照搬大量不适用的天正参数。R0 完成交互探针后，画一张具体布局示意和动态操作样例，确认后再完成 UI。

## 5. 尺寸链识别与数据

继续使用原生 Dimension，不炸开为线和文字，不把整串做成无法正常编辑的匿名块。首批不引入需要额外 Object Enabler 的自定义尺寸实体。

每串持久化稳定 ChainId、SchemaVersion、所属空间／测量平面、方向、尺寸线位置、段身份与顺序、可选来源信息；落在自有扩展字典／Xrecord 中，不覆盖已有万落或第三方数据。运行时 ObjectId 与持久化句柄分开；句柄失效必须检测，不能误指向新对象。

识别旧尺寸须同时核对：同 DWG／空间、共面、方向、尺寸线共线且同道、端站位连续、样式及比例／单位兼容。几何只能提出候选，重叠总尺寸、链分叉或多个解释须用户选串。不同界线的实际起点仍各自保留，不能因投影站位相同就把它们强制移到同一个世界点。

局部坐标以沿串 u、法向 v、测量平面法线 n 表示，支持斜墙、旋转 UCS、倒向拾点、反向端点及非零高程共面对象；任意异面对象首批明确不支持。

COPY／COPYCLIP／WBLOCK／INSERT 后须修复身份映射，复制出来的新串独立编辑；不能沿用旧 ChainId 而跨对象联动。外部修改、删除／恢复、UNDO／REDO、保存重开时校验并重建缓存；事件回调只登记失效，不直接递归写数据库。

## 6. 对象兼容和关联保护

| 来源 | 首批策略 |
|---|---|
| 我们生成的原生线性尺寸 | 直接支持，生成端逐步写入链和来源标识 |
| 普通 CAD 线性／对齐尺寸 | 唯一识别／人工确认后接入，保留样式覆盖、图层及文字位置 |
| 已有 DIMASSOC 关联尺寸 | 先检测真实关联。仅移动尺寸线保留被测关联；增删测量点需受支持的关联重建，否则明确降级选择或拒绝，不静默破坏 |
| 天正自定义尺寸 | 保留天正原操作；有公开且验证过的接口后另做适配，不靠 Explode 外观反推后直接覆盖 |
| 天正代理、外参、锁定层、块内／嵌套尺寸 | 首批只说明原因，不自动解锁、炸块或修改源文件 |
| 角度／半径／直径／弧长尺寸 | 原命令保留，后续另定义编辑规则 |

保持 Dimlfac、注释性比例、图层、颜色、字高、箭头、文字样式和段级覆盖；不能把模型单位、显示换算、图纸比例混成一个倍率。注释性对象若未通过多比例上下文验证，只读提示，不能悄悄清除注释性。

尺寸编辑不驱动墙、门窗或源几何变形。若以后加入“尺寸驱动模型”，须另做约束和宿主更新设计，不混入本功能。

模型出图和门窗大样可能重新生成尺寸。来源标记须保留；建立手工补点／位置覆盖的关联策略，刷新时能确定来源才重放，无可靠匹配时提示保留 CAD 手工结果或另生成新版本。不能默默丢失手工编辑，也不能仅把刷新覆盖风险藏在说明里。

## 7. 实现结构和性能

建议几何核心与 CAD 读写／UI 分离：

- DimensionChainGeometry：排序、投影、分段、合并、零段和移动计划；不引用 CAD，供核心回归。
- CadDimensionAdapter / DimensionChainStore：原生尺寸读写、样式与关联快照、自有扩展数据和复制映射。
- CadDimensionEditSession / Service：选择、状态机、预览、命令上下文、事务、撤销和文档生命周期。
- DimensionEditPanel / DimensionGripPreview：面板、命中、高亮和临时图形；禁止直接从 UI 线程任意写 CAD。
- DimensionDoubleClickRouter：可选外部双击入口，只在确认对象及空闲文档中调度，负责订阅释放和冲突恢复。

文件名可随实现调整，但不另做第二套尺寸样式系统。候选索引首次建立，后续按对象变更失效；拖动只预览当前串，不能每移动一个像素都扫描整张图。捕捉／夹点命中使用像素容差，几何零判定使用模型长度容差，两者独立。

## 8. 分阶段交付

### R0：最小原生交互探针与能力冻结

用合成临时图纸验证：原生串补点／零段／整串偏移的事务和关联；模式内双击；模式外双击能否与 CAD 默认文字编辑、天正双击和 CUI 并存。不得全局关闭 DBLCLKEDIT、永久改 CUI 或发送 Esc 抢命令来冒充成功。记录不同对象／环境的通过和不通过结果。

产物：可复现探针、兼容表、具体 UI 示意和最终操作规则。若模式外双击不稳定，仍按计划完成编辑模式，不阻断核心功能。

### R1：完整编辑模式与普通原生尺寸

交付新建／选串、模式内双击增补、连续补点、重合去零、界点移动／输入零、删除界点合并、删除段留空、整串法向移动、原生文字和样式保持、一次操作一次撤销、保存重开。水平／竖向／任意斜向均须通过；不以只能在水平例子操作作为完成。

### R2：兼容、原生直接操作与出图接入

通过验证的对象启用模式外双击／整串夹点联动；补齐复制／外部编辑／关联尺寸及注释性行为、手工编辑与模型／大样重生成保护、比例管理回归。未通过的对象保留明确边界。天正真对象写入只有取得可靠接口并单独验证才开放。

### R3：扩展

多串对齐／等距、总尺寸联动、圆弧／角度／半径／直径以及三维／跨视口策略独立设计。R1/R2 的基本线性流程达到完成标准后再开展。

## 9. 验收标准

1. 6000 在 2400 补点→2400＋3600；连续补点、首尾扩展、斜向及反向操作正确，其他对象不变。
2. 重复补点不产生对象；移界点重合或明确输入零只删除退化段；显示为 0 的真实小正段及文字覆写 0 不自动删。
3. 删除内部界点保持总跨度；删除段留空不会自动补回；首尾、仅剩一段、全部删除均能撤销恢复。
4. 拖整串尺寸线所有段同步，实测值和被测几何不变；内外道、重叠总尺寸和相邻建筑不误动，手工文字偏移保留。
5. 按一次 Ctrl+Z 恢复上一笔全部图元和元数据；Redo 正确，Esc 保留此前提交。取消或异常无半串残留。
6. 旋转 UCS、斜墙、共面非零 Z、大坐标、毫米／米／英寸、Dimlfac、不同图纸比例及注释性兼容通过或明确禁用。
7. 旧普通尺寸、我们的视图／门窗尺寸、真实关联尺寸的样式与关联保护；锁定／外参／代理不被改写。
8. 保存重开、复制粘贴、WBLOCK／INSERT、原生 MOVE／STRETCH／ERASE 后身份不串链，冲突有可见提示。
9. 模型／大样刷新不静默吞掉手工补点和位置；保留／重新生成路径可理解、可撤销。
10. 普通 AutoCAD 与天正环境分别实测；先 CAD 2022/2024，再完成 R25 目标版本验证。编译通过不替代实机双击和夹点测试。
11. 820×600 至大窗口／高 DPI 下操作可达；万段图纸仅当前串局部预览，记录真实响应耗时，不预先编造性能承诺。

核心测试使用合成几何，CAD 原生测试使用一次性图纸／临时侧数据库；不得用用户生产图纸验证删零。各阶段记录源码、已通过项目、限制及未实现项。正式安装仍需用户关闭确认、进程检查、备份并更新原目录。

## 10. 本计划建议的首个开发批次

先做 R0 和 R1，以“选一串→双击补尺寸→重合自动去零→整串拖动→撤销／保存”形成完整可用链路。外部双击增强可以晚于编辑模式，但不降低这四项核心要求；天正真对象、复杂尺寸和多串自动排布不冒充首批已支持。
