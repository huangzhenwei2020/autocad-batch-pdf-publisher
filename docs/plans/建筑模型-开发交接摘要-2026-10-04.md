## 当前交付

- 独立模型编辑器为 Avalonia，版本保持 1.5.6；当前机器原安装目录的模型程序及 R24 插件已覆盖并逐文件校验。安装包、SDK、个人 DWG、真实 model.json 和内部备份不提交 Git；另一台电脑须从最新源码重新编译。
- CAD 路径迁移：活动模型文件丢失或项目移动时增加有效路径解析，避免旧绝对路径导致无法继续模型工作。详见 `docs/reviews/项目迁移后模型路径异常-2026-10-03.md`。
- 轴网编辑：点选与 CAD 式两次点击框选可累加选择，空格/回车整批提交；隐藏、删除使用不同光标及跟随提示，取消不写模型。轴号在建筑外侧、密集时仅做最小非重叠避让；轴号直径、文字高度和宽度因子可设置。
- 图纸注释：比例可随时调整；真实模型/CAD 几何保持 1:1，注释纸面字高与轴号直径乘比例分母。自动尺寸显示整数，测量坐标不舍入，尺寸文字约束在对应界线之间。
- 门窗表达：按立面分格与开启方式生成单扇、双扇、子母、推拉、门联窗等平面符号；特殊平面图例不等于已完成其专用三维机械构造。原 CAD/天正编号保留，属性中可改编号且保留原做法。
- 门窗操作：位置、方向、编号各有夹点；支持拖动松手提交和点击松开、移动、再次点击。方向用鼠标左右/跨墙切换，无需 Shift。门扇、开启弧、洞口均可拾取，悬停预选一致；移动显示最近墙端净距，可输入数字，右键直接沿墙居中。
- 开启设置：90/45/30/15°预设及 0～180°自定义角度；平面扇、弧、夹点与选择区域同步。新建三维门默认闭合，实例开关控制是否按相同角度打开，兼容旧模型显式三维角度。
- MM 统一“门窗”选型：项目、模板、内置图例三种来源，支持编号和类别筛选；先设置宽高、窗台/门槛、开启角度等再放置。保存模板与插入分别作为可撤销提交，不能覆盖同编号其他构造。
- 门槛：默认 0，正值时门区平面画与墙边对齐的两根线，三维为对应实体；门联窗不延伸到窗区，复制、标准层、保存与安全重新登记保留参数。
- 最新框扇修复：平面采用真实净扇边界，不以洞口整宽画扇；推拉搭接不重复加，有固定框时保留净空。平开轮廓、弧、自由端及拾取共用避框位置。模型平面门窗细线固定逻辑屏幕线宽，放大不再盖住扇缝；真实洞口、三维和 CAD 图层线宽不改。

## 性能与验证

- 连续参数输入短延迟合并，几何计算异步，取消恢复已有缓存；保留未编辑字段的原始精度。
- 门槛/方向只重建当前门窗及其标准层实例；位置变化仅重建受影响楼层，但保留完整墙交接上下文。已完成的有效预览用于应用；同编号同楼层的局部编辑保留项目树展开状态。
- 核心投影/编辑测试及 CAD 登记测试通过；R24、R25 编译通过。模型程序存在现有分析器版本及过时 API 警告，不能报告成整个工程零警告。
- 实际窗口自测覆盖 900×650、1500×900：MM、模板、位置/方向/编号夹点、预选、净距、右键居中、开启设置及撤销。最终安装版交互检查退出码 0。
- 桂林·山水湾四期只读测试：15 层、138 个源门窗、285718 个面；门槛预览约 0.73 秒、应用约 0.06 秒，方向提交约 0.46 秒、移动提交约 0.96 秒，含 10 个标准层实例。增量几何与全量重建一致；不保存真实项目文件，不将这些时间写成通用帧率承诺。
- 本轮没有把 CAD 图形界面落图、打印或 Windows 多屏 DPI 复核写成已通过。当前用户视觉复测及复杂项目边界仍需继续。
- 上传前复跑中，核心套件有一次在 `BuildingModelViewPublisher.PublishViews` 的清单 `File.Replace` 处发生“无法删除要被替换的文件”；未改源码再次运行完整套件后通过。失败发生在 GUID 隔离测试目录，原因尚未确认，留作文件占用/发布可靠性的观察项，不能宣称已修复。CAD 登记套件通过；NuGet 漏洞查询曾返回 404 警告，不影响本次编译测试，但不等于已完成依赖安全审计。

## 后续方向

1. 先接收本次框扇与操作性能复测；出现新问题时用真实类型/剖切高度/镜像/宿主数据复现，不靠任意缩小真实洞口掩盖问题。
2. 按 `docs/BUILDING_MODEL_INTEROP_PLAN.md` 的“门窗模板配对方案”推进公共资源库与安全资源包、CAD 二维符号和 GLB 三维资产配对。当前 MM 是参数模板，不具备读取原生 MAX/SKP 或外部三维资源包的能力。
3. 首批外部资产以一个单扇门和一个固定窗验证尺寸、基点、轴向、资源路径、缺失回退及跨电脑迁移，再扩展推拉、门联窗、共享网格和材质。不能把显示着色模式冒充 PBR 或 Blender 生产几何内核。

## 复现入口

```powershell
& ./.tools/dotnet/dotnet.exe run --project BatchPdfPublisher.Tests/BatchPdfPublisher.BuildingModel.Tests.csproj -c Release
& ./.tools/dotnet/dotnet.exe run --project BatchPdfPublisher.Tests/BatchPdfPublisher.CadOpeningRegistration.Tests.csproj -c Release
& ./.tools/dotnet/dotnet.exe publish BuildingModelStudio.AvaloniaProbe/BuildingModelStudio.AvaloniaProbe.csproj -c Release -r win-x64 --self-contained true -p:UseSharedCompilation=false -o .artifacts/model-check/建筑模型
& ./.tools/dotnet/dotnet.exe .artifacts/model-check/建筑模型/万落建筑模型.dll --smoke --opening-plan-check --snapshot-size 900x650
& ./.tools/dotnet/dotnet.exe .artifacts/model-check/建筑模型/万落建筑模型.dll --smoke --parameter-check --snapshot-size 900x650
```

`.tools` 不上传；目标电脑需使用其已有 .NET SDK 或仓库构建脚本准备依赖。两个 UI 检查分别运行，不在同次进程混用模型夹点和通用板参数场景。真实模型性能入口为 `--smoke --parameter-perf-check --model <模型路径> --snapshot-size 1500x900`，只读但路径由目标电脑实际项目决定。

覆盖前必须保存并关闭 CAD 及模型窗口，检查后台占用；只覆盖已编译且匹配 CAD band 的文件，备份并核对哈希，不另装一堆版本。
