# 建筑模型开发交接摘要

日期：2026-09-27。目标宿主：AutoCAD 2022 / R24。本文供后续开发快速恢复上下文；完整范围、验收条件和任务编号以[建筑模型完整工作流开发任务书](建筑模型完整工作流-开发任务书-2026-09-27.md)为准。

## 产品方向

- 独立建筑模型编辑器使用 Avalonia；模型、编辑命令和文件协议留在共享核心，便于以后在 Windows 以外的平台运行。当前 AutoCAD 插件和天正读取仍依赖 Windows/AutoCAD 2022。
- 同一个语义模型要支持 CAD 平面登记、建筑建模、平面/立面/剖面编辑、图纸发布和 CAD 更新。用户确认天正原生墙、门、窗的**实例位置及参数**必须可登记、核对和修改，门窗表不能代替实例读取。
- Blender 是后续复杂几何服务的方向；当前 Avalonia GPU 视口和简单建筑几何不能称为已接入 Blender 生产内核。
- LTTZ 选择界面暂保持现状；它负责在 CAD 中落图或更新视图，不能把它当成完整的图纸发布工作区。

## 已有实现与本轮增量

- `BuildingModelStudio.AvaloniaProbe` 是发布包里的新版建模程序。它已能打开/创建项目模型，显示可旋转、平移、缩放和拾取构件的三维视口，并修改部分墙、门窗参数。
- 本轮新增 `PlanEditorCanvas` 平面工作区：楼层切换、连续点绘墙轴线、沿墙放门窗、选择/删除、端点和中点捕捉、100 mm 网格与正交吸附、平移缩放、Esc 取消。平面、三维和构件树共用一个编辑会话；初次打开平面时会按画布尺寸适应视图。
- `BuildingModelEditSession` 新增墙、门窗及删除命令。先克隆校验，再整体提交；删除墙同时删除宿主洞口，支持撤销重做并保持构件 ID。门窗越界、重叠或高度不合法时拒绝提交。
- 新版保存使用模型快照；视图生成使用快照和修订校验，先在暂存目录写完整批视图及待落图清单，再切换 `views` 目录。编辑或取消后不提交旧结果；目录切换失败时尝试恢复旧目录。
- “立面编辑”“剖面编辑”“图纸发布”仍为禁用页签；现有“生成 CAD 视图/推到 CAD”是过渡入口，不代表这些工作区已完成。

## 验证与发布边界

- `dotnet run --project BatchPdfPublisher.Tests/BatchPdfPublisher.BuildingModel.Tests.csproj -c Release` 通过，覆盖新增墙/洞口、非法参数回滚、删墙级联、撤销重做，以及已有投影与取件测试。
- Avalonia Release 编译、样例模型与空项目平面截图、GPU 拾取冒烟通过。`build/Build-Release.ps1 -Bands R24 -R24AutoCadYear 2022` 构建成功；发布包位于本地 `dist/WanLuoArchitectureTools`，其中 `建筑模型/万落建筑模型.exe` 为新版入口。构建同时通过 32 项图像转 CAD 与 92 项楼梯测试。
- `dist`、截图和本机临时测试项目不是本次 Git 交付内容；从源码在目标机器运行发布脚本即可重建。
- 本轮**未**在 AutoCAD 2022 图形界面完成手绘项目的保存重开、生成视图、LTTZ 首次落图及更新验收；此前的 AutoCAD 2022 命令行宿主测试是旧样例的证据，不能替代新流程验收。

## 接下来按顺序推进

1. 用隔离项目在新版平面页手绘四面墙、门窗，保存重开并核对 ID、尺寸和宿主；在 AutoCAD 2022 图形界面通过 LTTZ 落图与更新，同时检查人工补绘保留。
2. 补齐 C01/C02 的键盘精确尺寸、墙夹点/交接、厚度基准、移动复制旋转以及完整捕捉；验证空项目、真实项目和高 DPI/小屏操作。
3. 对 F01 做编辑中取消、换项目、写盘失败和 CAD 同时取件的故障注入，确认上一完整批次可恢复；随后做真正的图纸发布工作区。
4. 尽早开展 B08 天正原生墙门窗只读字段探针，记录真实版本、实例坐标、可读参数与缺失字段，再实现登记确认及用户参数覆盖。不要把代理几何推断误标为原生读取成功。
5. 后续按任务书推进立面/剖面语义编辑、CAD 回执和 Blender 常驻几何服务；每张工单用真实入口和数据单独验收。
