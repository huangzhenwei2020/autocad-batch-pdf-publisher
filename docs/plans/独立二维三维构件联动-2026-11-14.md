# 独立二维与三维构件联动开发清单

2026-11-14 用户确认先记录联动工作，再继续昨天的 MiniCAD 功能补齐。版本保持 1.5.6。本文为待实施计划。

## 数据与操作约定

共用现有 BuildingModelDocument 及构件稳定 ID，MiniCAD 表达建筑平面，现有三维编辑器表达三维模型。普通 CAD 图元保留自由编辑能力，建筑工具通过共用模型的事务完成编辑。构件图元记录模型、楼层、构件 ID 及表达角色，重开和复制均核验身份。

当前已具备同窗承载、项目共用、保存和撤销入口路由。构件级双向数据同步需要按下表开发。建筑构件的一次编辑由模型事务拥有，两个视图投影随提交、撤销及重做刷新，需防止投影更新再次触发编辑。普通 CAD 图形继续使用文档自身的撤销栈，焦点和当前操作决定入口归属。

## 开发与验收顺序

| 顺序 | 要做的工作 | 验收 |
|---|---|---|
| 1 | 文档与建筑模型绑定、楼层、毫米单位、登记基点及方向变换 | 切换图纸和模型不串绑，远原点图纸与模型正确重合 |
| 2 | 共用构件快照与增删改通知、版本检查、单一编辑归属及错误恢复 | 三维有未保存修改时二维更新通过当前会话提交，保存冲突可恢复 |
| 3 | 直墙二维投影、建筑页画墙与选择属性、夹点修改 | 二维画墙和改端点厚度高度，三维更新；三维修改后二维刷新 |
| 4 | 门窗宿主、位置、尺寸、编号与类型分格联动 | 改洞口同步开洞，保留既有分格／构造，复制创建新构件身份 |
| 5 | 楼板、弧墙、梁柱及标准层投影 | 边界、曲率、标高和标准层实例更新一致 |
| 6 | 阳台、女儿墙、栏杆、散水、泛水、楼梯及屋面 | 复用现有平面绘制流程，两个视图更新并可撤销 |
| 7 | 普通线／轮廓转换、旧 CAD 楼层登记与重新生成适配 | 用户指定类型参数，重新登记遵守已批准的替换和门窗做法保留规则 |
| 8 | 保存重开、删除复制、撤销重做、批量编辑及大模型性能 | 稳定身份及关联持久化，失败操作不留下半份状态 |
| 9 | 平面／四向立面／剖面／表格派生及图纸更新 | 同一模型生成对应成果，用户图纸标注的保留规则可验证 |

首个交付闭环为直墙创建、两端及墙厚编辑、双向刷新和一次撤销。接着接通门窗，逐类扩展。完整 MiniCAD 二维、建筑联动和高级实体内核分别记录验收进度。

## 现有代码复用

- `Shared/BuildingModel/ModelTypes.cs`、`BuildingModelEditSession.cs`、`ModelEditHistory.cs` 负责语义模型及编辑事务。
- `PlanEditing.cs`、墙／门窗／楼板几何及已有平面绘图逻辑提供投影和操作依据。
- `CadFloorPlanRegistry.cs`、`CadFloorModelGeneration.cs` 提供登记更新、坐标与旧模型兼容依据。
- `StandaloneWorkbench/StudioHost.cs` 和三维工作区命名管道扩展构件消息，需携带模型身份、修订号和操作结果。
- `CadKernel/` 扩展带构件身份的表达创建、拾取及编辑事件，复用原生捕捉和输入交互。
