# 天正室外与屋面构件识别及栏杆绘制开发计划

日期：2026-10-18。状态：**R0 只读核验工具及首批三维女儿墙/阳台板体已验证并备份覆盖安装**。产品版本保持 **1.5.6**。进展见 [三维首批实现与安装边界](../reviews/三维女儿墙与阳台绘制首批-2026-10-18.md)、[R0 调查和验证](../reviews/天正室外构件-R0核验工具与样本调查-2026-10-18.md)；以下各阶段是目标，不代表已经全部完成。

本计划对应用户提出的阳台、地面散水、屋面泛水、女儿墙识别，以及栏杆绘制。遵循 [当前上下文](../CURRENT_BUILDING_MODEL_CONTEXT.md) 和 [跨电脑接续约定](../handoffs/建筑模型-跨电脑接续-2026-10-07.md)，不取代既有门窗、图库或登记替换规则。

**按批准流程分批实施**：用户已确认并要求开始。交互以 [三维绘制流程](../designs/室外屋面构件-三维绘制流程-2026-10-18.md) 为准，先做独立绘制闭环；正式安装仍须另行确认保存关闭及检查进程。

## 0. 最新用户决定：三维独立绘制为主线

2026-10-18 用户明确：**女儿墙、泛水暂不要求通过 CAD 生成，先在三维中自行绘制；本轮所有功能都必须支持三维独立绘制。** 本节优先于早期“先完成五类 CAD 核验再进入绘制”的顺序。

- 阳台、地面散水、屋面泛水、女儿墙、栏杆全部提供建筑模型程序内的原生绘制入口，不以拥有 DWG、打开 CAD、登记楼层平面或识别成功为前提；仍需正常的模型及楼层/室外归属。
- 女儿墙、泛水的 CAD 自动识别与生成后置，不再为其寻找样本或字段而阻塞三维绘制；已取得的阳台、散水核验结果保留，后续按类别接入。
- 三维绘制不是只打开参数表：在三维视图可选宿主面/边或在明确工作平面上拾点，显示实际构件预览；平面视图可作辅助，但不强制回 CAD 或只能在平面中绘制。
- 手工与 CAD 两种来源使用同一类语义数据、尺寸解算、宿主规则、撤销、出图和导出，不另建“手工版”模型或第二套图库。
- 每阶段先交付独立绘制和编辑，再增加对应 CAD 来源；不能把读取到字段或已有窗口称为绘制能力已完成。

## 1. 总体方案

采用“三维独立绘制与编辑 + 统一语义构件 + 可选 CAD 识别来源 + 同源出图导出”。不另做一套导入工具，不要求用户先炸开天正对象，也不以导出网格代替可编辑构件。

- CAD 仍从现有“建筑模型”工作台进入，沿用当前模型、楼层、登记范围、基点和单位。
- 能核验的对象直接形成候选；缺参数的就地补齐；无法确认的保留为可捕捉底图，不阻止其他构件生成或进入模型。
- 每个构件保留稳定身份、楼层或室外归属、来源和宿主；三维、平面、立剖面、CAD 落图和 GLB/FBX/SKP 共用同一份数据。
- 自动识别与手工绘制最终生成同类构件。用户可以继续改尺寸、标高、路径和做法，不是一次性静态网格。
- 建议分批交付：**三维绘制基础及女儿墙/阳台 → 栏杆 → 散水/泛水 → 按类别接入 CAD 来源 → 综合验收**。R0 已有工具继续复用，CAD 核验不作为绘制主线的前置关卡；各阶段均需回归验证。

## 2. 现有基础与缺口

| 已核对的基础 | 本轮需要补齐 |
|---|---|
| 统一 CAD 工作台、楼层登记、只读底图和捕捉 | 新类别的读取、核对、重读和替换范围 |
| 墙体支持直线、圆弧、厚度及自定义高度 | 女儿墙用途、底部偏移、屋面宿主与标高关系 |
| 楼板支持轮廓、孔洞、圆弧和圆角 | 阳台语义及边界部件；散水的真实坡面 |
| 基础双坡屋面模型 | 屋面交接泛水路径、截面、局部标高与接头 |
| 楼梯投影中有栏杆示意线 | 独立、可编辑、具有真实截面的栏杆构件 |
| 标准层、撤销、投影和静态导出管线 | 新构件在这些管线中的完整接入与回归 |

当前天正框选过滤主要是墙、幕墙、洞口、柱、梁；只增加一个类别名称不能实现新对象识别，必须同时扩展选择、来源重读、登记持久化、核验和生成。

天正官方 [T30 建筑产品说明](https://tangent.com.cn/tzt30jz) 列出了阳台、散水等屋顶及室外构造能力，也说明其采用自定义建筑对象。但这不是对象接口说明，**不能据此假定本机 T20 V9.0 的实体类名、字段名和可读参数**。首阶段以本机实际对象的只读核验为准，其他版本分别建立适配记录。

## 3. 五类构件如何建模

### 3.1 阳台：组合关系，不是额外叠一块板

- 阳台记录轮廓、板厚、板顶偏移和所属楼层；支持直边、圆弧、凹轮廓与孔洞。
- 阳台板复用楼板几何，增加用途及组合身份。栏杆、实体栏板或矮墙作为独立子构件关联，允许逐边启用和单独编辑。
- 从 CAD 同时读到阳台板和边界栏杆时，按来源及几何对应配对，不再自动补一套相同栏杆。
- 与自动围合楼板重合的部分必须识别：可复用同一块板，或按确认边界分区，不能叠面或重复计量。重叠无法确认时进入核对，不做猜测性布尔切割。
- 封闭阳台的窗、墙继续使用既有门窗和墙语义；不因“阳台”名称自行生成封窗、顶板或房间面积。

### 3.2 女儿墙：墙体内核 + 明确的屋面用途

- 优先复用墙几何，补“普通墙 / 女儿墙”等用途、底标高偏移或宿主关系、独立墙高；不能把所有低墙自动当女儿墙。
- 底部可跟随已确认的屋面或屋面板，也可输入明确标高；改变宿主标高后重新计算，不能默认从下一层地坪起整层拉伸。
- 支持直线、圆弧、连续交接，后续可补压顶做法。压顶属于可选子部件，不强制每面墙都生成。
- 已按天正普通墙读取的女儿墙只补用途与定位，不重复创建第二面墙。用途不明时允许用户批量指定。
- 墙体融合必须考虑用途、实际底顶标高和材料，不因平面相接就把不同高度的普通墙和女儿墙错误合并。

### 3.3 栏杆：路径 + 截面 + 排布，不拉伸一个成品模型

- 独立栏杆记录路径、宿主、底标高、总高、立柱、扶手和填充；部件保留实际截面尺寸。
- 首批水平路径支持直线、多段折线及圆弧、开口或闭合。首批样式为竖杆式、玻璃式；实体栏板复用矮墙语义，不伪装成密集杆件。
- 立柱提供“最大中心距”与端部退距，显示实际排布结果；杆件净距与中心距分开，不能混用。每段可选择均分或延续节距，转角柱只生成一次。
- 扶手连续转角，端点可独立设置端柱与收头；连续玻璃、分格玻璃的接缝规则明确。转角不以相互穿透的盒子代替接头。
- 宿主可选阳台板边、楼板边、女儿墙顶，或无宿主独立路径；按选定侧偏移，基准可选择完成面而非默认结构板面。
- 斜坡及楼梯栏杆列为后续子阶段：按真实宿主高程、平台和梯段分段，不能把整段楼梯简单拉成一根斜直线。本阶段不宣称已支持所有楼梯。
- 栏杆高度、净距等为可编辑工程参数，默认值不是“规范合格”承诺；安全校核须另行核对项目用途及适用规范。

### 3.4 地面散水：具有真实横坡的室外带状构件

- 记录沿建筑外缘的路径、分段宽度、离墙距离、内侧标高、向外坡度、厚度及端部收口。
- 三维生成真实坡面，外缘高差由宽度与坡度计算；坡向可翻转，参数使用明确的 mm、% 单位。
- 支持直角、斜角和圆弧转角，检测偏移自交与过窄区域；门口、台阶、坡道处可手动断开和排除，不能自动跨过去。
- 默认归属室外基准，不随标准层逐层复制；室外地坪高程与首层结构标高分别记录。内院或多段地坪允许分段设置，不假定整栋同一室外标高。
- 普通 CAD 双线或多段线可在核对中指定为散水并补参数；不能仅凭图层或文字就直接确认为实体。

### 3.5 屋面泛水：先确认表达含义，再生成交接构造

- 首先核对天正对象实际表示的是泛水轮廓、上翻、边带还是其他构造，不能把所有屋面边线都解释成同一种泛水墙。
- 首批针对已确认的平屋面与墙交接：路径 + 立边高度 + 水平搭接宽度 + 做法截面 + 基准面，支持连续转角与端部。
- 作为屋面交接构造，不替代女儿墙、不额外制造一圈承重墙；薄层做法和有厚度构件分开表达，示意线不进入实体体积。
- 沿当前已支持的坡屋面，只有在路径局部高程可可靠求出时才跟随生成；复杂多坡交汇、天沟、雨水口和变形缝节点后续扩展，不猜测补齐。
- 无宿主或基准不明时保留候选，可由用户选择屋面或输入标高；不静默落到 0 标高。

## 4. 天正识别与重新登记规则

### 4.1 先建立只读适配样本

每类至少核对一个简单对象、一个转角或圆弧对象、一个修改尺寸后的对象。记录天正/CAD 版本、实际 DXF/RX/COM 身份、来源句柄、单位、变换、原生曲线及可读字段，并与对象编辑器显示值对照。

- 对象身份确认后，使用经过验证的属性白名单；不猜实体名，不把“属性能读到”视为语义已确认。
- 优先原生参数与曲线；必要时仅对临时副本做受限分解，限制递归、对象数和几何数量，释放临时对象，不修改或炸开源图。
- 普通 CAD 几何允许用户指定用途，仍需轮廓、宿主和标高校验；包围盒只作定位参考，不能拿来拉伸成阳台或泛水。
- 核对状态采用“已确认 / 待补参数 / 仅底图 / 已排除”，不展示没有校准依据的识别百分比。
- 未加载天正、代理对象或缺失版本适配时，明确降级为底图或待核对，不伪造完整识别成功。

### 4.2 身份、归属与替换

- 来源键包含图纸指纹、实体句柄、嵌套实例路径和登记范围；同一块多次插入不能仅按块内句柄去重。组合及子部件身份分别稳定。
- 沿用已有“登记楼层按 CAD 替换，编号和洞口大小相同的门窗保留做法、位置重算”规则；新增构件也要进入替换预览及撤销，不能反复生成越叠越多。
- 首次升级旧登记时，新类别未采集不等于已登记为空；未适配、读取失败、用户未纳入范围均不能被解释成删除。先补采集并显示替换清单，确认后进入该类别的替换范围。
- 已完整登记且确认删除的来源，更新时删除其对应组合和子件；单个来源解析失败则保留原件并列出未更新原因，其他确认项继续处理。
- 室外散水按明确的室外登记范围管理，不随某层替换误删整栋室外构件；未登记楼层和其他模型不动。
- 标准层的阳台与栏杆共享模板；女儿墙只在实际关联楼层出现，散水不默认加入标准层。允许解锁为单层编辑，禁止同时保存展开副本和模板造成重复。
- 用户自绘构件同样遵循所选替换范围；窗口预先列出受影响数量，不暗中新增一套“手工永远保留”的规则。
- 自动识别问题不阻止建模，但文件读写、并发冲突和安全保存失败必须明确报错，不能声称保存成功。

## 5. UI 设计与操作流程

### 5.1 CAD：扩展现有工作台，不增加入口选择窗口

保留“模型与楼层 / CAD 平面登记 / 生成与打开”三页、顶部目标模型和左侧楼层。登记页增加类别筛选和候选清单，右侧随选择显示参数。

```text
建筑模型    当前 CAD    目标模型 [模型名称 v]    新建 / 打开 / 保存
模型与楼层 | CAD 平面登记 | 生成与打开
-----------------------------------------------------------------------
楼层        | 类别 [全部 v] 状态 [全部 v]       | 属性：所选构件
一层        |                                  | 用途 / 来源 / 核验状态
二层        | CAD 底图 + 所选来源高亮           | 宿主 / 标高 / 厚度
屋面        | 生成轮廓叠加，可切平面 / 三维     | 宽度 / 坡度 / 方向
室外        |                                  | 分段边界 / 包含开关
            |----------------------------------| 缺失字段就地标记
            | 纳入 | 类别 | 名称 | 状态        | 批量应用到所选
-----------------------------------------------------------------------
已确认数量 / 待核对数量 / 未更新数量           保存登记   生成并打开
```

- “室外”是登记归属，不虚构一个建筑楼层。阳台、散水、泛水、女儿墙、栏杆在同一类别筛选内，不再套多层标签页。
- 点清单定位源对象，点预览同步清单与属性；含多项时仅共同参数可批量改，混合值明确显示，不用第一项覆盖所有项。
- 采用勾选包含/排除、下拉用途和宿主、数值输入及步进箭头、图标方向翻转；拾取路径/边界/基准有即时预览。
- 保留已有源线与生成结果的区别，缺三维时不能拿占位盒冒充实际几何。小窗口可收起侧栏，不压缩到看不清预览。
- “生成与打开”页列出新增、替换、删除、保留未更新及仅底图数量。支持继续生成已确认内容，处理完毕汇报实际结果。

### 5.2 Studio：构件入口与实际形状预览

- 在现有 Ribbon“构件”页按室外/屋面分组安排阳台、散水、泛水、女儿墙和栏杆；不再增加一个总入口弹窗。女儿墙接入现有墙体窗口的用途选择。
- 阳台使用现有板轮廓绘制交互，选边添加栏杆/栏板；散水和泛水使用“选路径 + 右侧参数 + 方向预览”。
- 栏杆提供专用选型窗口，布局与墙体、门窗一致；左侧每种样式显示真实生成的栏杆小样，中间显示所选样式的实际截面和三维，不使用通用立方体图标代替。

```text
栏杆                         类型 [项目类型 v]        保存为类型
-----------------------------------------------------------------------
样式缩略图   | 平面 / 三维 / 截面预览             | 总高 / 底部基准
竖杆式       |                                    | 扶手与立柱截面
玻璃式       | 实际杆件、分格、转角、端部收头     | 最大柱距 / 端部退距
             |                                    | 填充 / 净距 / 材料
-----------------------------------------------------------------------
路径 [绘制 / 取 CAD 线 / 选宿主边]    所属楼层 / 室外    开始绘制 / 取消
```

- 样式选用与路径绘制分开：先选参数，再在主视图绘制；修改已有栏杆可在属性面板直接调，不必每次重走选型。
- 绘制支持连续点、数值长度、底图捕捉、圆弧段；宿主边可逐段点选，明显显示所选边和偏移侧。仅支持已核验的 CAD 线型，其他类型提示保留底图。
- 数值有效时动态更新草稿；输入空值、负厚度等只标记对应字段，不把错误值写入模型，也不每按一个数字就弹窗。
- 放下夹点即提交；Esc 取消当前未提交段或草稿，已应用修改保留；Ctrl+Z/Ctrl+Y 沿用模型撤销。一次参数应用或一次连续路径提交为一个撤销单元。
- 路径端点、偏移侧、标高提供明确夹点；移动宿主后重算，删除宿主时选择一起删除或转独立，不能静默悬空。复杂节点编辑按后续能力逐项启用。
- 首批类型先随项目保存；后续公共样式进入现有共享图库，同一资源 ID，不另外建“栏杆库”。这不等于外部模型可变尺寸和运动已经实现。

### 5.3 五类构件的独立绘制入口

| 构件 | 三维视图中的绘制方式 | 主要可调参数 |
|---|---|---|
| 女儿墙 | 复用墙体窗口选女儿墙用途；连续拾点、圆弧或选屋面/板边 | 墙厚、独立高度、底标高/偏移、定位侧、材料 |
| 阳台 | 选楼层工作平面绘制闭合轮廓，或选已有板边建立轮廓；逐边添加栏杆/栏板 | 板顶偏移、板厚、边界圆角、各边部件 |
| 栏杆 | 自由路径或选板边/墙顶，支持连续直线、折线、圆弧 | 总高、侧偏、扶手/立柱截面、分格与填充 |
| 散水 | 沿已有建筑边选择路径，或在室外工作平面独立绘制 | 宽度、厚度、内侧高程、坡度/坡向、断口 |
| 泛水 | 沿屋面与墙交接选边，或在指定平面/高程独立绘制路径 | 立边高度、搭接宽度、截面、基准高程、端头 |

- 绘制前明确所属楼层/室外、工作平面和基准标高；拾取楼板顶面、墙面、屋面或已有边时显示实际落点及宿主高程。无宿主也可指定基准绘制，不能随相机方向任意改变绘制平面。
- 三维拾点沿用遮挡与可见性规则，不穿透选到背面或其他楼层；可见面、边、端点等捕捉与数值输入统一处理。首批只启用已验证的基准面/宿主；复杂坡面跟随未实现时仍可用明确的独立路径与标高。
- 移动、旋转、复制、删除、改路径/尺寸和保存重开必须覆盖五类构件；层高或宿主改变后的跟随与独立化规则一致，不要求回 CAD 重画。
- 手工来源与 CAD 来源分别记录，但不改变既有“按所选登记范围替换构件”的约定；以后重新登记时仍须预览受影响项，不能因新加手工入口就悄悄改变替换规则。

## 8. 测试清单

- 无 CAD 主线：不开 CAD、不提供 DWG、不登记平面，在空模型内分别完成五类绘制、捕捉、改参数/路径、保存重开、撤销重做和出图导出；仅有参数表或静态预览不能算通过。
- 只读采集：一次框选、重新读取、对象修改/删除、代理对象、缺天正环境；源图修改标志与几何不变。真实项目仅用私有副本，原生测试用临时图纸及侧数据库。
- 坐标：毫米/其他登记单位、基点、旋转、镜像、嵌套块、多实例、远离原点；不能把局部高程偏移重复叠加楼层标高。
- 几何：凸凹阳台、孔洞、弧边、斜转角、不同高度女儿墙、散水内外转角/断口、泛水端头、栏杆短段/闭合/转角/圆弧。
- 宿主：改层高、改板顶、改屋面、改墙高、移边、删边、删宿主、复制到不同层；检查关联、独立化和撤销。
- 更新：同一登记反复生成不增加数量；明确移除来源才删除；未采集新类别、单项读取失败、空候选不能误清旧构件；未登记楼层不变。
- 旧功能：门窗分格、同编号做法保留、弧墙、墙柱遮挡、普通楼板、屋面、楼梯、房间及标准层、模板和共享图库均回归。
- 操作：动态输入、步进、批量混合值、选择/捕捉、夹点落下、Esc、Ctrl+Z/Y、保存重开；小窗口、DPI 缩放、长名称不遮挡。
- 输出：平面/立面/剖面/轴测、CAD 实体层/线型/比例、GLB/FBX/SKP 回读；核对尺寸、高程、材质、法线、重复面、转角边和该闭合实体的开放边。
- 性能：大量标准层和长栏杆的杆件数量、面数、材质数、内存/耗时；取消不留半成品、不替换旧文件，受保护导出与打开保持有效。
- 平台：本机已安装的天正 + CAD 2022/2024 分别原生验证，R25 编译和实际环境分开记录；没有对应环境就明确未验收，不由一次测试外推全版本支持。

## 9. 本轮不承诺的能力

不做结构受力、防水施工节点合规或雨水排放能力的自动保证；不凭通用教程预设安全高度。不做任意天正版本全对象识别、任意复杂屋面、异形艺术栏杆、全楼梯自动栏杆或实时回写天正对象。

后续家具、装修门和外部构件仍沿用既定共享图库路线；本计划不把外部模型变尺、动作、实例放置等未完成功能标记为已完成。
