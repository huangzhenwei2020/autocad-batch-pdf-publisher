# 建筑模型开发交接摘要

日期：2026-10-24。产品版本：1.5.6。本次集中整理源码和上下文，不重新覆盖安装。

## 本批收录

- 三维独立绘制女儿墙和阳台，复用墙/楼板语义、三点弧、工作平面、动态预览、原子提交和撤销；后续增加语义边选取及阳台重绘。见 [绘制流程](../designs/室外屋面构件-三维绘制流程-2026-10-18.md)、[首批验收](../reviews/三维女儿墙与阳台绘制首批-2026-10-18.md) 和 [取边/重绘](../reviews/三维语义取边与阳台重绘-2026-10-18.md)。
- 天正室外构件只读核验工具，保留原始几何、高程、坐标变换和人工类别对照；阳台/散水调查不等于正式自动生成完成。见 [R0 核验](../reviews/天正室外构件-R0核验工具与样本调查-2026-10-18.md)。
- CAD 统一工作台非模态，支持保留窗口编辑图纸，命令上下文排队及来源文档保护。修复创建完成状态，重复名称由用户确认备份替换。见 [非模态](../reviews/建筑模型工作台非模态与CAD并行编辑-2026-10-20.md)、[创建/替换](../reviews/模型创建完成状态与同名替换-2026-10-21.md)。
- 生成模型显示真实阶段、登记组计数和用时；不可靠阶段用活动进度，保存回执后才完成。见 [生成进度](../reviews/模型生成分阶段进度-2026-10-21.md)。
- FBX 墙交接数值清理、目标单精度退化微小面的有界容错及中文成功警告；不修改源模型，不放宽整网格、材质及真实细节保护。见 [跨轮廓交接](../reviews/FBX跨轮廓墙交接精度修复-2026-10-20.md)、[亚微米交接](../reviews/FBX亚微米墙交接清理-2026-10-21.md)、[容错策略](../reviews/FBX微小面容错与成功警告-2026-10-21.md)。
- FBX 按每个实际楼层写原生 DisplayLayer，所有语义构件可读命名，稳定 ID 保存到属性和清单，保留几何字节。见 [分层验收和限制](../reviews/FBX楼层图层与可读名称-2026-10-23.md)。
- CAD `XTJZ`/`WLLINECORRECT` 参数窗口：按角度偏差、中点定位校正水平/垂直，多段线逐段校正并保持公共顶点；Z 归零独立开关，动态预览和一步撤销。见 [线条校正](../reviews/CAD线条校正与Z归零-2026-10-23.md)。

## 本次重新验证

使用本机 .NET 8.0.424，以下五个测试入口均以 Release 编译并运行成功：

1. `BatchPdfPublisher.LineCorrection.Tests.csproj`。
2. `BatchPdfPublisher.OutdoorDrawing.Tests.csproj`。
3. `BatchPdfPublisher.BuildingModel.Tests.csproj`。
4. `BatchPdfPublisher.CadOpeningRegistration.Tests.csproj`，包含工作台、同名替换和生成进度的 WPF 回归。
5. `BatchPdfPublisher.ModelExport.Tests.csproj`，无参数入口包含中立场景、共面/凸转角、微小面容错、FBX 图层容器及并发提交恢复。

本轮没有再次启动原生 CAD、Max 或 SketchUp 场景验收，也没有重做完整发布编译。各次安装及 CAD 2022/2024 原生测试结果见相应历史验收记录。Max Batch 仍受 ADLM 授权错误阻止；8# SKP 历史面数问题仍待修复，不能宣称全部格式均已通过。

测试可用系统 .NET 8 SDK 运行 `dotnet run --project BatchPdfPublisher.Tests/<上述入口> --configuration Release`。便携 SDK 可放 `.tools/dotnet`，不随仓库提交。隔离临时输出时应排除所有 `obj*` 生成目录，避免 SDK 默认通配编译重复包含旧 AssemblyInfo；正式发布仍只用 [构建安装说明](../BUILD_AND_INSTALL.md) 中的 `build/Build-Release.ps1`。

## 后续边界

栏杆、散水、泛水的独立三维绘制及正式 CAD 生成、宿主边跟随、三维节点编辑仍未完成。后续沿 [室外/屋面开发计划](天正室外与屋面构件识别及栏杆绘制-开发计划-2026-10-18.md) 继续。外部资源放置、变尺和动作仍不能当成已完成能力。

保留现有门窗参数、标准层、模板、图库稳定身份和用户编辑。CAD 与三维使用同一个本地图库，不恢复手工导出/导入 CAD 平面的旧流程。

## 上传与清理范围

源码提交包含既有受版本控制的模块依赖包，不包含 `dist` 安装目录、`.artifacts`、`.tools`、用户 DWG/模型、导出文件或个人设置。近期 IGS 排查和项目路径修复属于本机私有数据处理，不作为产品功能或用户数据上传。

本机空间整理只针对确认可重新生成且未被运行程序占用的旧暂存包、测试二进制及下载缓存；当前安装、回退备份、私有样本/日志和开发 SDK 保留。聊天历史、账号配置、模型权重和其他软件工作区不按普通缓存整目录删除。
