# 独立 CAD 图层线型、剪贴板与外参

版本保持 1.5.6，继续 MiniCAD 0.8.4 固定提交的阶段 C。用户批准使用 AutoCAD 2022 临时图和独立配置回读，并已确认保存关闭及授权结束云同步 PID 10188。原目录已备份覆盖，安装后回归通过。

## 本批操作入口

| 入口 | 当前实现 |
| --- | --- |
| 绘图／管理中的线型管理，`LT`、`LTYPE`、`LINETYPE` | 选择当前线型、新建命名线型、修改简单图案、说明、全局比例和布局比例 |
| `LTSCALE` | 直接选择全局比例操作，复用线型窗口 |
| 修改图层 | 名称、颜色、线宽和线型一起提交，支持撤销 |
| 点样式，`PTYPE`、`DDPTYPE` | 点形状、圆／方边框、固定单位和视口百分比大小 |
| 文字／多线样式，`STYLE`、`MLSTYLE` | 在上一批新建、修改和当前样式基础上增加重命名及删除，检查默认和被引用样式 |
| 修改中的剪贴板 | Ctrl+C、Ctrl+Shift+C、Ctrl+X、Ctrl+V，带基点复制、剪切和落点粘贴 |
| 插入中的外部参照，`XREF` | 显示名称、路径、已加载／未解析／已卸载状态，选择目录查找未解析参照 |
| 视图 | 十个标准方向、线框／着色、栅格 F7、坐标轴和视图导航开关 |
| 管理中的全部保存 | 保存已修改图纸及新图纸，返回原活动文档，取消另存时结束本次保存流程 |

剪贴板在同一独立工作台的图纸之间共享。粘贴时按名称映射图层、线型、文字样式、嵌套块和属性的引用，目标已有同名定义沿用目标做法。源文档关闭后仍可粘贴，取消预览不添加依赖，粘贴及新增依赖一起撤销／重做。新实体使用目标活动模型／布局空间。此项的系统剪贴板与外部 CAD 数据交换继续待接入。

多线编辑 `MLEDIT` 增加功能区入口，沿用原生 C／T／R／O／M 五种编辑方式。本轮主要验证命令接入，多线各方式与复杂交点的桌面操作继续列入专项回归。

## 文件与引用修正

- 图纸头变量保存当前线型、LTSCALE、PSLTSCALE、PDMODE 和 PDSIZE。
- 已有源图的线型编辑回写原记录，保留原句柄及其余字段。
- 重命名文字／多线样式时同步原表项、字典名和实体引用，删除经过引用检查的闲置记录。
- 多线元素表格切换操作前提交正在编辑的行，支持新增行后的切换。
- 修正定义块时新 INSERT 的当前图层和模型／纸空间归属。
- 源文件关闭后的剪贴板依赖快照包含嵌套块、属性和文字样式，插入引用重新绑定到目标表。
- 外参成功定位后保存新路径，跨图纸复制保留实际解析路径。外部源文件单独保留。
- 修正外参依赖线型、图层和文字样式表项的依赖标记，带竖线名称写入有效 DXF 记录。
- 标准视图使用原生编辑器视图操作，功能区方向随活动文档及相机反馈更新。

## 验证结果

原生 C++ 内核及 WPF Release 编译通过。正式发布使用 `build/Build-Release.ps1 -Bands R24,R25 -R24AutoCadYear 2022`，两代图标检查通过。R25 使用本机 2026 SDK 编译。

独立窗口验证线型与点样式参数、图层线型撤销、样式重命名／删除及撤销、样式引用保护、跨文档与源文档关闭后的粘贴、取消、剪切、嵌套块 ID 冲突、纸空间归属、外参修复保存重开、全部保存和十个标准视图。原有新建、框选、光标、26 个二维测试实体、三维同窗与大小窗口回归通过。实际截图核对线型、点样式、多线样式和外参窗口。

用户批准的 AutoCAD 2022 侧数据库回读通过。DWG／DXF 核对线型图案 24,-6,0,-6、比例 20、布局比例关闭、点模式 35／大小 -3、图层线型、样式重命名和闲置样式删除、跨图纸块与文字位置、嵌套块、外参路径和纸空间文字。结果为 `CAD_MANAGEMENT_ROUNDTRIP_OK`。已有源实体、单位、文字、属性、附加数据和字典保留测试继续通过。

测试中发现两个具体问题并修正。定义块的 INSERT 原本固定到默认图层，现采用当前属性。已加载外参产生的带竖线名称缺少依赖标记，AutoCAD 的 DXF 回读曾拒绝该记录，修正后全套回读通过。全部保存测试使用独立会话内的两张临时图，避免测试入口保存调用方已打开的图纸。

本机测试记录位于 `.artifacts/minicad-completion/`，源码上下文上传时按仓库规则排除。正式包日志为 `build-release.log`、`stage-cad2022.log`。临时图与截图保存在系统临时 QA 目录。
