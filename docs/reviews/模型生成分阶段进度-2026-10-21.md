# 模型生成分阶段进度

日期：2026-10-21。版本保持 1.5.6。

## 用户要求

生成建筑模型时不能只显示“正在处理”；用户需要看到当前步骤和等待情况。

## 实现

- CAD 统一工作台底部显示当前阶段、进度条、已用时。读取 CAD、启动/等待模型程序、重建三维及保存显示活动进度；有准确分母的楼层处理显示已完成登记组数及“当前阶段”百分比，不伪造总进度或预计剩余时间。
- 三维程序接收 CAD 请求后显示同一生成任务的进度窗口。耗时语义生成基于分离快照在后台运行，UI 可更新计时和阶段；三维重建沿用原后台流程。
- 语义结果在 UI 上一次提交，保留一步 Ctrl+Z；提交前复查编辑修订，不覆盖生成期间的新编辑。
- 跨进程使用模型旁的 `.cad-generate-progress.json`，以请求 ID 隔离，按秒更新当前阶段。不把活动心跳当作成功；实际模型和参照保存后才写成功回执。
- 完成/失败回执仍是最终事实来源。进度文件不可写不能阻断队列/最终确认；旧请求心跳不能覆盖新请求或已完成任务。
- CAD 等待未接收任务最多 45 秒；观察到实际运行后最多等待 600 秒。已开始的任务超时不会静默取消，提示检查三维窗口并不要重复提交。
- 未确认保存前不显示最终 100%；失败收起进度条并恢复操作，保留错误原因。旧式仅提交请求的代理不虚报“已保存”。

## 范围

- CAD 生成前预检也显示“校验登记”阶段，区别于实际模型生成。
- 登记组可含标准层。阶段分母是登记平面组数，不声称是展开后的物理楼层数量。
- 同步原生 CAD 读取仍在 CAD 命令上下文执行，不搬到后台线程，不用 DoEvents 重入 CAD。该段不提供逐图元计数/取消。
- 三维生成进度窗口在任务期间防止误关闭；当前不新增中途取消或强杀后台任务按钮。
- 不改变既有非阻断识别策略、重新登记替换/保留门窗约定，不触碰用户 DWG 和真实项目。
