# 平开窗方向与浅色虚线开启弧

日期：2026-10-06。针对 C1824 带固定上亮子的平开窗不能调整方向，以及开启弧需使用浅色虚线的反馈。

## 实现

- `OpeningPlanGeometry.DirectionHandle` 支持有平开窗扇的主面，按该扇的净范围计算黄色方向夹点。用扇的中间高度截取构造，避免固定上亮子的横框被误当成竖向边框，造成负净宽。高窗虽不切墙，仍可调整方向；纯固定窗不增加无效夹点，上悬窗不套用平开门夹点。
- 平面操作条的左右/内外翻转随支持的扇启用；右侧属性栏增加相同图标按钮，在三维视图也可使用。鼠标方向夹点仍支持直接拖动、松手提交，Esc 取消未提交草稿，Ctrl+Z 一次撤销。保留类型编号、洞口大小与原有实例事务规则。
- 窗的平面仍按窗的截面表达，不为窗添加门的开启弧。三维继续使用构造角度和上一增量修正的净扇合页轴；方向提交后主场景立即重建真实窗扇位置。
- 平开门主开启弧增加可选 `ViewLine.OpeningArcId` 与 `DASHED` 线型。投影、视图 JSON 与图纸排版保留标记，各洞口和排版单元的弧互相隔离。门扇、门框及方向箭头保持实线。
- 平面及插入选型预览将短线连成连续路径，使用原符号颜色 55% 不透明度及虚线；图纸使用浅灰蓝 `#91A0AB`，连续虚线纸面长 2 mm、间隔 1 mm，不随线宽变化而改变纸面长度。既有实体向内收线宽不变。
- CAD 落图把每条开启弧合成一条连续线型的多段线，保留真实毫米尺寸；仍使用规范管理的门窗图层及用户线宽。单独浅色及 `WL_OPENING_SWING` 线型，按视图比例换算 2/1 mm 纸面虚线，不误入墙体隐藏线图层。
