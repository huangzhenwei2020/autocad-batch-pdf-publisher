# CAD 楼层登记流程修正与原生定位验证

用户要求：登记沿用当前建筑模型；逐层拾取基点、框选平面；登记后直接生成建筑模型。门窗表来自框选的天正洞口，与门窗立面共用编号算法，具体做法可在门窗立面中后续调整。

## 最终实现

- 打开、保存、另存建筑模型时记录当前模型路径。登记窗口自动加载该模型楼层，移除“选择已有建筑模型”。楼层行分别提供“拾取基点”和“框选登记平面”，方向使用基点拾取时的 UCS X 轴，无需额外方向点。单位和模型基点设置折叠显示。
- 各层基点与登记结果持久化；取消不覆盖已有登记。标准层引用复用来源层几何，数量按实际楼层统计。生成前从当前源 DWG 重新读取已登记对象，旧登记不必重新框选；DWG 指纹通过 GUID 规范化比对，原始指纹保留用于稳定来源身份。
- 新增“门窗表（编号与尺寸）”，显示楼层、编号、宽高、数量、离地高度和定位状态，可编辑编号、尺寸或按尺寸编号。宿主句柄、内部 ID 和原始来源字段不出现在常规界面。
- 登记门窗表与 MCLM 门窗立面调用同一个编号函数。原生编号优先；缺号按类别及尺寸编号，例如 1500×2200 的门为 M1522。相同编号、相同尺寸合并；同编号不同尺寸按尺寸稳定排序添加 A/B 后缀，预留已存在的显式编号，避免碰撞。细微浮点误差不会拆成不同规格。
- 不要求先核对门窗类别或指定立面做法。缺类别按编号和洞口自身几何采用默认门/窗；未知底高使用明确的模型默认值，原生未知值仍保留未知。具体样式继续在 MCLM 中调整，登记和生成无需先打开门窗立面。
- 原生宽高来自已核验的只读 getter。编号只从该洞口自身递归展开的 TCH_TEXT、块及文字部件读取，不使用邻近标注。原生门扇开启圆弧可用于无编号门的默认类别识别。
- 自动查找附近的 TCH_WALL 和 TCH_CURTAIN_WALL，只保留已选墙和核验后的洞口宿主。普通墙使用原生定位曲线、左右厚度及墙高。直线轴向幕墙使用原生曲线与三维实体边界核验实际厚度、偏移和高度，不调用未核验 COM getter。
- 自动定位核验自身横穿墙厚的侧边、整宽框边，以及门扇圆弧和铰接端部线。门的开启半径结合实测门扇半厚恢复洞口宽度；双扇门还要求共享闭合点、两扇宽度之和与原生洞口一致。所有结果必须匹配唯一宿主与原生宽度；矛盾位置不自动采用。
- 几何部件不足时，只有原生洞口轴向边界宽度与洞口宽度一致、处于墙体和墙端范围内且宿主唯一，才使用该边界定位。文字扩大边界、旋转不明、尺寸不符或多宿主不当作可靠定位。人工定位保留并重新校验，异常对象仍可通过“补充门窗位置”处理。
- 表格编辑与重新读取采用暂存副本，校验成功后一次替换，并检查登记文件版本。取消、读取失败或并发修改不覆盖原登记；宽度修改会重新校验位置。
- “生成建筑模型”向当前模型窗口整批提交墙与洞口，刷新三维和平面并保存。一次撤销/重做同时覆盖构件及来源。完成请求即消耗，避免撤销或重开后重放；重复登记保持来源 ID 并替换旧导入，发现人工修改或删除时不静默覆盖。

## 实际验证

CAD2022 + T20 天正建筑 V9.0 中，对用户原 DWG 和已登记模型的副本作原生重新读取，原项目与源图未改写。

| 楼层 | 洞口 | 缺失定位 | 生成墙 |
| --- | ---: | ---: | ---: |
| 一层 | 26 | 0 | 35 |
| 二层 | 21 | 0 | 24 |
| 3层 | 7 | 0 | 14 |
| 合计 | 54 | 0 | 73 |

原生验证输出 NATIVE_GENERATION_OK walls=73 openings=54。此前旧快照有 40 个未定位洞口，现已通过幕墙宿主、洞口自身文字及门扇几何适配恢复，未要求逐个手工补点。单扇 1100×2200 和双扇 1500×2200 的真实圆弧、门扇样本均通过。

正式发布的 Avalonia 编辑器接收同一原生登记副本，完成整批导入、保存和三维绘制，输出 CAD_GENERATION_EDITOR_OK 和 AVALONIA_SNAPSHOT_RENDER_OK，且确认撤销可用、请求已消耗。截图：.artifacts/cad-floor-workflow-20261001/native-generated-model.png。该视角中心无构件，因此此轮验证实际模型绘制；GPU 拾取另在前面的合成登记用例通过。

- 建筑模型与天正只读探针原有逻辑回归通过。CAD2022 插件和 .NET8 插件编译通过；.NET8 为 0 警告、0 错误。

## 验证边界

后续发现原生 CAD 墙高与模型层高不一致时会出现层间空隙，现已改为登记墙随模型层高，门联窗改为闭合显示。该两项最终规则与新版发布目录见 [层高与门联窗显示修正](CAD登记层高与门联窗显示修正-2026-10-01.md)；上文原生墙高生成描述及旧发布哈希记录为前一轮状态。

本轮实机验证覆盖上述工程重新读取与生成；新建工程逐层连续拾取、全部天正版本和各类旋转、曲线幕墙未作完整实机验证。无法核验的曲墙、幕墙边界和墙底偏移仍明确报错，不能推测位置。轴网、楼板、柱和楼梯 CAD 自动转换不属于本次洞口修正。
