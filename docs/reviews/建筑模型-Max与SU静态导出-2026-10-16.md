# 建筑模型 Max / SU 静态导出

日期：2026-10-16。产品仍为 1.5.6。用户确认目标 Max 2024 / SketchUp 2026，并授权实现、测试和备份覆盖。本记录不将格式能力、SDK 回读和目标软件界面验收混为一谈。

## 当前实现

- 建筑模型“出图 → Max / SketchUp → 三维模型导出”。统一窗口选 FBX/SKP、整栋或指定楼层、附近原点或 CAD 原坐标、输出位置。SU 自动检测本机 2026，也可选安装位置。
- FBX 使用固定版本 AssimpNetter 6.0.5 的二进制写出器，不手写 FBX、不依赖 Blender 或 Max 授权才能生成文件。
- SKP 在独立任务的主线程调用用户已安装的 SketchUp 2026 C API（本机 26.0.429 / API 14.0）；毫米转换为英寸内部单位，文档显示单位设为十进制毫米并读回核对。没有捆绑、复制 Trimble DLL，不等于已取得可独立分发的 SDK。没有 SU 的电脑不能使用本轮 SKP 通道。
- 共同场景使用双精度毫米/Z 向上，楼层、构件、来源 ID、几何定义、实例及共享材质分开。仅在实际几何/材质相同才复用；不以门窗编号相同作为合并依据。源模型先取副本，不改变项目、标准层和图库。
- SKP 保留楼层组、构件组件/实例、透明玻璃；合并重复顶点，隐藏共面内部三角线，同一曲面按表面身份平滑，真实轮廓/孔洞/硬转角保留。
- FBX 原生写出库会展开共享网格、忽略部分自定义元数据；验证日志明确报告，界面计数采用实际回读网格数，不宣称 FBX 已保留实例。身份/原点同时写进可识别节点名与伴随构件清单。
- 每个模型输出附 `<文件名>.wanluo.json`，包含模型哈希、毫米单位、原点偏移、楼层和构件对应。不把这份清单当第二个图库，也不要求用户重新登记 CAD 平面。

## 保存与运行安全

- 同一程序一次只导出一个模型；独立转换子进程只运行无界面的导出入口。Windows Job 限额 2 GB，3 分钟超时，可取消；不停止其他进程，不自动打开 Max/SU 或进入材质/渲染预览。
- 文件生成后先真实读回，核对几何、单位、位置、层级、材质等，再按回执 ID 和 SHA-256 验证。原点很远且 FBX 单精度无法保留毫米精度时拒绝提交，提示改用附近原点；逐实例核对，不只比较整栋包围盒。
- 模型与清单在同一目标目录暂存，使用目标路径文件锁协调多个 Studio 进程。记录旧/新哈希和恢复日志，I/O 失败回滚；进程中断后，下次同路径提交先恢复/完成上次事务。发现其他来源改动时保留备份并提示，不盲目回滚用户新文件。
- 单次限制 200 万实例三角面/10 万构件；大文件建议分层。保护降低转换风险，不保证防止所有显卡、驱动、系统资源或电源故障。
- 构建暂存包不再结束原安装的后台同步；若构建输出目录对应的启动器仍运行则拒绝替换。正式安装继续要求当次关闭确认、进程复查和原目录备份。

## 验证

- 共同场景测试：范围、稳定身份、标准层复用、大坐标、孔洞、绕序、弧墙/楼板及取消，源模型不变。
- 实际子进程 FBX/SKP：整栋/单层、中文空格路径、原文件取消保护、失败保护、清单占用时回滚、哈希/身份清单。50 层标准层样例两种格式通过，SKP 复用几何定义。
- 两个测试进程并发提交 60 次，模型/清单哈希一致；模拟中断模型替换后的恢复通过。恢复先检查模型、清单两者及需要的备份，再执行任何恢复；外部编辑冲突时两者都不改的回归通过。FBX 内部构件的大坐标 1 mm 漂移必须拒绝，附近原点通道通过。
- 独立 Blender 5.2.1 后台导入 FBX：16 构件、1180 三角面，尺寸 7440 × 5640 × 6900 mm 保持，未自动打开交互视口或执行渲染。
- 导出窗口 560 × 500 / 800 × 660，格式切换、范围、FBX/SKP 实际按钮导出、取消关闭、源模型保持通过，截图为私有测试产物。
- 旧 GLB、建筑模型核心回归通过；正式 R24/R25 编译、25 图标、Studio 项目/模型管理、参照/登记/替换、图纸和 GPU 拾取回归通过。既有分析器版本和 Bitmap.Save 弃用警告保留，不宣称零警告。

### 未通过或未完成的外部验收

- Max 2024 Batch 在导入脚本执行前遇到 ADLM 授权检出错误，退出 -8。没有修改许可、登录或安全设置；不能宣称 Max 原生导入/保存重开已验收。脚本 `build/Test-BuildingModelFbx.ms` 保留供授权正常的环境复验。
- 以隐藏方式启动独立 SketchUp 程序打开合成 SKP 时未获得可操作窗口，已结束本轮自建测试进程，没有操作用户工程，也不据此判断文件损坏。SKP 的本机 C API 保存重开、组件/面/边/材质/尺寸核对通过，不等于 SU 交互视口验收。

## 能力边界

本轮是当前姿态的静态视觉模型，不输出动画、独立合页控制器、动态组件或 Max 参数墙；现有一樘门窗仍是一个构件网格，没有实现逐活动扇节点。原生 MAX 生成、精细部件拆分、跨软件改尺寸/开闭和反向更新待后续开发。外部图库资源的正式项目实例/变尺/运动、家具能力没有因新增导出自动完成。
