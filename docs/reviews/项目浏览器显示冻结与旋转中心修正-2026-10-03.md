# 项目浏览器显示、冻结与旋转中心

日期：2026-10-03。

## 行为

- 开始旋转不再自动把选中构件设为中心；当前相机中心与距离保持不变。显式缩放适应、选中构件取景仍保留。
- 浏览器构件、类型、楼层以及项目节点增加眼睛与锁按钮。眼睛控制显示，锁控制冻结；冻结不隐藏物体，但禁止浏览器/场景选择与通过当前选中对象编辑。
- Alt 单击眼睛独立显示该节点包含的构件；再次 Alt 单击同一眼睛全部显示。改为独立显示其他节点时立即切换。
- 父节点开关覆盖全部子构件，不受搜索结果过滤影响。部分子构件隐藏或冻结时父图标降低透明度表示混合状态。
- 标准层以实际楼层构件 ID 控制，各层可分别显示/冻结；平面视图映射回当前实际楼层的来源构件。
- 浏览器右边缘宽 6 px 拖动区调整宽度，范围 210–650 px，同时为场景预留空间；收起再展开保留当前窗口内设置的宽度。
- 控件位于固定右侧列，长名称省略并提供完整名称提示；左右拉宽可直接查看。
- 显示/冻结属于当前编辑窗口状态，不写入模型或改变出图模型。打开其他模型清除这些状态。标准层物理模型按模型版本缓存，搜索不重复展开标准层数据。

## 实现

- ModelViewport 保存完整场景和过滤场景；过滤后仍采用完整模型边界进行归一化，隐藏/显示不会重新定位相机。冻结 ID 从 GPU 拾取射线结果中排除。
- 平面实体、门窗符号、墙交接线和拾取同步采用显示/冻结条件。
- 控制按钮与原构件选择事件区分处理；点击眼睛、锁不触发门窗双击编辑。
- 图标使用现有 Lucide 素材库，保留原图形，仅采用程序现有颜色。

## Alt 点击事件修正

- 用户反馈 Alt 点击眼睛无效。原普通冒泡 `PointerPressed` 监听被 Button 已处理的事件跳过，未记录 Alt 状态；此前直接调用显示函数的检查未覆盖这个问题。
- 改为隧道阶段监听 `PointerPressed`，并接收已处理事件，保证按钮 Click 前记录本次按键状态。Click 完成后清除状态。
- 回归检查改为向眼睛按钮发送带修饰键、已处理的 PointerPressed 路由事件，再发送 Click 事件，覆盖普通隐藏/显示、Alt 独立/全部显示以及松开 Alt 后的普通点击。这是路由事件注入检查，不是操作系统鼠标输入。
- Release 编译通过（0 错误、3 个既有警告），原生窗口检查输出 `BROWSER_STATE_OK routedEyeClick altIsolate/all altRelease hide/show freeze/pick floor width=440 cameraStable modelUnchanged` 和 `AVALONIA_GPU_PICK_OK`。

## 隐藏楼层后悬空短线修正

- 根因：BuildingVolumeBuilder 为每层生成墙顶上方 2 mm 的墙交接辅助线（IsWallJoint），没有 ElementId；按构件隐藏时无法过滤这些线，所以独立显示后其他层的辅助线残留在空中。
- 三维 MeshSnapshot 不再加入 IsWallJoint 辅助线。保留 ModelMeshEdges 从真实多边形提取的边线及轴网；共享几何数据不改动，避免影响其他绘图用途。
- 增加渲染数据检查：仅含一条墙交接辅助线及一条普通参考线的体量，生成快照只剩普通参考线的两个顶点。
- Release 编译通过，浏览器原生窗口检查输出 `BROWSER_STATE_OK noWallJointGuides` 和 `AVALONIA_GPU_PICK_OK`；独立楼层截图 `.artifacts/opening-editor/browser-isolated-floor-ui.png` 已目视检查无悬空短线。
- 已替换本地运行版：119 个文件校验、替换 2 个文件、3 份配置未变。备份 `.artifacts/cad-auto-slabs/previous-runtime-before-wall-joint-guide-fix`，DLL SHA256 `5CF182BC7F30C3C1CC11C10E4E9878201E52ADB013DDB34B21ACDDC15DDF6282`。
