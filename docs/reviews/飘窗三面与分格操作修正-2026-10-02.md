# 飘窗三面与分格操作修正

## 问题与修正

原立面生成器把飘窗左右侧面展开到正面坐标范围以外，供 CAD 标注使用。三维构造与新编辑器把这些侧面也当成正面格子，再生成两侧，导致重复几何、越界校验和空白预览。现在正面只读取主面分格；左右侧面共用原立面的侧面布局生成函数，分别保存和编辑，切换面不会互相覆盖。

拖动采用按下时的视图比例和鼠标位移计算实际毫米，避免拾取偏差引起跳动。只有一个方向的中梃也能拾取；预览指示线采用实际吸附和钳制后的坐标。外框固定，邻格最小尺寸仍为原编辑器的 50 mm。

飘窗三维添加上下封板，默认厚度 100 mm，可在构造中调整；左右进深支持分别设置。存在可用本层楼板轮廓时，根据墙两侧内外关系确定伸出方向；没有可用轮廓时沿墙局部法向生成。

## 原分格编辑器操作对照

| 原门窗立面操作 | 三维模型编辑器 |
| --- | --- |
| 竖向、横向拆分，合并 | 已接入，保留原材料、开启和门扇身份规则 |
| 删除、恢复 | 已接入，至少保留一个未删除格 |
| 同行等宽、同列等高、所选居中 | 已接入，保留所选区域和外框尺寸 |
| 鼠标移动步长 | 0～1000 mm，默认 5 mm；0 为自由移动，应用后随模型保存 |
| 实际格宽、格高 | 右侧/下侧内部中梃优先，邻格随动 |
| 框料、中梃、安装缝、扇框/门套 | 采用共享立面参数和净面板边界 |
| 材料、开启方式、门扇身份 | 已接入原选项与分格数据 |
| 飘窗正面、左侧、右侧 | 独立编辑，共用原侧面默认算法 |
| 撤销、重做 | 编辑内撤销；应用后模型整笔撤销，含模板和移动步长 |

原立面的默认分格、框料和开启方式继续使用共享建议服务；三维进深、玻璃厚度、封板厚度属于新增建模参数。

## 验证

建筑模型与 CAD 登记回归通过。新增 TC1818 正面六格、左右各两格、不重复展开侧面、上下封板、楼板判定朝向、居中、等宽、吸附坐标、移动步长保存与撤销检查。

在隔离的实际 15 层项目中打开 TC1818，移动正面中梃、编辑左侧、切换右侧、返回左侧和正面均通过，二维及三维预览有效。最终整栋场景预览约 508 ms。截图位于 `.artifacts/opening-editor/bay-editor-main.png` 和 `bay-editor-left.png`。

R24 插件和模型程序编译通过，已替换本地发布目录，保留用户设置。测试与截图使用隔离模型副本。

独立 AutoCAD 2022 测试 DWG 的 22 项落图通过：1484 个尺寸、136 个旋转文本，无尺寸测量错误、无尺寸文字重叠、无 SOLID 填充，图纸间距至少 2100 mm，更新没有重复实体。
