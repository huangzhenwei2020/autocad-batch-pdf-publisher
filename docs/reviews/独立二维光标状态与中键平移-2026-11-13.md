## 光标规则

| 操作 | 光标 |
|---|---|
| 空闲绘图区 | 十字与拾取框 |
| 绘图指定点、指定框选对角点 | 十字 |
| 命令要求选择对象 | 拾取框 |
| 按住中键平移、PAN命令 | 四向移动 |
| 激活夹点后跟随落点 | 四向移动 |
| 命令栏文字与坐标输入 | I形文本光标 |
| 文件操作占用绘图区 | 系统等待光标 |
| 尚无图纸 | 系统箭头 |

中键松开后恢复当前命令的光标和落点状态。Esc、失去焦点、意外丢失鼠标捕获、切换文档及二维／三维切换时清理临时平移。鼠标移出绘图区后停止绘制十字与拾取框。

平移和夹点跟随采用Windows四向移动光标，为本轮交互选择。绘图、选择与空闲状态沿用MiniCAD视口渲染的十字／拾取框。

## 实现

- 在原生Session统一计算光标状态，由WM_SETCURSOR处理绘图区系统光标。
- 文本输入由WPF显示I形光标，原生刷新仅处理自身窗口或拥有鼠标捕获时的光标。
- 使用WM_MOUSELEAVE与TrackMouseEvent清除离开画布后的光标残影。
- 键盘和命令事件保留最近的鼠标位置，避免十字跳到左上角。
- PAN完成后忽略等待回收的工具状态，及时恢复空闲光标。
- 正常松键释放捕获与意外失去捕获分别处理，保留夹点第一次点击后跟随、第二次点击落点及Ctrl+Z撤销。
- 打开、新建、切换、关闭文档及解绑视口时结束临时导航，并释放本窗口的捕获。
