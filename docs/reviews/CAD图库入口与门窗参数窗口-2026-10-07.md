# CAD 图库入口与门窗参数窗口

日期：2026-10-07；产品版本保持 1.5.6。本轮只改 CAD 门窗平面来源的入口与参数交互，不冒充外部构件正式入库。

## 入口与参数

- CAD 功能区“建筑模型”组只新增一个“图库”按钮；经典菜单、快捷键设置页从同一 `FeatureRegistry` 同步。默认快捷键 `TK`，内部命令 `WLLIBRARY`。旧 `WLCOMPONENTPLAN` 兼容打开同一窗口。
- 窗口门／窗分开，各自保留块、编号、基点、方向、宽高与单位倍率草稿。未实现家具页，家具后续接入同一入口。
- 基点 X、Y、Z 可直接输入，也可在 CAD 拾取；拾取取消不清除原输入。选块取消同样不丢失之前的选择。
- 沿墙方向只选择正 X 或正 Y，不再拾取第二个方向点。
- 坐标与方向统一按打开窗口时的 UCS 解释，拾取结果先转 WCS 再转回该 UCS；宽高填写毫米，基点填写 CAD 坐标，单位倍率独立设置。非水平 UCS 拒绝打开，避免倾斜坐标系静默投影。
- 原生提取仍是只读事务，支持范围和整笔拒绝规则不变；保存窗口有父窗口，取消保存不写文件。导出失败在窗口内提示，不关闭、不丢失表单。
- 窗口 660×720、最小 520×690；控件统一 36 DIP，X／Y 坐标分行，状态区固定高度以防长路径挤掉表单。

## 验证

- `BatchPdfPublisher.ComponentPlan.Ui.Tests.csproj`：620×670、480×640 内容区的门／窗截图、输入、拾取、取消、类别隔离、X／Y 切换、无效宽高、单位倍率及控件边界通过。截图在 `.artifacts/component-plan-ui/screenshots`。
- AutoCAD 2022 CoreConsole：隔离临时数据库的线、圆弧、圆、多段线凸度、嵌套变换、镜像、非等比拒绝通过；新增 UI Y 方向、旋转 UCS 下 UI X 方向通过，输出 `CAD_COMPONENT_SOURCE_NATIVE_OK ... ui-Y ui-X-rotatedUcs`。
- 第一次无输入图纸的 CoreConsole 在退出时等待保存；仅结束本轮测试进程，没有覆盖工作区 `Drawing1.dwg`（其最后写入时间仍为 2026-09-30）。随后指定测试临时图纸重跑，退出码 0。第二次退出有 Autodesk 临时日志清理警告，不是提取失败。
- 原来源契约/GLB 测试及建筑模型核心回归通过，R24、R25 编译无警告、无错误。
- WPF 截图与按钮回调为独立窗口测试；CAD 内实际鼠标拾取与保存对话框仍需用户交互验收，不能称为 CAD 完整 UI 自动化已通过。
