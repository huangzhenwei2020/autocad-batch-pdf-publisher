# 建筑模型 G0：墙窗样例与 CAD 更新验收

日期：2026-09-27。范围：第一条“修改墙/窗 → 重算立剖面 → 更新既有 DWG 放置”的纵向链路。

## 自动金样

`BatchPdfPublisher.Tests/BuildingModelProjectionTests.cs` 中 `WallAndOpeningEditUpdatesElevationAndSection` 建立一层、长 5000 mm、厚 240 mm 的墙，窗中心沿墙偏移 2000 mm、宽 1200 mm，剖面在墙轴线外 140 mm。修改后墙长 6000 mm、厚 300 mm，窗中心偏移 2400 mm。测试锁定：窗的构件 ID 不变；立面窗锚点移动 400 mm、墙端延伸约 1000 mm；原本未剖到的 Y=140 剖面出现墙断面。它是几何与参数联动的可重复基线，不代替真实项目 DWG 人工核对。

## CAD 放置更新行为

`LTTZ` 现在按视图文件的规范化完整路径和视图 ID 识别同一来源，用 XData 给本次生成的线、文字、圆、标注、填充和项目图框块参照记录放置实例 ID 与插入点。再次选择同一视图时列出已登记实例，输入序号更新该实例，输入 0 另插一份。更新在同一 DWG 事务中先建新实体，再擦除旧实例的生成实体；未登记的用户补绘及该视图的其他放置实例不参与擦除。取消选择或插入点提示时不修改 DWG。

旧版本生成的实体没有身份标记，无法安全判断哪些线属于哪一次落图；第一次使用新版本时只能新增已登记的放置，旧图应由用户在备份 DWG 中人工清理。源文件移动/改名后路径键也会变化；正式图模关系应在下一阶段引入持久模型 ID、视图 ID、放置 ID 与版本登记，而不是长期依赖路径。

## 在 AutoCAD 真机上的待验步骤

用**临时 DWG 副本**和同一份生成的 `views/*.json`，不要直接在正式图纸首次验证：

1. 执行 `LTTZ` 首次插入，保存 DWG；在生成视图旁手工加一条可识别的辅助线。
2. 在建模程序中改墙/窗并重新生成视图；同一 DWG 再执行 `LTTZ`，选该视图、默认选择 1 更新。检查生成的旧墙窗线消失，新立面/剖面出现；手工辅助线仍在，图框只剩一套。
3. 再重复更新两次，检查生成实体数量没有持续增加；在 AutoCAD 中撤销一次，确认整次更新可还原。
4. 输入 0 在另一位置插入副本，再更新位置 1，确认位置 2 不动。取消选择与取消插点均不得新增或擦除实体。
5. 分别在 AutoCAD 2024/R24、2026/R25 复核；检查当前项目图框、无登记图框、含填充/标注的视图和大 DWG 中列表响应时间。

本次已通过纯逻辑测试及 R24/R25 发布编译；AutoCAD 宿主事务、DWG 撤销和实际性能尚未自动验证。正式宣布“CAD 视图受控更新可用”必须完成上述真机步骤。
