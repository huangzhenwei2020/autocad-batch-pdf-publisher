# 建筑模型 G1：Avalonia 视口首轮验收

日期：2026-09-27。状态：**Windows 本机 GPU 显示、选择、基础参数编辑及模型/视图文件往返通过；跨平台、大模型和正式建模功能未通过**。

[`BuildingModelStudio.AvaloniaProbe`](../../BuildingModelStudio.AvaloniaProbe/README.md) 引用同一个 `BuildingModel.Core`，从仓库现有双层住宅样例生成 276 个体量面。Avalonia 12.1.3 的 `OpenGlControlBase` 完成实际三角网格绘制。首轮 `--smoke` 曾返回 `AVALONIA_GPU_FRAME_OK`，现在增加拾取验证并返回 `AVALONIA_GPU_PICK_OK 2F-S`；合成器截图 `.artifacts/avalonia-probe.png` 可见墙体、屋面和门窗洞口，验证不是“网格已挂载但窗口空白”。鼠标左键拖动旋转已接入。

第二轮补上三维面到稳定构件 ID 的映射，以及 CPU 前端拾取。`--smoke` 在视口中心实际拾取到 `2F-S`，截图 `.artifacts/avalonia-edit-probe.png` 显示左侧选中的 `1F-S` 墙与视口橙色高亮一致。墙长和门窗沿墙定位通过共享编辑事务校验、提交、撤销/重做；非法参数不更新模型。纯逻辑测试已覆盖构件 ID 稳定及回滚。

第三轮补上文件打开/保存/另存为、未保存提醒、视口平移/缩放/复位。项目 `model.json` 修改后可生成同级 `views/` 中的立面、剖面、平面、门窗表和图纸文件；测试验证墙长改变传递到南立面，落盘视图可重读并被现有 `StudioLaunch.ListViews` 识别。构件选择改为 GPU uniform 高亮，不再因选择重建网格；编辑后的体量重建在后台计算，过期结果不覆盖新模型。截图 `.artifacts/avalonia-edit-save.png` 可见更新后的工具栏和模型。

真实窗口鼠标复测发现：直接挂在 `OpenGlControlBase` 上的指针事件未收到，最初的视口只会显示、不能用鼠标操作。改为覆盖透明输入区域后，在真实窗口里观察到左键拖动旋转、滚轮缩放及点击屋面后 `SLAB-ROOF` 属性和高亮同步。中键/右键拖动尚未被自动化工具实测。

下一轮将墙和门窗属性面板扩展为完整的基础尺寸编辑：墙长/厚/高、洞口定位/宽/高/窗台高一次校验后提交。测试覆盖同值提交、无穷数、窗顶越界、洞口重叠、撤销，以及门窗尺寸变化进入立面线稿。Release 构建和无界面 GPU 拾取检查通过。本轮真实窗口操作工具因无法确认窗口状态而中断，新的多字段面板仍需人工点击验收。

仍没有精确吸附、操纵柄、完整构件参数、正式可停靠布局或真实 CAD 自动更新。几何拾取逐三角形扫描，编辑校验仍在 UI 线程；尚未测帧时间、内存或大场景性能。视图文件生成只是复用现有中立格式，Windows CAD 里仍需显式取件/更新。Windows 当前构建有 Avalonia 分析器与仓库 .NET 8 SDK 编译器版本不一致的 `CS9057` 提示；将其列为工具链待办，不掩盖为“零警告”。

下一道关口：编辑过程预览与 Windows CAD 实际更新闭环，100%/150%/200% 缩放与窗口拉伸、核显/独显、macOS/Linux 真机启动，以及 1000/10000/50000 构件的首帧和旋转 P95。通过前不迁移现有建模程序。
