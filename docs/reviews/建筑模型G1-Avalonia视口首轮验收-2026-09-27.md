# 建筑模型 G1：Avalonia 视口首轮验收

日期：2026-09-27。状态：**Windows 本机真实 GPU 出图通过，跨平台与编辑功能未通过**。

[`BuildingModelStudio.AvaloniaProbe`](../../BuildingModelStudio.AvaloniaProbe/README.md) 引用同一个 `BuildingModel.Core`，从仓库现有双层住宅样例生成 276 个体量面。Avalonia 12.1.3 的 `OpenGlControlBase` 完成实际三角网格绘制。`--smoke` 返回 `AVALONIA_GPU_FRAME_OK`；合成器截图 `.artifacts/avalonia-probe.png` 可见墙体、屋面和门窗洞口，验证不是“网格已挂载但窗口空白”。鼠标左键拖动旋转已接入。

第二轮补上三维面到稳定构件 ID 的映射，以及 CPU 前端拾取。`--smoke` 在视口中心实际拾取到 `2F-S`，截图 `.artifacts/avalonia-edit-probe.png` 显示左侧选中的 `1F-S` 墙与视口橙色高亮一致。墙长和门窗沿墙定位通过共享编辑事务校验、提交、撤销/重做；非法参数不更新模型。纯逻辑测试已覆盖构件 ID 稳定及回滚。

此图仍只证明现有简化体量在此机可见、可选、能在内存改两个参数。没有吸附、正式保存、真正 Blender 式可停靠布局或精确剖切。拾取逐三角形扫描，选中后重建并重传整个网格；尚未测帧时间、内存或大场景性能。Windows 当前构建有 Avalonia 分析器与仓库 .NET 8 SDK 编译器版本不一致的 `CS9057` 提示；将其列为工具链待办，不掩盖为“零警告”。

下一道关口：编辑过程预览、视图/CAD 更新联动，100%/150%/200% 缩放与窗口拉伸、核显/独显、macOS/Linux 真机启动，以及 1000/10000/50000 构件的首帧和旋转 P95。通过前不迁移现有建模程序。
