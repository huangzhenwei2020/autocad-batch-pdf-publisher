# 楼层设置开放编辑

楼层标高可直接输入，已有构件的普通楼层也可修改标准层来源、删除。名称、层高和类型保持可编辑。

标高与层高保持联动：修改基准层标高时移动整栋；修改上层标高时调整其下方楼层的层高并推算更高楼层；修改地下层标高时调整该地下层的层高并向下推算。非法数值或非递增标高不能应用，不完整输入不改写正式模型。

改为标准层引用时，本层独立构件被来源层平面替换，避免两套实体重叠。改回独立层时保存当前实例，包括墙、门窗、楼板、柱、楼梯、屋面和房间。删除非空楼层同时删除本层构件和对应平面图；删除来源层后，其他楼层改为独立层并保留原实例。上述操作均在点击“应用楼层”后作为一次修改提交，支持撤销重做，取消窗口不修改模型。窗口说明和按钮提示明确告知来源替换、删除对本层构件的影响。

CAD 登记窗口和生成流程按当前模型对登记快照作协调，忽略已删除或改为引用的楼层，并使用最新楼层名称、标高和层高。旧式绝对标高楼板及其 CAD 来源基线随楼层同步移动，保持再次生成可用；其他人工几何修改仍保留原有保护。

验证：模型回归、CAD 登记回归通过；新增检查覆盖来源替换与独立层保留、七类构件的删除、图纸及来源基线处理、撤销重做、删除后再次 CAD 生成、旧式楼板标高修改后再次生成。实际三层模型的正式 Avalonia 窗口输入检查为 `STOREY_EDITING_UI_OK`，覆盖标高、层高、来源选择、非空来源层删除、无效输入、取消和地下层。R24 完整发布和 .NET 8 插件编译通过；保留已有的两条 Avalonia CS9057 分析器版本告警。
