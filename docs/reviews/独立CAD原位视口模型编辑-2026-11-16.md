# 独立 CAD 原位视口模型编辑

版本保持1.5.6，接续已安装的最大化视口编辑。

## 操作

在布局内双击平面视口进入原位编辑，保留整张布局和其他视口。功能区“视图 → 布局视口 → 原位编辑”、底部“视口编辑”和MSPACE也可进入，多视口通过选择窗口指定目标。

双击当前视口外返回纸空间，双击另一个视口切换目标。PSPACE、底部“返回布局”可结束原位编辑。VPMAX／MSPACE可在最大化与原位模式间切换。Esc取消当前草稿，已应用的模型修改使用Ctrl+Z撤销。

锁定视口中仍可绘制和修改模型，中键和滚轮操作纸面视角。未锁定时，中键修改模型中心、滚轮修改视口比例，每次手势可撤销，Esc恢复尚未提交的平移。纸空间对象按原坐标显示，模型修改更新共用模型及其他视口。

## 实现

- 每个文档保留临时原位模式及原布局归属，共用原Scene、模型实体和撤销栈。
- 原编辑器通过独立交互相机转换旋转、比例和模型中心，拾取、捕捉、绘图、属性及夹点沿用既有入口。
- 纸空间显示和模型交互反馈分别渲染。纸面静态内容按几何版本刷新，模型反馈只生成选择、预览、夹点和捕捉等动态流。RGBA纹理使用预乘透明度合成，并按视口边界精确裁剪。
- 拾取几何使用原有线、填充及点裁剪逻辑，顶点按局部原点转换以保持大坐标精度。凹口、圆形边角的隐藏几何参与选择过滤，捕捉点也限制在有效边界内。构造线与射线沿用可见延伸段的拾取。
- 临时编辑状态、显示模式和反馈轮廓属于运行会话，DWG／DXF继续写入原生模型、布局、视口及裁剪引用。
- 离开模式或切换文档时清理纸面编辑器及对应显存缓存，窗口调整时同步交互相机和渲染目标。
