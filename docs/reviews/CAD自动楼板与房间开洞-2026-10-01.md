# CAD 楼层登记自动楼板与房间开洞

登记窗口新增“楼板厚度 mm”，默认 100。按登记范围内完整的天正墙、幕墙实体围合轮廓自动生成楼板，边缘收至每段外围墙的实际内侧，保留凹角、斜墙和墙轴偏心；不使用外包矩形或凸包代替建筑轮廓。板顶跟随本层标高加层高，板厚向下，在本层墙顶封口。标准层引用复用轮廓及洞口，但板顶按引用层自己的层高计算；楼层标高、层高变化后同步跟随。旧手动楼板的绝对标高和楼层基准偏移保持原语义。

墙默认厚度为 200 mm，模型中新画墙也采用 200。天正墙已能读取实际厚度时保留原图数值。缺失墙厚的默认值是毫米数，不再按 CAD 源单位重复换算。

读取 TCH_SPACE、TCH_TEXT、TCH_MTEXT 和普通文字的实际文字位置；名称包含“楼梯”“电梯”“井”的房间，按墙体围合形成的净空轮廓开板洞。重复标签不重复开洞。外边界上的凹口直接保留空缺。能读到天正房间自身面积时，用其检查明显错误的连通区域，避免缺墙时将整层空间误切成洞口。未形成闭合范围、找不到内部边界或面积明显矛盾时提示具体原因，不猜测矩形洞口。

生成前重新按已登记范围读取完整墙体，补齐旧登记漏掉的幕墙；范围检查支持旋转框。所有读取只用已适配的墙属性和实体展开，不枚举未知天正 COM getter。

楼板随墙、门窗整批生成、保存和撤销。来源基线包含楼板及板洞，重复生成替换已有登记楼板；人工修改或删除登记楼板时停止覆盖。板厚保存到登记文件，拾取基点、保存楼层、门窗表及原子刷新不会丢失设置；旧登记文件默认 100 mm。楼板编号与手动楼板避让，不在不同独立楼层重复编号。

楼梯、井道板洞从房间净空向外扩至周边墙体靠楼板一侧的墙面，按每段墙的实际厚度处理，避免楼板覆盖洞口周边墙顶。与板边相接的区域合并为外轮廓缺口；内部区域保留独立板洞。布尔运算前后统一到 0.001 mm 精度，避免天正墙端点的浮点误差造成相接洞环或零宽狭缝。

平面轴号圈和文字使用模型尺寸，按场景比例缩放；轴线端点使用建筑整体范围或用户设置的实际范围，缩放适应包括轴号范围。墙、门窗及楼板参数有效时实时刷新平面和三维预览，不改写正式模型或撤销历史。连续输入只显示最新结果，不完整或非法输入保留最后一次有效预览。应用提交一次修改，取消或 Esc 恢复。门窗、墙属性标题显示业务编号和楼层/宿主墙编号，去掉内部构件 ID。

## 验证

- 合成测试：凹形外轮廓、斜墙、大坐标、偏轴墙角、分离建筑、开口墙、重复房间名、关键字、面积矛盾、CAD 米单位、100/200 默认值、标准层、板厚持久化、重复导入、人工修改保护及撤销/重做通过。
- 实际 CAD2022 + 天正 T20 V9 源 DWG 副本：一层 38 面墙，二层 26 面墙，3 层 23 面墙；生成 3 块楼板，贴外围墙的楼梯区域转为外轮廓缺口。读取到的 4 个楼梯间位置全部不被楼板覆盖；三个登记快照 DBMOD 均为 0 → 0。门窗仍为 54 个。合成图纸另行验证内部井道仍保留独立板洞。
- 正式发布编辑器接收同一实际登记副本：`CAD_GENERATION_EDITOR_OK`；保存、可撤销、请求消耗和 GPU 楼板拾取通过。楼板绘制、编辑、开洞、取消、删除、复制及撤销/重做检查为 `SLAB_UI_CHECK_OK`。
- 不同外墙厚度的内收距离、贴外墙楼梯缺口、不同层高的标准层引用、修改楼层标高/层高及撤销通过。正式编辑器参数预览检查 `PARAMETER_PREVIEW_OK` 覆盖门窗、墙、楼板、连续输入、非法输入、取消、应用后一次撤销及 GPU 刷新。
- 建筑模型原有回归、CAD 门窗登记回归通过；R24 完整发布及 .NET 8 插件编译通过。Avalonia 编译有既有的两条 CS9057 分析器/SDK 版本告警，功能检查通过。
