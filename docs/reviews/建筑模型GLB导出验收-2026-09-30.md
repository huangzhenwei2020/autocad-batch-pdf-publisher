# 建筑模型 GLB 导出：第一阶段验收

2026-09-30，“出图”Ribbon 增加导出整栋 EG、导出当前楼层 EF、取消导出。当前楼层取平面视图楼层选择。导出使用编辑快照，在后台生成；不保存或修改模型 JSON。文件在同目录暂存，完整写入后原子替换，取消或失败保留旧文件。

追加“导出后用 Blender 打开”选项，默认开启，记住本机勾选状态和 Blender 路径。使用参数列表启动新 Blender 进程，由随包导入脚本加载 GLB 并适配视口。本机 Blender 5.2.1 已通过脚本导入检查；找不到程序时可手动选择，取消或启动失败不影响已导出的文件。

## 格式与身份

- SharpGLTF.Toolkit/Core 1.0.7 写入自包含 glTF 2.0 二进制文件，LibTessDotNet 1.1.15 对面多边形剖分，包含凹楼板。
- 毫米 Z 向上转换为米 Y 向上：`(x, y, z) → (x/1000, z/1000, -y/1000)`。不重新居中，保留建筑坐标原点。
- 层级为建筑 → 楼层 → 构件。节点 extras 保存 storeyId、elementId、sourceElementId、楼层标高与标准层来源；标准层实际实例 ID 与来源 ID 分开。
- 每个构件保留独立网格，材质按体量类型分组。导出基础色、粗糙度和玻璃透明度，不导出视口参考轴线或临时选择高亮。
- 第三方许可证随建筑模型发布到 `licenses/BuildingModelInterop-LICENSES.txt`。

## 已通过

- `BatchPdfPublisher.BuildingModel.Interop.Tests`：整栋/单层范围、包围盒、坐标、法线与绕序、表面积、楼层层级与 ID、标准层实际标高和来源 ID、原子覆盖、取消保留旧文件、非法楼层、凹楼板 3 平方米面积。
- 建筑模型现有纯逻辑回归测试通过。
- 本机 Blender 5.2.1 LTS 实际导入样例 GLB：2 层、16 个构件、1460 个三角形，尺寸 7.44 × 5.64 × 6.90 米；保留楼层与构件自定义属性。
- Blender 重新导出后，再由 SharpGLTF 读取，三维包围盒、表面积与法线保持一致。南墙窗洞与实墙位置通过 Blender 射线检查。

## 限制与下一步

外部门窗资产导入和用户材质编辑尚未实现。当前导出几何精度遵循建筑体量模型，窗框/门扇仍为程序化几何。超大模型导出性能、macOS/Linux 文件覆盖、其他三维软件实机导入仍待验。下一步先实现受控 GLB 资产加载、单位/轴向/原点适配、门窗类型关联及资产缺失回退，再扩展 PBR 材质预览。
