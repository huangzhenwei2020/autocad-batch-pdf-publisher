# Blender 共面多边面导入

- GLB 作为传输与实时渲染格式仍输出三角面。导出并自动打开 Blender 时，对各构件独立执行 BMesh 共面边溶解，而不是仅隐藏边线。
- 在每个构件内部合并重复位置顶点（米制容差 1e-7），使用 0.05 度共面角容差兼容导入浮点法线精度，保留锐角与材质分界；存在 UV 时保留 UV 分界。不跨构件或楼层合并。
- 开洞平面不能用一个带孔 Blender 多边面表示，因此保留必要连接边，不承诺所有平面只剩一个面。GLB 手动导入不会运行此清理脚本；重新导出 GLB 也会再三角化。
- Blender 5.2.1 后台实测：样例 464 面变为 204 面，生成 n-gon。逐构件表面积、洞口射线、米制包围盒、16 个构件身份及两层父子结构检查通过。
- 测试入口 `build/Test-BuildingModelGlb.py`，推荐加 `--python-exit-code 1`，避免 Blender 的脚本异常被进程默认零退出码掩盖。
- 后续 OBJ/DAE 导出应直接携带多边面，避免依赖 GLB 作为编辑拓扑格式。
