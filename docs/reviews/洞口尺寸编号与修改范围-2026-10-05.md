# 洞口尺寸、编号与修改范围

日期：2026-10-05。接续修改门高闪退修复，保持产品版本 1.5.6。

## 原因与处理

- 分格设计是模态窗口，不能操作后面的主属性栏；此前分格窗口只有格宽/格高，没有整体洞口宽高。现已在其右侧增加始终可见的“洞口尺寸”，修改后同步二维分格、三维构造和宿主墙洞口。
- 主属性栏增加“洞口尺寸修改范围”，默认仅当前樘。按用户后续确认，单樘与同编号全部的尺寸变更均按新尺寸更新编号，不能再保留旧尺寸式编号。尺寸式编号按新尺寸生成，自定义编号保留前缀并追加字母。
- 新编号已存在时，在正式提交前弹窗选择“并入已有类型 / 加后缀新建 / 取消”。合并沿用已有编号的分格、材料和构造，不修改已有门窗；加后缀新建保留当前做法。已有类型或实例的实际宽高/类别不匹配时禁止合并，不能仅以四位尺寸式编号相同判定兼容。
- 分格窗口默认勾选“仅当前樘”；取消勾选则应用到同编号全部。分格比例及开启、材料参数随新尺寸保留，不覆盖其他类型。
- 批量提交先验证全部受影响实体的宿主墙、洞口范围、楼层高度和构造。任何一处无效，整批不提交；有效修改一次撤销即可恢复。位置、窗台及门槛仍是当前位置参数，不随编号批量移动。
- 同编号批量修改重建全部受影响的三维场景，不能仅更新选中门窗的网格。模态预览尺寸变化时也重建墙洞，避免门窗变大但墙洞仍旧。
- 草稿门窗深复制，取消恢复模型和画面；范围切换会重新预览，主属性栏展示实际尺寸预览编号。
- 主属性栏的编号字段随洞口尺寸草稿自动显示预览编号；尺寸草稿期间不允许单独提交这个编号，防止尺寸未应用、编号先改的错配。重名提示取消后保留参数输入和草稿，不生成撤销事务。分格窗口同样使用这一决策，校验失败不关闭编辑器。
- Esc 仅取消当前命令或未提交草稿，不执行模型 Undo；Ctrl+Z 才撤销已提交修改。原按键处理未发现 Esc 调用 Undo，此次用连续 Esc、已提交尺寸之后的新草稿取消及真实 Ctrl+Z 路由作了回归验证。

## 标准层边界

标准层共用一份平面。当前樘的尺寸修改对应当前源平面这一位置，所有共用层该位置同步；UI 明确提示“洞口共用层同步”。若只改一个实体楼层的洞口几何，应先解除该层共用。本次没有添加独立楼层的洞口几何覆盖字段。

保持尺寸不变的构造编辑仍走原有实例覆盖逻辑。本次不修改原 CAD DWG 中门窗块编号；模型保存、门窗表及后续图纸生成使用修改后的模型编号。
