# 独立 CAD 透视视口导航

在布局的“调整内容”或 `VPVIEW` 中，单击透视视口后，可用中键平移和滚轮缩放。平移基于相机目标平面。滚轮联动焦距和视图高度，保持目标平面上光标所在位置的投影稳定。视口边框、观察方向、目标点、旋转和前后裁剪参数保持原值。锁定视口或者锁定视口所在图层可保护视图。

每次完整拖动或滚轮操作可撤销、重做。拖动期间按 Esc 或失去鼠标捕获会恢复拖动前的观察位置。本批覆盖线框导航。透视视口内绘图、最大化编辑和着色待接续。

## 透视视口内移动与复制

在布局的“视图 → 透视视口”中选择“透视移动”或“透视复制”，也可输入 `VPMOVE` 或 `VPCOPY`。依次点选透视视口、一个模型点或直线、基点和目标点。移动在指定目标点后完成。复制可连续指定多个目标点，按 Enter 或空格结束。每次落点都可以单独撤销。

鼠标可捕捉可见的模型特征点。基点无捕捉时取当前工作平面交点，目标点无捕捉时取经过基点且平行于工作平面的交点。也可直接输入世界 XYZ 或相对基点的 `@ΔX,ΔY,ΔZ`。移动预览及点选遵循视口边界和前后裁剪。原实体的图层、颜色等属性随移动或复制保留。图层锁定限制编辑，视口相机锁定继续保护相机参数。
