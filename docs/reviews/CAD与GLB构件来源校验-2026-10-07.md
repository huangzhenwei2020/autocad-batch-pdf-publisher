# CAD 与 GLB 构件来源校验

日期：2026-10-07。阶段为 P2a 来源提取与只读校验，不是完整外部构件导入/放置，也不是正式部件配对编辑器。

## 用户入口

1. CAD 命令 `WLCOMPONENTPLAN`：选门窗块，拾取洞口左端墙参考线基点和沿墙从左到右方向，输入编号、门/窗类别、毫米宽高、一绘图单位对应毫米数；输出 `.wlplan.json`。
2. 3ds Max 使用自己的 GLB 导出流程。检测到本机安装 3ds Max 2024，其 [官方实时导出器](https://help.autodesk.com/cloudhelp/2024/ENU/3DSMax-Interoperability/files/GUID-834F8D09-88D8-44A3-99C1-BC88370EA02A.htm)提供 GLB 选项。本阶段接受无贴图、无动画/蒙皮、无必需扩展、完全自包含的静态三角网格。
3. 模型程序“管理 → 构件校验”，或程序命令 `WLASSETCHECK`：选择 CAD 符号和 GLB，查看二维/三维、节点、毫米尺寸、宽高差和模型最小点；可导出 JSON 校验报告。

当前报告状态明确为 `SourceInspectionOnly`，不是 `.wlopkg` 或项目资源引用。MM 参数公共库仍不接受外部资源包；没有配对保存、自动缩放、部件绑定或外部实例放置。项目与输入文件不会因校验而改变。

## 实现边界

- CAD 原生提取 LINE、ARC、CIRCLE、带 bulge 的 LWPOLYLINE；传统二维多段线经 CAD 原生 Explode 读取线/弧，若得到不支持对象则拒绝。递归读取静态/当前有效块形态，保留来源路径、层和线型信息；处理嵌套变换、水平基点、毫米比例和镜像弧方向。不写 CAD 数据库。
- 文字、常量属性及可见属性单独记为候选，不把编号烘焙进静态符号；本阶段尚不自动选择哪个候选是实例编号锚点。
- 跳过不可见实体及关闭/冻结层；外参、未知/代理/三维实体、不在同一水平面的数据、非等比缩放或剪切后的圆弧给出拒绝清单，不导出残缺文件。不声称支持动态块参数、椭圆、填充、标注、图像或所有代理对象。
- `.wlplan.json` 保留原生圆弧/圆参数。只有检查画布的弧会细分，圆仍用圆对象。画布采用可见的像素细线，绝不改变文件坐标和图纸正式线宽规则。原图层/线型目前作为来源记录，没有完成规范用途映射与正式 CAD 出口。
- GLB 读取复用 SharpGLTF 1.0.7；保留父子世界变换和稳定节点索引，按 [glTF 坐标/单位规范](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html#coordinate-system-and-units)转换为毫米、Z 向上；负比例节点反转绕序，检查平面法线。预览是中性色、平面法线，不是原材质/透明/PBR 或平滑法线还原。
- GLB 首阶段限制：32 MiB 文件、2 MiB JSON、256 节点、300000 实例顶点、100000 面、32 层节点嵌套；拒绝任意 URI、贴图、必需扩展、动画、蒙皮、变形、非三角网格、退化面、奇异变换、非有限/超限坐标。解码和 GPU 网格准备异步、可取消；失败保留上一有效预览，窗口关闭取消任务。
- CAD 符号限制：2 MiB、8192 图元、256 文字候选、16 层块嵌套/20000 遍历对象；源 JSON 与预览复杂度有上限。导出符号及报告采用临时文件替换，报告禁止覆盖输入来源。

## 验证

- `BatchPdfPublisher.ComponentSources.Tests` 通过：原生符号/圆弧/圆/文字候选往返、单位与方向、镜像弧、非等比/非平面拒绝、失败保存保留旧文件；GLB 层级/负比例、毫米坐标、法线、取消、URI/扩展拒绝、来源不变。
- AutoCAD 2022 Core Console 原生 `WLCOMPONENTPLANQA` 通过：线、弧、圆、bulge、多层块、旋转、比例、镜像、文字候选、非等比圆弧拒绝。测试只创建临时 side database，不使用用户图纸。首次相对 DLL 路径失败，改用受控临时目录绝对路径后执行成功；Core Console 命令写出 `CAD_COMPONENT_SOURCE_NATIVE_OK`。
- 900×650 和 1280×800 原生检查窗口通过：实际 GPU 网格和节点拾取、预览最小尺寸、错误资源保留有效状态、项目与源文件字节不变。截图 `.artifacts/component-sources/source-ui-900x650.png`、`source-ui-1280x800.png`。
- 原核心门窗、鼠标操作/虚线窗表示/图库、CAD 登记、参数公共资源包回归通过。模型程序和 R24/R25 编译完成；仅保留既有 Avalonia 分析器版本和 Bitmap 过时警告。
- 本机 3ds Max 2024 的独立空场景 batch 测试停在 `License Startup Error`，返回 `[ADLM] 20: Generic license checkout error`，没有执行导出脚本。只终止已核对父子身份的本轮空场景测试进程，未动用户场景、授权或安全偏好。不把合成 GLB 测试冒充 Max 实机导出通过。
- Max batch 样例脚本 `build/Test-MaxComponentSource.ms` 只供新空场景测试，拒绝覆盖输出/读取既有场景；实际 Max 输出仍需授权正常环境验证。
