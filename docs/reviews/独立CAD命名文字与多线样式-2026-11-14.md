# 独立 CAD 命名文字与多线样式

版本 1.5.6。按用户要求先编写 [二维／三维构件联动清单](../plans/独立二维三维构件联动-2026-11-14.md)，随后继续 MiniCAD 阶段 C。本批为命名样式首批接入，安装状态在下文单独记录。

## 入口与操作

“标注 → 命名样式”增加文字样式、多线样式图标，命令行支持 `STYLE`、`MLSTYLE` 和 `MLS`。原生 Editor 的样式请求经 WPF 参数窗口处理，支持选择现有样式、设为当前、修改参数及以所选样式新建。

文字样式可设置名称、主字体、SHX 大字体、固定字高、宽度因子和倾斜角。提供字体文件选择，保留原有缺字形字体回退。固定字高为 0 时沿用绘图字高；固定字高用于后续新建文字。引用该样式的文字随字体、宽度和倾斜角刷新。

多线元素通过表格编辑偏移系数及 ByLayer／RGB 颜色，支持末行新增和 Delete 删除元素行，并可设置描述、起终点封口和顶点连接线。实体沿用上游样式快照规则，修改命名多线样式供后续绘制使用，已绘多线保留已有形状。

新建／修改／当前样式操作作为文档命令进入原生撤销栈，Ctrl+Z 与重做恢复样式表、稳定 ID 和当前选择。重复名称和无效参数保留窗口供修正，取消关闭原生请求。

本批首阶段完成后，后续批次已接入样式重命名和删除，见 [图层线型、剪贴板与外参接续](独立CAD图层线型剪贴板与外参-2026-11-14.md)。文字／多线实体批量换样式继续列入阶段 C。

- 修复同格式同版本保存时未被实体使用的新建文字样式被跳过的问题。

- 修复导入已有 Standard 多线样式时因重名添加失败而丢失记录映射的问题。
