# 批量打印页码、多选移动与界面适配

2026-11-10，产品版本 1.5.6。本批已通过正式构建、安装前后回归及原目录备份覆盖。

## 功能与操作

- 图框登记增加“序号／页码”的属性映射和默认值。扫描同时读取图块实例属性和常量属性定义，兼容中文及 PAGE_NO、PAGE_NUMBER 等标签。旧登记的空映射可自动识别，显式空字符串表示停用映射。
- 图纸列表增加可编辑“序号／页码”列。默认按自然数字升序排列，例如 1、2、10，空值放在后面。手动调整后切换为自定义顺序并保存。
- 可选择“布局在前，模型在后”。有布局 TabOrder 时按 CAD 标签顺序排列，旧记录缺少该字段时使用布局名称自然排序。
- CAD 文件和子项目列表支持拖动排序。文件拖动同步调整各子项目内的图纸顺序，保留同一文件内部的相对顺序。子项目拖动同步发布顺序，文件及发布勾选状态随原条目保留。
- 图纸支持 Shift 连续多选和 Ctrl 间隔多选。所选图纸可整组拖动、上移、下移、移到顶部或移到尾部，保持原有内部先后顺序和移动后的选中状态。窗口显示快捷键及选中数量。
- 移到顶部／尾部作用于当前子项目。筛选后的上移／下移按当前可见列表移动，隐藏条目所在位置保留。跨子项目拖动由当前子项目范围限制。
- 按钮统一文字测量和绘制边距，按文字与图标计算尺寸。头部和图纸工具栏按实际宽度换行，换行后重新计算高度。修正缩放时下拉框宽度归零及左侧列表挤压问题。

## 持久化与兼容

ProjectProfile 增加 BuildingOrder 和 SheetSort。CAD 文件顺序沿用 CadFiles；图纸沿用 Order，并增加 PageNumber、SourceLayoutOrder。启动器链接同一模型定义，因此发布时一起更新启动器和两代 CAD 程序集。

保存、扫描合并、重新打开及 PDF 最终合并使用同一套已保存顺序。已有页码、图号、名称、纸张和来源数据随条目保留。

## 换电脑接续

正式构建入口为 build/Build-Release.ps1。使用项目既有依赖和原目录自包含运行环境，按 docs/BUILD_AND_INSTALL.md 交付。

非 CAD 检查可运行下列命令。

```powershell
dotnet run --project BatchPdfPublisher.Tests/BatchPdfPublisher.ProjectStore.Tests.csproj -c Release
dotnet run --project BatchPdfPublisher.Tests/BatchPdfPublisher.CadLoad.Tests.csproj -c Release
dotnet run --project BatchPdfPublisher.Tests/BatchPdfPublisher.ComponentImport.Tests.csproj -c Release
```

CAD 宿主检查先取得用户批准，本机仅使用 AutoCAD 2022。在用户同意的临时图和独立配置范围内执行以下入口。

```powershell
./build/Test-PublishingNative.ps1 -PluginAssembly ./dist/WanLuoArchitectureTools/CadApi/R24/BatchPdfPublisher.dll -UserApproved
```

该入口包含页码、布局、排序持久化、多选移动和大小窗口回归。测试程序集文件名沿用仓库已有的内部访问友元名称。
