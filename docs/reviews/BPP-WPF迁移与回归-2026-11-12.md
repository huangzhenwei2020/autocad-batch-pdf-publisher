# BPP WPF 迁移与回归

版本为 1.5.6。本轮范围包括批量发布主窗口、项目管理、图框管理与登记、创建／插入图框、插入目录、框选发布和发布问题列表。

## 界面与代码

- 主入口 `BPP`／`BPPUBLISH` 及对应功能区操作已接到 `PublisherWindow`。主窗口在 CAD 返回空闲后创建，使用 WPF 非模态宿主。
- 相关业务窗口位于 `BatchPdfPublisher/Features/Publishing/Views/Wpf`，XAML、交互代码及共享主题分别组织。
- 发布、工程保存、图框、目录和扫描业务复用既有 ViewModel 与服务。文件夹选择与 CAD 颜色选择通过原生对话框完成。
- 图纸列表支持扩展多选、整组拖动、上移／下移、移到顶部／尾部、筛选和保存顺序。CAD 文件与子项目列表接入既有拖动排序逻辑。
- 工具栏采用换行布局，三栏支持分隔条调整。主窗口、项目窗口及各参数窗口进行了普通与较小尺寸检查。
- 实际 PDF 预览使用既有打印服务生成，转换为冻结的 WPF 图像。预览与发布期间有忙碌状态和关闭保护。
- CAD 点选、框选、目录插入和发布通过命令上下文执行。模型来源文档关闭后，关联的 CAD 操作窗口会退出。
- 图框属性映射含子项目、图号、图名、比例、序号／页码。目录和图框创建读取既有参数格式。

## 构建与测试

正式入口为 `build/Build-Release.ps1`，R24 使用 AutoCAD 2022 API 编译，R25 编译通过。发布图标检查通过。

本轮用户已批准 CAD 2022 临时图与独立万落配置测试。新增可重复入口如下。

```powershell
./build/Test-PublishingWpfNative.ps1 -PluginAssembly <R24插件路径> -UserApproved
./build/Test-PublishingWpfNative.ps1 -PluginAssembly <R24插件路径> -UserApproved -Desktop
```

以后每批 CAD 宿主测试仍须先取得用户批准。桌面测试使用新建图纸，桌面上需要处理的宿主提示应按其实际内容检查。

已验证的项目包括以下内容。

- 1000 张图纸加载、连续三次打开／关闭、保存后重开、两张图纸整组移到顶部与尾部。
- 快速比例修改及多选保留，主窗口较小尺寸布局。
- 项目、图框、创建图框、框选发布、目录和问题列表窗口构造与渲染。
- 图框登记窗口的 `PAGE_NO` 映射和默认页码保存。
- CAD 2022 桌面上的正常 BPP 入口、真实 PDF 预览、WPF 框选发布按钮的合并 PDF 输出。
- 发布测试回读一页 A3 PDF，页面误差容许值为 0.5 mm，覆盖驱动将 PDF 页面边界量化到整点的情况。
- 工程存储、旧登记、页码与排序相关非 CAD 回归共 46 项通过。

桌面自动化的阶段调度采用 WPF DispatcherTimer，实际产品入口仍通过 CAD Idle 打开。测试结束仅关闭本测试新建的图纸与宿主进程。
