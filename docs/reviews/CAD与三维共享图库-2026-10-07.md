## 使用流程

- CAD 功能区仍只有“图库”一个入口，打开门/窗管理窗口；“平面入库”选择块，指定编号、毫米宽高、基点、X/Y 与单位换算，直接保存共享目录。
- 选择记录后“插入 CAD”，选择当前 UCS 的 X/Y、单位换算并拾取插入基点。生成可复用块，保留原生 LINE/ARC/CIRCLE、可编辑编号属性 `WL_CODE` 与隐藏资源属性 `WL_RESOURCE_ID`；图层按插件门/窗及文字规范管理，几何 1:1，不爆炸成散线。
- 更新原记录保留资源 ID，预填原编号/尺寸。重复编号不默默覆盖，要求选择原条目更新或改新编号。取消拾取不插入，不误报成功。
- 模型“管理 → 图库”同步同一本机目录；CAD-only 资源显示真实平面及“待补充三维”。选择“补充三维”自动预载 CAD 平面/编号/尺寸，仅载入 GLB、指定三维基点和部件。没有平面文件选择步骤，不新建另一条资源。
- 已配对记录可直接继续编辑原模型；发布多次为同一 ID 的不可变载荷修订，图库只显示一条当前记录。平面变化会保留旧模型但标记待复核，过期作者窗口不能覆盖更新后的 CAD 记录。

## 数据与兼容

共同默认目录 `%LOCALAPPDATA%/WanLuo/ComponentLibrary`；测试用 `WANLUO_COMPONENT_LIBRARY_ROOT` 隔离。共享索引在 `records/<AssetId>.json`，含原生平面、记录版本、平面哈希和模型修订/包哈希/配对平面哈希。CAD .NET Framework 与模型 .NET 8 编译同一份契约。

索引采用跨进程排他写锁、乐观版本校验和原子替换；限制 JSON 大小/图元/路径链接，坏记录隔离显示，写入时不忽略坏记录绕过编号冲突。完整旧 v2 配对原 ID 一次迁移，不产生平面已写、模型未关联的半成品；有共享记录时不自行覆盖 CAD 编辑。包文件是内部几何载荷与历史兼容，不再是主入库操作。

旧参数门窗、项目模板和 MM 保持原生成路径。家具类别的静态资源契约兼容，CAD 当前制作 UI 仍只开放门/窗。外部三维资源的项目实例放置、可变尺寸、部件运动/开闭、材质、原生 MAX 读取与跨电脑云同步未完成；本轮不能作为这些功能的验收。
