# LTTZ WPF 视图选择首轮验收

`LTTZ` 在图形 AutoCAD 中改用 WPF 模态窗口选择待落图视图；再次选择同一视图时，用第二个窗口点击已有位置或“另插一份”。待落图仍排最前，选择后继续在 CAD 图面指定插入点。取消选择不进入落图事务。

验证环境：R24 使用 AutoCAD 2022 API，R25 使用 AutoCAD.NET 25.0.1。两组发布构建通过，R24/R25 编译无警告和错误；发布流程内的 LineVision、楼梯、启动器测试通过。用 .NET Framework STA 进程实际构造并渲染 R24 WPF 窗口，确认 XAML 与资源可加载；720×560 和 480×330 两种窗口尺寸下，文字、列表、按钮均未互相遮挡，窄窗口的列表滚动条保持深色。AutoCAD 2022 `accoreconsole` 使用保留的无界面输入路径重新执行 `LTTZ` 更新：实体数 148→147，退出码 0。

仍需在 AutoCAD 2022 图形界面人工点选两步窗口，检查窗口归属、焦点、取消、插入点和反复打开的稳定性。现有无模式 WPF DataGrid 曾在该宿主出现问题，本轮只引入轻量模态 `ListBox`，没有把批量打印窗口一并替换。
