# 门窗参数与移动性能校对

## 范围

用户反馈桂林·山水湾四期模型修改门槛、开启方向和移动门窗卡顿。
实测读取用户已有 model.json，15 层、138 个源门窗，三维约 285718 个面。
测试只操作内存编辑会话，未保存或覆盖用户模型文件。

## 原因与修正

- 原参数预览逐次在界面线程克隆模型，再重建整栋三维；取消又同步重建整栋，应用随后再后台重建一遍。
- 180 ms 合并输入，后台串行处理有效草稿；任务版本与模型引用共同检查，丢弃旧输入及已取消结果。
- 门槛及方向更新只生成相关门窗和标准层实例构件，复用墙、楼板和其他门窗面；完成的预览直接用于应用，取消恢复缓存。
- 未改动字段不再把两位小数显示值写回原始定位/尺寸，避免参数舍入误改模型并触发全量重建。
- 移动重算原宿主/新宿主相关楼层的墙面，完整保留本层交接算法；其他门窗和构件复用。
- 编号位置不改变三维几何；同编号、同类别、同楼层修改保留项目树，不重建上千个节点或重置展开状态。
- 缓存未对应原模型、其他类型编辑以及历史操作仍走完整重建，不能为提速采用过期结果。

## 实测

同机、同份模型、1500x900 客户区。旧代码测量为真实执行旧刷新路径，修正版测量包括合并输入等待及界面更新：

| 操作 | 旧路径 | 修正版一次实测 |
| --- | ---: | ---: |
| 门槛连续输入后预览完成 | 7919.5 ms | 613.6 ms |
| 应用已完成的门槛预览 | 17602.1 ms | 48.6 ms |
| 取消有效门槛预览 | 7958.5 ms | 2.9 ms |
| 非标准层开启方向提交 | 未单独测旧版 | 348.0 ms |
| 非标准层门窗位置夹点松手提交 | 未单独测旧版 | 602.5 ms |
| 4F 源层开启方向提交（同时更新 10 个引用层） | 未单独测旧版 | 511.5 ms |
| 4F 源层位置夹点松手提交（同时更新 10 个引用层） | 未单独测旧版 | 1212.4 ms |

另外在普通层和 4F 源层分别回放 240 次真实路由指针事件，事件处理 P95 不超过 0.01 ms、最大为 0.96/1.17 ms。这不是实时渲染 FPS，也不包含每次输入后等待完整 GPU 帧的时间。
大模型边线叠加仍异步计算，本次没有声称完成全部渲染管线的增量 GPU 上传优化。

## 验证

- 真实窗口参数编辑、立即应用未完成预览、Esc 取消排队输入、一次撤销和未编辑数值精度保留。
- 真实路由方向/位置夹点预览、拖动松手提交、两个独立撤销；操作前草稿不写模型。
- 大模型增量移动后的所有实体面与完整重建逐面核对一致，包括语义 ID、楼层、顶点和法线。
- 门槛局部构件与全部构件重建结果对比，包含标准层；无效实例 ID 不误重建其他门窗。
- 窗口尺寸、通用参数预览和门窗交互回归另行运行，不用小示例的性能代替实际项目测试。
- 不更改产品版本，不创建新安装目录；CAD 主 DLL 无需改动，发布只更新原安装中的模型程序与其核心程序集。

本轮没有新增 UI 设计图，外观和操作规范保持原样；未进行 AutoCAD 实际落图或 Windows 多显示器 DPI 测试。
