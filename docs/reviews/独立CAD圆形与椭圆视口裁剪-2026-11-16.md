# 独立 CAD 圆形与椭圆视口裁剪

版本保持 1.5.6。本批接续 MiniCAD 二维能力，在已有多边形裁剪与文字／图片精细裁剪上增加圆形、轴向椭圆边界。

## 操作与文件表达

- 布局页使用“裁剪视口”或 VPCLIP，窗口选择目标视口及边界类型。
- 圆形依次指定圆心和圆周点，椭圆依次指定外包矩形的两个对角点。第二次单击提交。
- Backspace 退回首点，Esc 取消草稿，已提交结果可用 Ctrl+Z 撤销。无效半径保留工具供重新指定。
- 纸面边界改变时保持模型到纸面的变换和比例。恢复矩形、复制布局及保存重开延续已有入口。
- DWG／DXF 写入原生 CIRCLE／ELLIPSE，并正确记录视口的非矩形裁剪引用及纸空间归属。原图保存沿用未共享边界句柄，切换类型更新实体，清理恢复矩形后的孤立边界。
- 独立版以 256 段显示及裁剪曲线，命中检查使用椭圆方程。CAD 文件保存解析圆／椭圆。首批绘制和识别支持水平／竖直长轴的完整椭圆。
