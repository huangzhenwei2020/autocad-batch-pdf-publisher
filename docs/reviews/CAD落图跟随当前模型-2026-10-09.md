# CAD 落图跟随当前模型

版本保持 1.5.6。用户反馈 CAD 落图不是当前正在编辑的建筑模型。

## 原因与修复

- Studio 打开、保存模型会写入项目的 `建筑模型/当前模型.txt`，但原 CAD 落图按项目名称调用 `FindModelFolder`，跳过了当前模型记录。
- CAD 窗口及无界面序号入口统一使用 `StudioLaunch.ActiveViewSource`，读取当前模型所在目录的视图，不再借用项目同名旧模型。
- 窗口显示当前项目、实际模型目录名及路径提示；刷新重新解析当前模型。不同模型即使图纸 ID 相同，也清除旧勾选；同模型刷新按路径与 ID 保留勾选。
- 点击开始落图前重新核对来源，切换后停留窗口供用户重新选择。来源读取失败清空清单，缺少模型或视图不回退旧模型。
- 生成／推送视图成功后更新当前模型记录，即使本轮没有新的未保存编辑，也能使 CAD 取到刚发布的模型。
- 独立非 `model.json` 文件不借用同目录其他模型的视图；需要另存到独立模型目录后生成视图。

图纸仍是已生成的视图快照，不是内存模型的实时投影。修改模型后请在当前模型中生成视图／推送 CAD，再刷新落图窗口；本轮没有新增实时双向绘图功能。
