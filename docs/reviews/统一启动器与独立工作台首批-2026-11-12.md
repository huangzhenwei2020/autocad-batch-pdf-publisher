# 统一启动器与独立工作台首批

版本保持 1.5.6，已于本轮确认保存关闭后备份覆盖原安装目录。

## 已实现流程

启动器以 WPF 显示共用项目列表，提供“进入独立版”和“打开 AutoCAD／天正”。独立入口启动自包含 .NET 8 WPF 工作台，CAD 入口进入既有环境选择与加载流程。项目管理和 CAD 环境配置本轮复用现有窗口。

工作台支持项目选择、新建、关联已有项目文件夹，直接使用 PublishPlanStore 和 BuildingModelCatalog。模型支持新建、打开、保存、另存副本和楼层名称／标高／层高编辑。同名新建提供打开已有模型、备份后替换、取消三个选项。保存复用模型校验和文件互斥，核对打开时文件哈希与三维活动会话。

“打开三维编辑器”通过模型文件路径及项目目录接通现有 Avalonia 编辑器，其中参数门窗、标准层、语义模型和本地图库继续沿用现有数据服务。三维界面尚待后续 WPF 整合。

图纸预览采用独立 MiniDWG 读取进程，基础覆盖 LINE、ARC、CIRCLE、带凸度轻量多段线、TEXT、块及属性、模型与布局空间。提供图层开关、适应窗口、滚轮缩放、中键平移、坐标显示、进度和取消。未覆盖的对象类型与数量显示在读图结果中。首批尚待实施独立 CAD 编辑、天正语义登记建模及独立 PDF 发布。

## 源码与部署

- `BatchPdfPublisherLauncher/LauncherEntryWindow.xaml` 提供 WPF 双入口。
- `StandaloneWorkbench` 提供 WPF 工作台与项目模型交互。
- `DrawingReader` 提供 C++20 独立读取进程。
- `ThirdParty/MiniDWG` 保存上游序列化子集、固定提交和许可。
- `Shared/UI/WorkbenchTheme.xaml` 共用深色控件和滚动条。
- `Shared/CloudSyncAgentSignal.cs` 向既有托盘同步进程发出重新扫描请求。
- `build/Build-Release.ps1` 统一发布两个 CAD 代际、启动器、自包含工作台、读图引擎和自包含三维编辑器。
- `build/Test-StandaloneWorkbench.ps1` 使用独立配置和合成图验证基础闭环，可传入已有临时 DWG。

MiniDWG 子集来自 MiniCAD 0.8.4，提交为 `9740e7fbc288f1ea5a71af2b89503fce1496389c`。保留 MIT 许可与第三方说明，使用原始序列化库源码构建。完整 MiniCAD UI 及绘制内核的兼容范围仍按技术评估推进。
