## 三维工作区

独立工作台顶部提供二维绘图、三维建模和模型管理。模型管理的“进入三维建模”在同一主窗口承载现有完整建模界面，沿用墙、弧墙、门窗分格、楼板、阳台、女儿墙、构件图库、图纸视图及模型导出。二维和三维切换保留各自文档及编辑状态。

WPF 主工作台通过显式 Win32 子窗口宿主承载原有 Avalonia 建模程序。三维渲染保留独立进程，使用当前用户命名管道协调就绪、保存、另存、撤销重做和关闭。模型数据、编辑历史、保存确认和参数窗口继续由同一建模会话管理，项目文件和共用图库沿用原路径。

切换项目或模型、关闭工作台前，先处理三维会话的保存确认。取消确认保留草稿和模型窗口。三维编辑期间，管理页的楼层表采用只读模式，楼层修改使用三维中的楼层设置。管理页保存／另存路由到当前三维会话，避免使用旧快照覆盖正在编辑的模型。

子窗口实现显式设置 WS_CHILD、清除 WS_POPUP，并按宿主实际客户区像素缩放。当前测试覆盖本机桌面下的窗口缩放。跨显示器不同物理 DPI 的切换仍需专项验证。[Microsoft SetParent](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setparent)

独立 DWG 楼层登记自动建模、模型出图回填独立二维文档仍沿后续计划接入。现有 CAD 专用协同入口保留原宿主流程。

## AutoCAD 操作依据

命令栏输入命令和数值后，Enter 与空格执行确认。命令完成后空输入再次确认可重复上一命令，Esc 取消当前命令。[Autodesk 命令输入](https://help.autodesk.com/cloudhelp/2022/ENU/AutoCAD-MAC-Core/files/GUID-4F12A276-E19C-434C-B0E7-DF6C30B1D324.htm)

空白处单击并松开，移动光标，再次单击完成矩形选择。左向右选完整包围的对象，右向左包含相交对象。普通点选追加，Shift 点选或框选移除对象。采用 PICKFIRST=1、PICKADD=2 的常用选择规则。[Autodesk 选择规则](https://help.autodesk.com/cloudhelp/2024/ENU/AutoCAD-DidYouKnow/files/GUID-D0D5C0C3-F092-448A-8E81-D38F27094639.htm)

## 本批交互实现

| 操作 | 行为 |
| --- | --- |
| 命令输入框的空格／Enter | 提交命令和坐标，焦点返回绘图区 |
| 绘图区空格／Enter | 确认当前步骤，空闲时重复上一命令 |
| 直线 | 连续落点，空格／Enter 结束并保留已画线段 |
| 多段线 | 空格／Enter 提交草稿 |
| 圆、矩形、三点圆弧 | 完成一次有效几何后结束命令 |
| 两点矩形选择 | 首次松开鼠标后保持框选，第二次单击完成 |
| 左右方向 | 左向右窗选，右向左交叉选择 |
| 追加与减选 | 普通点选／框选追加，Shift 减选 |
| 命令前后选择 | 支持预选后修改，也支持先发起移动／复制／旋转／缩放／镜像／删除／分解，再选择并确认 |
| Esc | 清理框选和当前工具状态，已应用几何通过撤销恢复 |

普通参数输入框和模型名称输入保持文字输入行为。空格确认仅在 CAD 命令输入框处理，通过 PreviewKeyDown 避免 TextBox 将空格提前当作文本消费。

后续修复已统一为两次点击完成矩形选择。用户反馈首次点击稍有移动便退回拖拽分支，已移除该分支，详见 [首次移动及松键保留修复](二维两点框选与鼠标移动修复-2026-11-13.md)。套索、围栏、多边形选择、完整命令选项及右键自定义菜单仍需后续适配，完整 AutoCAD 操作一致性继续逐项验收。
