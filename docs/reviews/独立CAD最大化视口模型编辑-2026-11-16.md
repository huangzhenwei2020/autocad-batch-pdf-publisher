# 独立 CAD 最大化视口模型编辑

版本保持 1.5.6。本批接续布局视口内模型实体编辑，采用最大化编辑流程。

## 操作

布局页“视图 → 布局视口 → 编辑模型”及底部“视口编辑”进入最大化模型编辑，命令为 VPMAX。多个平面视口且未选定目标时弹出视口选择窗口。已选定视口或仅有一个视口时直接进入。

编辑时使用整块画布，保留原视口的模型中心及旋转方向，当前布局页签继续选中。底部显示“返回布局”，VPMIN及PSPACE也可返回。再次输入VPMAX保持当前模式。切换布局会退出临时编辑，切换图纸则保留各自的编辑会话。

模型对象共用原图Scene、Editor、捕捉、拾取、绘图修改工具及撤销栈。新增实体进入模型空间，纸空间图形在编辑模式下隔离。视口冻结层参与顶层显示、捕捉、选择及嵌套绘制／拾取／高亮过滤，保存维持原有全局图层开关。

锁定视口允许编辑模型。中键平移和滚轮缩放使用临时编辑相机，返回恢复原纸面相机。原视口纸面中心、尺寸、比例、旋转、模型中心、冻结层和锁定数据保留。临时范围缩放沿用几何撤销顺序，编辑中的方向切换保持二维工作流。原裁剪边界通过临时轮廓提示原出图范围。

Esc取消当前草稿，已应用修改保留，Ctrl+Z撤销几何。布局页签切换与返回按钮会先结束当前草稿并清理选择。DWG／DXF保存更新共用模型，临时编辑模式及提示轮廓属于会话状态。

Autodesk文档说明VPMAX会扩展布局视口并进入模型编辑，锁定视口也可编辑模型，VPMIN恢复原中心及放大率。[最大化视口编辑](https://help.autodesk.com/cloudhelp/2022/ENU/AutoCAD-LT/files/GUID-97B34506-5671-4680-A97F-955DE7715B52.htm)、[VPMIN](https://help.autodesk.com/view/ACD/2026/ENU/?caas=caas%2Fdocumentation%2FACDLT%2F2014%2FENU%2Ffiles%2FGUID-A18E5FA1-2A4E-461B-A606-EFF5AB14E0E5-htm.html)
