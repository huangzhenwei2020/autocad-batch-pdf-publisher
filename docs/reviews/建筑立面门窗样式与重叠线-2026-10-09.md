# 建筑立面门窗样式与重叠线

日期：2026-10-09。产品版本保持 **1.5.6**。

## 本轮修正

建筑立面复用门窗立面几何生成器，但此前在投影和裁剪时丢失线条类别，全部落到建筑细线图层；开启线也失去虚线属性。现保留外框、分隔框、扇框、开启、安装洞口和材料类别，以及门／窗外观分类，从遮挡裁剪、镜像、图纸排版、JSON 一直保留至 CAD 原生落图。

CAD 门、窗及开启洞口分别使用门窗立面同一套 `DoorWindowDoor`、`DoorWindowWindow`、`DoorWindowOpening` 制图标准配置；颜色与线型随层，扇框保留原门窗立面的 ACI 8 表达。带玻璃上亮的门沿用既有窗外观规则，不另造门型分类。用户设置的图纸门窗线宽仍优先；未单独设置时 CAD 采用对应标准图层线宽。

Studio 图纸预览按对应类别使用窗框青色、普通门深色、扇框灰色、开启示意浅色虚线的易读默认表达。实际 CAD 图层名称、颜色和线型以当前制图标准为准，不声称预览已实时读取所有 CAD 自定义真彩色。

输出清理采用 0.01 mm 共线容差、方向／法向距离分桶和区间相减：完全重合、反向重复、同用途的部分重叠不再重复输出；相接且样式及描边区域一致的实体框线合并。洞口与实体框轮廓重合时保留实体框，开启示意不因与实线共线就被误删。真实平行框线、安装缝、不同用途线型和解析圆弧保留；不改变模型洞口尺寸、分格、三维几何或标准层。独立 CAD 门窗立面插入也复用相同清理规则。

旧视图 JSON 和旧 CAD 实体不强制迁移；刷新／重新生成立面或重新落图后采用新规则。
