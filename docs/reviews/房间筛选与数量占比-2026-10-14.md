# 房间筛选与数量占比

版本保持 1.5.6，沿用 FJTJ / FJHZ 和原统计窗口，不新增重复入口。

## 本轮规则

- 名称筛选：排除、仅包含、全部房间。关键词按名称包含匹配，忽略大小写；
  支持逗号、顿号、分号及换行分隔，不把单个关键词中的空格拆开。
- 首次默认排除“楼梯、水井、电井、前室、电梯”，例如楼梯间、消防前室、电梯厅都排除。
- 预览逐项勾选的是房间名称组；同名房间整体纳入或排除。原 CAD 框选仍决定候选范围。
- 支持全部勾选、取消勾选和恢复默认；恢复默认同时清空手动排除。
- 模式与关键词在窗口关闭时按既有 INI 方式保存；手动排除不跨次保存。
- 修改关键词或勾选即重算，不重复读取 CAD；不修改原房间或原表。
- 普通房间统计继续保留同面积明细，筛选影响实际插入的统计数据。
- 汇总只输出“序号、房间名称、数量、数量占比”，合计行为数量总数和 100.00%。
- 占比 = 本名称被计数量 / 最终勾选总数，显示两位小数百分比；逐项四舍五入可能有尾差。
- 全部排除时不允许插入空统计表，不除以零。
- 兼容旧五列面积统计表及本次四列数量汇总表；数量汇总不依赖面积明细或旧占比，
  因此面积明细无效但数量有效的旧表仍能汇总数量。旧合计行不重复计入。
- 新数量表保留来源快照，可保存后重新汇总，并与来源表去重；同来源面积变化
  不影响数量去重，名称或数量版本冲突仍须选择最新表。
