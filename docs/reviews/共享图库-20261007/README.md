- `shared-cad-only-960x680.png` / `shared-cad-only-1600x960.png`：未补充模型时的同条记录与真实 CAD 预览。
- `pairing-960x680.png` / `pairing-1600x960.png`：预载 CAD 平面，仅载入 GLB。
- `library-960x680.png` / `library-1600x960.png`：模型补充后仍是原条目，修订不重复列出。
