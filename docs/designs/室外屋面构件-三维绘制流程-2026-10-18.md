日期：2026-10-18。状态：**用户已确认，分阶段实施；不是全部已实现功能**。版本保持 1.5.6。

后续源码进展（2026-10-20 已安装）：语义板边/板洞边/墙顶中心路径的单边或整圈快照取边，以及已有阳台三维轮廓重绘已实现并通过回归，见 [实现与边界](../reviews/三维语义取边与阳台重绘-2026-10-18.md)。不代表持续宿主追踪、任意选面、三维节点夹点及栏杆已经实现；其余流程仍为目标设计。

用户在阅读流程后已要求结合现有条件开始实施。首批已完成三维水平工作平面的女儿墙路径和阳台板体，且经用户确认关闭、备份覆盖原安装，见 [首批实现与安装边界](../reviews/三维女儿墙与阳台绘制首批-2026-10-18.md)；其余为目标流程，不表示全部完成。R0 工具和未提交代码保留。关联 [开发计划](../plans/天正室外与屋面构件识别及栏杆绘制-开发计划-2026-10-18.md)。

## 1. 核心决定

五类构件采用同一条主流程：**进入构件工具 → 选做法 → 确定楼层/室外与标高 → 绘制或取已有边 → 预览调整 → 完成**。

- 阳台、散水、泛水、女儿墙、栏杆都能在建筑模型内独立绘制，不依赖 CAD、图纸登记或识别结果。
- 绘制在主模型视图中进行，不在参数窗口里操作项目几何；参数窗口只负责选型及实际构件小样。
- 一套参数与几何同时服务手工、可选 CAD 来源、平面辅助视图、三维、出图和导出，不做两种来源各自独立的模型。
- 首批先支持明确水平工作平面上的自由绘制及已验证的平面宿主。复杂坡屋面、楼梯斜向跟随单独开发和验收；不提供一个看似可选却实际不能用的模式。
- 无 CAD 的空模型也有完整绘制路径，只有类型缩略图或参数表不能算完成。

## 2. 入口与界面分工

### 2.1 从哪里开始

沿用现有 Ribbon“构件”页：阳台、栏杆、散水、泛水提供直接工具；女儿墙是墙体工具中的用途，同时可有直接预选该用途的入口，二者打开同一个墙体窗口，不另做两套参数。

已有构件被选中时，右侧属性可直接修改参数；“编辑路径”“更换做法”是选中后的明确操作，不需要删除重画。未选中构件时不展示假定属于某个实例的参数。

### 2.2 选型窗口

- 左侧：项目中可用的做法，按真实截面/杆件/板形生成缩略图，不使用通用盒子冒充部件。
- 中间：所选做法的三维小样与截面切换；改变参数即更新，尺寸标注跟随实际几何。
- 右侧：尺寸、材料、基准、偏移和按构件需要出现的排布参数；数值使用带上下箭头的输入框。
- 底部：明确的“开始绘制”和“取消”。开始绘制只进入工具，不创建项目构件、不改变选中的旧构件。

首轮可复用现有墙体窗口；其余窗口使用相同布局，不以通用巨型表单同时展示五类全部参数。公共图库的样式发布另按原共享图库规则实施，首批项目做法不冒充新公共资源库。

### 2.3 绘制时的主窗口

- 左侧项目树保持原位，不切换成另一套管理导航。
- 视口上方出现当前工具条：路径方式、线段/圆弧、选边范围、偏移侧及结束/取消图标。选项集使用菜单或分段控件，工具图标有名称提示。
- 右侧保留当前草稿的少量常用参数和分段属性，可输入后即时预览，不重新打开大窗口。
- 底部只显示当前步骤及错误，例如“指定下一点”“选取楼板边”“轮廓自交”；不放功能介绍或整段教程。
- 不自动把三维视图切到平面。用户主动切平面辅助时保留草稿、工作平面及已拾取点，返回三维不丢操作。

## 3. 定位：先把“画在哪儿”说清楚

### 3.1 归属与标高

默认继承当前楼层；散水默认使用室外归属，室外不是一层虚构楼层。工具条始终显示本次归属和基准，避免沿用上次屋面标高却在首层误画。

基准采用三种明确选择：

| 基准 | 操作 | 保存关系 |
|---|---|---|
| 当前楼层 | 选楼层，输入相对标高 | 随该层标高变化，偏移不变 |
| 选宿主面/边 | 点选楼板顶面、屋面或墙顶边 | 显示宿主名称和实际标高，可跟随宿主 |
| 指定高程 | 选择水平工作平面，输入绝对高程 | 独立保存，不因层高改变自动跳动 |

结构板面、完成面不是同一概念；需要完成面时允许输入明确附加偏移，不假定模型已经有装修层。宿主已有高程只取一次，不能再叠加楼层高程造成双倍抬高。

### 3.2 三维拾点与捕捉

- 自由绘制时显示当前水平工作平面的淡化网格和实际落点；射线与工作平面求交，不以鼠标屏幕坐标直接当模型坐标。
- 捕捉端点、交点、现有语义边等，显示捕捉位置。离平面过远的点不静默吸附到其他楼层；需要换基准时明确操作并重新核对草稿。
- 已有宿主模式只从可见、可编辑的候选面/边拾取，不穿透选中背面或隐藏楼层。相近候选可临时高亮切换，最终点选锁定。
- 工作平面或宿主一旦锁定，旋转相机不改变基准；视线近乎平行于平面时提示调整视角，不能制造极远落点。
- 只选建筑边界、板边、洞边等语义边，不把三角网格的内部对角线提供为路径。

## 4. 两种常用绘制方式

### 4.1 自由绘制

1. 确定工作平面后点起点；移动鼠标显示路径、实际构件和动态长度。
2. 可输入长度及方向/角度，也可捕捉下一点；数值输入的 Enter 只确认该数值，不同时结束整条路径。
3. 点击下一点，继续添加直线。圆弧通过工具条切换，采用已有三点弧逻辑，预览通过点和走向；此时完成按钮只在圆弧参数齐全后可用。
4. 路径构件允许开放或闭合。轮廓构件必须闭合；直边轮廓至少三个有效顶点，带弧轮廓按闭合、非零面积及无自交检查，不机械要求三条直边。
5. 有效路径完成后按 Enter 或点“完成”提交一次；闭合轮廓在回到起点后进入完整预览，再明确完成，不能把闭合误当取消。

数值框有焦点时先处理数值，再回到视口绘制状态。暂不擅自分配新的全局字母快捷键；已存在的 F 圆角等按原上下文保留，后续有冲突检查后再确定工具内快捷键。

### 4.2 沿已有边绘制

1. 选“已有边”，悬停高亮真实边，点选第一条；尚未创建构件。
2. 范围可选“单边”“连续边”“闭合周边”。默认单边，不能第一次点选就自动绕整栋生成。
3. 连续边在分叉处让用户选方向；闭合周边先显示完整候选，可取消不需要的边或设置断口。
4. 屏幕显示构件落位及偏移方向，用户确认定位侧；没有已确认内外关系时使用路径左/右侧，不假称“室内/室外”。
5. 改尺寸或排布，确认实际预览后完成，整个选择路径作为一个撤销单元。

无现有模型边时，“自由绘制”始终可用。阳台的板面创建使用轮廓绘制或完整板轮廓复用，不把任意一条不闭合板边直接猜成阳台面。

## 5. 五类构件的具体流程

### 5.1 女儿墙

**选墙体用途“女儿墙” → 选屋面板顶或指定基准 → 画线/弧，或选屋面周边 → 调整厚度与内外定位 → 完成。**

- 高度是独立墙高，不默认拉满层高；没有屋面也可用指定基准绘制。
- 同一路径内的墙段正确连接，转角预览实际墙体收口；底顶标高、材料不同的段不误合并。
- 默认跟随所选宿主底部高程，墙高保持；按段修改与整条路径修改有明确作用范围。

### 5.2 阳台

**选阳台做法 → 确定楼层与板顶偏移 → 画闭合轮廓/矩形，或复用已有板轮廓 → 完成阳台板 → 按需选边添加栏杆或栏板。**

- 首先得到可保存、可编辑的阳台板；栏杆、栏板是后续可选子构件，不强制每边都加。
- 板生成后保持该板选中，“添加栏杆/栏板”定位到它的真实边界；只预选与当前做法明确对应的边，不能默认为建筑连接边也加一圈。
- 已有楼板与拟建阳台重合时，显示重合区域并提供“使用已有板”或返回修改边界；不默认复制一块叠板，也不自动裁切原楼板。
- 板与后续栏杆是两次明确提交，分两步撤销。避免用户只想撤掉栏杆时连阳台板也消失。

### 5.3 栏杆

**选竖杆/玻璃做法 → 自画路径或选阳台/楼板边、墙顶 → 确认基准与偏移侧 → 预览实际立柱和分格 → 完成。**

- 总高、扶手/立柱截面、最大柱距、端部退距、填充净距分别设置；修改长度重新排布，不整体拉伸固定截面。
- 转角柱只出现一次，端柱可独立开关；短段容不下当前做法时标记对应段，不凭空塞入交叠柱或删除整条路径。
- 分格的“均分/延续节距”有实际杆件预览；大量杆件在提交前预检数量，超限先提示调整，不让界面长时间无响应。

### 5.4 散水

**选散水做法 → 确定室外基准 → 沿建筑选边或自画路径 → 指定向哪侧铺设 → 调宽度/内侧高程/厚度/坡度 → 留入口断口 → 完成。**

- 用方向箭头及实际坡面显示坡向，同时显示计算出的外缘高差；宽度或坡度改变，预览立即重算。
- 门口、台阶、坡道处允许排除某段及精确输入断口长度，不假定图中所有出入口都已识别。
- 转角、内院及分段高程在提交前检查；默认不随标准层复制。

### 5.5 泛水

**选泛水截面 → 选屋面与墙交接边，或指定高程自画路径 → 确认立边侧和搭接侧 → 调立边高度/水平搭接宽度/做法厚度 → 完成。**

- 截面小样与视口一致，能看见立边朝墙还是背墙、搭接朝哪侧，不能只显示一根中心线让用户猜。
- 没有屋面实体也可在指定基准绘制，但属于独立构件，不伪造宿主。
- 只自动跟随已支持且能求局部高程的宿主；遇到未支持的坡面或高程跳变，明确停在该段供调整，不水平连过去，也不回落到零高程。
- 薄层示意和真实厚度分开处理，不默认生成一圈承重墙。

## 6. 草稿、提交和取消

| 当前状态 | Enter / 完成 | Esc | Ctrl+Z |
|---|---|---|---|
| 选型窗口 | 开始绘制进入工具 | 关闭窗口，不改模型 | 数值框有焦点时只撤文字输入 |
| 等待起点/第一条边 | 无有效草稿时不创建对象 | 退出当前工具 | 视口焦点且无草稿时，撤销上一笔模型提交 |
| 草稿已有点/边 | 参数齐全且校验通过才提交 | 丢弃当前未提交路径，回到等待起点 | 视口焦点时撤掉最近草稿点/弧或边选择；同一次按键不继续穿透撤旧模型 |
| 绘制中正在输入数值 | 确认当前数值，返回绘制 | 恢复该字段输入前的草稿值 | 仅处理文本框输入历史 |
| 刚完成一条路径 | 保持工具，准备下一条；不重复提交 | 退出工具，不删已完成构件 | 没有当前草稿、视口焦点时撤销上一笔模型提交 |
| 编辑已有构件草稿 | 应用全部有效修改，提交一次 | 取消本次未应用修改，保留已应用结果 | 有草稿时只撤本次草稿编辑；无草稿时沿用模型撤销 |

- 连续路径提交后可继续画下一条，避免每条都重新开窗口；画单个女儿墙回路或整条栏杆是一笔提交。
- 新女儿墙一条路径可能由多面墙组成，但这次路径提交一起撤销；不在本轮顺便改变旧普通墙的逐段提交习惯。
- 右键提供就近操作菜单：完成、闭合、退回上一步、取消；无效操作禁用。门窗移动中“右键沿墙居中”的旧约定不改。
- 不启用容易误结束路径的双击提交作为首批默认；轮廓闭合与整笔完成有独立的有效性判断。
- 绘制时改参数只更新草稿，不每次按键写一个模型历史；更改宿主/工作平面会影响已有点时先预览差异，不能悄悄投影旧草稿到另一层。

## 7. 已绘制构件如何修改

1. 选中构件，右侧显示其实际参数、基准、宿主、来源和所属楼层；默认只作用于当前选中实例。
2. 输入参数实时预览，字段中按 Enter 或点击“应用”提交当前整组有效参数草稿，一次操作即可，不要求连按两次 Enter。取消恢复旧值。参数无效就地标记，不关窗口、不清空选择、不破坏旧模型。这与绘制期间 Enter 仅确认动态尺寸的上下文区别应在状态和按钮可用性上明确。
3. “编辑路径”显示端点、节点及侧向/标高控制；拖动夹点显示草稿，放下即提交，不再要求额外 Enter。越界或自交则保持拖前状态并定位原因。
4. 支持移动、旋转、复制和删除；复制分配新实例身份，保持适当的类型引用，不把所有复制件当同一个实例。
5. 多选相同类别可批量修改共同参数，混合值明确显示；未明确选择“修改项目类型/同类型全部”前不扩大范围，不影响其他楼层实例。

宿主移动/改高程后按已选跟随规则重算；删除宿主时可选连同依附构件删除或转独立，转独立保留当前世界位置。标准层默认共享模板，修改前明确作用于标准层组还是先解除当前层的共享。CAD 重新登记仍按既有用户约定的替换范围执行，不能默认为手绘件永久不替换。

## 8. 输入、校验与小窗口

- 工程长度输入默认整毫米，坡度/角度允许合理小数；保留模型坐标和曲线的计算精度，不能把门窗洞口按 10 mm 归整的规则全局套给杆件、截面或节点。
- 长度、厚度、宽度、半径及排布边界按实际几何校验；不规定一个缺少规范依据的“统一安全高度”。参数错误不冒充规范检查。
- 自交、零面积、半径不足、重复边、无宿主高程、短段装不下立柱等问题，在视口高亮对应位置；允许修正，旧已提交模型不动。
- 尺寸输入有上下箭头，偏移方向用图标及箭头，模式用分段控件；不以大量文字按钮挤满工具条。
- 小窗口自动收起非当前参数，属性区可滚动，工具条允许折叠次要命令；完成/取消始终可达，视口不能缩到只剩一条缝。
- 继续使用已有视图旋转、平移和缩放操作；导航不提交草稿、不改变工作平面，也不与新快捷键争抢。

## 9. 进入编码前要确认的四点

1. 大窗口选做法，主视图绘制时用右侧参数调整，不在大窗口里画项目路径。
2. 自画与取已有边两种入口并存，不依赖 CAD；第一批三维基准以明确水平平面/已支持宿主为准。
3. 一条路径完成后整体提交，Esc 取消当前草稿或退出工具，不撤已提交对象；草稿撤点与模型撤销按状态隔离。
4. 阳台板先完成，栏杆/栏板再作为可选操作添加；不一次默认包围所有边。

以上确认后，再按开发计划实现绘制状态、工作平面、女儿墙/阳台，再扩展栏杆与散水/泛水。正式开工前以本稿处理提交行为和操作顺序，不能直接把前期选型窗口示意当作完整交互规格。
