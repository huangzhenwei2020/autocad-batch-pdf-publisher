# 建筑结构构件与屋顶机房开发计划

## 已确认的规则

- 单位统一为毫米，楼层标高作为构件的竖向基准。
- 新楼板默认板顶齐所属楼层标高，板厚向下；允许板顶偏移。
- 新梁默认梁顶齐板顶，梁高向下；允许独立偏移。
- 柱默认从本层到上一层楼面，允许柱底、柱顶偏移；跨多层柱后续增加明确的终止楼层。
- 屋顶层、机房层各有独立平面和标高，不套用普通标准层；机房只生成局部实际轮廓，不复制整栋楼。
- 普通标准层共用平面，三维必须逐实际楼层实例化，不能只显示一份。

## 第一阶段：楼层类型与标高联动

本阶段已实现：

- 楼层设置增加普通层、屋顶层、机房层；增加屋顶层、机房层入口。
- 标准层引用校验排除屋顶和机房；楼层计算、CAD 登记复制、保存和三维展开保留类型。
- 楼板增加可空 `TopOffset`，值为 0 表示板顶在本层标高；三维与立剖面统一通过 `TopElevationOf` 取值。
- 柱增加 `BaseOffset`、`TopOffset`；自动高度模式按层高和上下偏移计算，三维与立剖面共用计算。
- 屋顶类型楼层的默认坡屋面檐口取本层标高，普通层维持旧规则。
- 回归覆盖保存、撤销重做、标准层实例、楼板厚度方向、柱偏移、特殊楼层和旧模型。

兼容边界：旧楼板没有 `TopOffset` 时继续使用绝对 `TopElevation`，调整楼层时沿用原有楼面/层顶跟随逻辑，不批量改变旧板的位置。显式柱高继续保留，不自动改成层高。第一阶段还没有新增楼板绘制和结构参数面板。

## 第二阶段：楼板与洞口

2026-10-01 进度：设计已确认，几何、绘制工具和右侧参数面板已实现；R24 与独立模型程序已编译。用户本轮确认关闭 CAD 和模型窗口后，已于 18:42 覆盖原安装目录，285 个文件哈希核对通过，版本保持 1.5.6。备份：`.artifacts/install-backup-20261001-184232`。

- 已新增带身份、名称、闭合轮廓的楼板洞口，支持多个内部井道。
- 已用 LibTessDotNet 1.1.15 双精度库生成凹板及带孔板面，保留外圈和洞壁，验证面积、贯通和闭合实体。
- 已实现新增/修改楼板事务、短编号、非法轮廓拒绝、保存及撤销重做。
- 已同步现有平面视口的轮廓显示、CAD 平面板边及孔边、剖切板段和 GLB 导出；标准层保留孔洞并逐层生成。
- 当前洞口要求完全处于板内，边界不能相接，孔不能重叠或嵌套；开到外边缘的缺口应编辑外轮廓。尚未实现自动识别楼梯井、电梯井，不擅自封板。
- 新增共享三角化依赖后，R24 编译需 `/restore`；安装必须同时覆盖 `LibTessDotNet.dll`、`LibTessDotNet.Double.dll`，不能只复制插件 DLL。

- 属性栏保留楼层、编号、厚度、板顶偏移、只读顶底标高，以及洞口列表、名称和宽长；多边形宽长按包围盒以左下角为基点缩放，几何仍须通过校验。正文滚动、底部固定按钮、路径翻页、胶囊拖动与上下数字箭头均有独立运行检查。
- 视口新增真实板面填充、洞口位置/尺寸标记、项目树洞口子项；门窗图例复用 CAD 投影的共享算法，不在高频重绘时重新三角化。
- 图片中残留的滚动箭头不采用，标题图标复用现有统一品牌图形，不以普通 W 字替换。实际模型比例按毫米坐标显示，不拉伸去匹配生成图中不准确的几何比例。

- 自定义闭合轮廓、板厚、板顶偏移及属性面板。
- 显式登记楼梯洞、电梯井、设备洞和中庭；未经确认不得直接封满全部建筑轮廓。
- 使用成熟多边形裁剪和带孔三角化库，验证凹轮廓、多孔、孔靠边、非法交叉。
- 同步平面、三维、立剖面、CAD 与导出模型，保留对象身份、图层和撤销。

## 第三阶段：梁柱

- 梁完整接入模型存储、编辑、三维、立剖面、CAD、导出和对象身份，不只添加数据类。
- 梁截面、定位轴、梁顶偏移；相交与端部连接。
- 柱终止楼层及跨层跨度校验；删除终止楼层须处理引用。
- 标准层的跨层柱必须按相对跨度展开，不能错误引用原始楼层。

## 第四阶段：屋顶与机房

- 屋顶板、洞口、女儿墙、平屋面与坡屋面。
- 独立机房局部墙、梁柱及屋面；不自动复制普通楼层门窗。
- 全楼立剖面、最高点标高、取景范围及模型导出验证。

## 交付流程

新面板先画设计图并确认；遵守 UI 开发原则，控件等高、紧凑对齐、DPI 不裁切。每阶段独立测试与编译。覆盖原安装目录前重新确认 CAD 和建筑模型窗口均已关闭，校验安装文件哈希；不增加另一套安装版本。
